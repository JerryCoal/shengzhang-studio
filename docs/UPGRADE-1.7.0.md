# v1.7.0 测试版：MCP 连接与 Qwen

这是 2026-10-14 保存的开发进度版本。已完成本地回归；真实账号发布、外部小红书 MCP 服务联调和新界面完整验收尚未完成，不应视为正式生产版。v1.6.0 与 v1.2.0 下载继续保留。

## 本次新增

- 连接与设置 → 账号与发布：增加小红书、抖音 MCP 连接卡片。
- Windows 应用随启动提供内置 MCP，驱动现有官方页面助手。小红书还可选择外部 `xpzouying/xiaohongshu-mcp`。
- 发布中心增加「MCP 投送」：自动准备本次素材与文案、确认后提交、保存可识别回执。结果不明时锁定本条，防止重复投稿。
- 评论分析增加「MCP 获取评论」：选择自有已发布作品 → 采集 → 勾选预览 → 导入去重；原有人工分类保留。
- 文字模型新增 Qwen Plus / Flash，保留 OpenAI、DeepSeek。模型可按策略、规划、文案、分类、复盘分别选择。
- Qwen API 密钥与可选 MCP 访问令牌按工作台用户在本机加密保存，重启保留，备份文件不含这些密钥。

## 升级与使用

1. 在旧版系统托盘中选择「退出并停止后台任务」。完整解压新版 ZIP，再运行 `ShengzhangStudio.exe`。
2. 使用原有本地用户登录；数据继续在 `%LOCALAPPDATA%\ShengzhangStudio`，不放在安装目录中。
3. 连接与设置 → 文字模型：选择 DeepSeek 或 Qwen，保存对应平台 API Key 并检查连接。Qwen 当前支持阿里云百炼北京地域的 `https://dashscope.aliyuncs.com/compatible-mode/v1`。海外地域 Key 不适用于此固定地址。
4. 连接与设置 → 账号与发布：选择内置 MCP，点击「检查连接」。不需要另装 MCP；平台登录仍需在官方页面自行完成。
5. 发布中心选择成品，点击「MCP 投送」，核对账号、标题、正文和素材。内置助手准备完成后仍会弹出最终确认；选择继续检查不会发布。登录、验证码、可见范围、平台额外选项需要本人处理。
6. 核对平台结果并登记作品链接后，在评论分析点击「MCP 获取评论」。选择条数、是否含回复，完成后预览并导入。平台未加载的评论不计入结果，不承诺完整抓取。

模型连接检查不产生付费文案，但真实生成按服务商计费。Qwen 界面金额是预算估算，不是最终账单。

## 外部小红书 MCP：待完成实机联调

适配目标：[xpzouying/xiaohongshu-mcp](https://github.com/xpzouying/xiaohongshu-mcp)。工作台通过 MCP 协议调用其工具，没有直接复制其爬虫代码或把第三方程序打进安装包。

1. 按该项目说明下载、运行 Windows 服务。推荐只绑定本机，例如 `-port 127.0.0.1:18060`；若启用服务访问令牌，在工作台填写相同令牌。
2. 在工作台选择「外部 MCP」，填写 `http://127.0.0.1:18060/mcp`，保存后检查连接。当前只支持本机 HTTP `/mcp` 地址；Docker 的素材路径需自行做好映射。
3. 连接成功且工具可用时可获取登录二维码。评论读取需要完整小红书作品链接，包含平台提供的 `xsec_token`；不要把 Cookie、平台密码或模型 API Key 当作 MCP 令牌。
4. 外部发布在工作台明确勾选并点击确认后直接交给 MCP 执行，不再弹出内置助手的确认框。必须先核对该服务实际登录账号。

**当前验证限制：** 官方 v2.5.5 Windows 文件已下载并通过 GitHub 提供的 SHA-256 校验，但本机真实握手尝试未成功。适配器已通过模拟协议与数据测试，不能据此宣称该外部服务已能直接使用。此问题留待恢复开发后排查；现阶段优先测试内置连接。

第三方服务自行管理平台登录文件，可能以 Cookie 文件保存在其目录。工作台不接管这些文件，不保证它们受到工作台保险箱保护。不同工作台用户需要各自的服务目录、端口及平台登录状态。

## 保持原有边界

- 保存排期不会无人值守自动发布；本版是单条内容确认后的自动执行。
- 抖音使用自研内置官方页面助手，并非引入了第三方抖音 OpenAPI 投稿权限。
- HTTP 错误、超时和无可核验回执不会触发自动重试。先在平台核对，再登记或解锁。
- 静态站及远程网站不能直接使用电脑上的内置 MCP；需要运行 Windows 应用或同机后端。
- 平台页面可能变化，登录验证不绕过。原有素材导出、手动发布、文本评论导入继续保留。

验证与待办见 [验证记录](PLATFORM-ASSIST-VALIDATION-1.7.0.md) 和 [开发进度](DEVELOPMENT-HANDOFF-1.7.0.md)。
