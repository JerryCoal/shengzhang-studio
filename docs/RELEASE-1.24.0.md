# v1.24.0 本地更新

- 每个平台账号可保存身份记忆，支持直接填写、选择或拖入 MD/TXT；保存的是正文，之后移动原文件不影响记忆。
- 每账号支持多套创作方案、默认方案、长期内容方向与分步骤 Skills。创作前显示实际账号、身份与方案。
- AI 策略、文案、封面、首尾帧和视频使用启动时的身份快照；切号不会改变进行中的请求。不同账号的文案与配图组合会提示先重新生成文案。
- 创作页和图片/视频生成窗口支持选择电脑文件与拖拽；参考图片、配音与直接采用成品分别提供清晰入口。
- 已有 PNG/JPG 图片及 MP4/WebM 视频可在预览确认后直接采用，无需调用模型；文件类型、大小和内容版本均有检查。
- 修复“前往发布”无说明禁用：现在可进入发布中心查看，具体列明待制作、候选图未采用、旧画面待更新等原因。
- 发布默认选择生成内容的账号，改选其他账号提示核对身份；历史恢复保留对应账号归属。
- 修复窄屏关闭侧栏后导航文字偶尔仍遮挡正文的问题。
- 原有项目、养号功能、单账号用法、本地加密数据、费用与发布确认流程继续保留。

使用方式见 [新版使用说明](UPGRADE-1.24.0.md)。网页版暂不经中转传送私人账号身份或自装 Skills，此类 AI 创作请使用 Windows 版。

本次仅本地交付，不自动上传 GitHub，也不向真实平台投稿。验证范围见 [验证记录](VALIDATION-1.24.0.md)。
