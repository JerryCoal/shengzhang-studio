# v1.13.0 验证记录

使用隔离数据、合成密钥和模拟模型接口验证；未读取真实用户密钥、平台 Cookie 或项目，未调用付费搜索或模型。

覆盖：默认公开新闻无需搜索密钥；Qwen 单次联网复用密钥、地域/业务空间、真实来源解析、费用、预算、原文读取与日期筛选；多提供商切换和密钥保留；待核实线索与旧分析保留；公开网页访问限制；UI 宽窄布局与 Windows 打包。

## 结果

- 全量自动回归：478 项通过，0 失败、0 跳过。包含 Qwen 搜索、公开网页读取、完整研究链路、隐私隔离及原有功能。
- TypeScript 与桌面前端构建通过。
- 隔离界面验证通过：10 张截图、9 项 760/1360px 布局检查，无外部请求或控制台错误。验证了 RSS 默认、Qwen 复用密钥及省去规划、动态费用、火山删除不切换服务、待核实链接、风险确认和五项选用上限。
- 真实免费新闻源：IT之家 60 条、少数派 10 条，70 条通过近七天清洗。仅说明这次来源读取成功，不等于全网覆盖或 AI 分析质量。
- 真实网页：发现本机 IPv6 连接不稳定，改为在全部 DNS 地址通过公网检查后优先 IPv4，并固定连接地址。两篇 IT之家文章均返回 200，取得正文 347 / 505 字；原站日期缺少时区，仍保留为待核实线索，没有猜测日期。
- 随后用与桌面后端一致的 `--use-env-proxy` 参数复测：70 条 RSS 仍通过清洗，两篇少数派文章取得正文及明确发布时间，原文核验成功 2 条、失败 0 条。这项验证未调用模型。
- Windows 包另验证加密保存、重启恢复、不同用户隔离、搜索方式切换保留旧密钥，以及原有两个平台内置 MCP 连接。包内保留 14 份 Skills，排除用户数据目录。
