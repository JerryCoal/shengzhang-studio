# 生长 STUDIO v1.15.0 本地测试版

本次让字号、重点阅读和外部 MCP 启动更容易操作。

- 新增「外观与阅读」：四档字号、界面与文案重点强调、即时预览、自动保存和恢复默认。
- 外观偏好按用户本地加密保存，后台 AI 运行期间仍可调整；不改变文案原文、导出素材或模型请求。
- 外部 MCP 整理为下载、启动、登录三步；手动地址收进展开区，一次完成保存与检查，并解释未启动、未连接和未登录的区别。
- 拦截误选小红书登录工具或选错平台主程序，更新抖音项目下载入口。
- 改善大字号下表单、设置标签、弹窗和后台任务面板的布局。
- 修复外观连续选择、失败重试及保存期间退出时的边界问题。
- 修复策略任务收起并结束后，再次点击生成或编辑时弹窗仍被隐藏的问题。

使用步骤见「新版功能与使用说明.md」。本轮未发布至 GitHub，未进行真实平台发布或付费模型调用；模拟验证不代表第三方服务的实时可用性。
