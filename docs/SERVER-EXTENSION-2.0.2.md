# v2.0.2 灵感对话服务边界

沿用私有 `GET/PUT /api/agent-workspace` 草稿保存（key 为 `projectId:agentId`）及现有策略生成接口，不新增任意命令、自动工具执行、自动发帖或免确认生成端点。其他 Agent 的旧协议不变。

灵感草稿可含 `conversation: {version:1,id,input,turns}`；轮次包括唯一编号、用户消息、时间、平台、账号、模型、状态及可选回复。服务端限制字段、长度、数量、账号归属，拒绝修改已提交消息或直接伪造已完成回复。

对话生成请求携带 `inspirationTurn: {conversationId,turnId}`，只认领已经在私有草稿保存的 pending 轮次。严格拒绝未知顶层字段、冲突模型参数和非空查询参数，防止旧流程选项绕过真实派发。服务器从冻结草稿重新构建上下文，不信任客户端传入历史。

私有提交回执用于一次性认领、并发防重和重启恢复；回执不重复保存整份回复。策略结果与回复同事务提交，成功后更新最新需求，失败保留旧方案。已接受请求不自动重放，未知外部完成状态要求人工核对。

历史仅同用户、项目、平台与账号可见；通用灵感不得隐式继承当前默认运营账号的身份或私人 Skills。资料/经验仍需明确选择和既有权限过滤。最新确认方案可交接到指定平台账号，不携带完整私有对话。

网页静态/relay 入口不传本轮完整私人对话协议；完整 AI 对话仅在 Windows/团队后端启用。无真实收费模型与社交平台端到端验收承诺。v2.0.1 的本地 Qwen、MCP 和发布限制继续适用。
