# v1.11.0 使用说明：从近期内容研究到文案创作

本版增加完整的近期参考工作流，保留 Windows 应用、原有项目语料、创作 Skills、词库、评论与 RSS 功能。首次建议用公开、非敏感的测试项目少量体验。

## 如何开始

1. 完整解压新版，运行 `ShengzhangStudio.exe`，登录原来的本地用户。联网研究只支持加密本地工作区及同机浏览器，不支持静态或中转网页版。
2. 打开“连接与设置 → 文字模型”，配置模型密钥。研究的查询规划沿用“评论标签与情绪”模型，分析沿用“评论复盘”模型，不需要把所有环节换成同一家服务。
3. 如需网页搜索，在“联网检索”保存**火山联网搜索的专用 API Key**。页面已提供[官方开通与密钥配置教程](https://docs.volcengine.com/docs/Networkedsearch/Networkedsearch-2?lang=zh)。它和 Seedream/Seedance 的密钥分开；保存后只显示末尾字符。默认每次网页搜索预留人民币 0.02 元，可按套餐调整，最终费用以服务商账单为准。
4. 如需小红书来源，在“账号与发布”配置外部小红书 MCP，由你完成登录并检查连接。已有内置发布助手不代表具备热点搜索能力。没有可用 MCP 时先不勾选这一来源。
5. 打开项目的“热点与灵感”，输入 1–8 个关键词，选择来源。默认使用本地关键词检索；如勾选语义检索，需要先配置 Qwen，且参考摘要与查询问题会发送至阿里云。
6. 点击“研究近七天内容”，核对弹窗中的传输范围与预算，再确认开始。等待查询规划、采集、清洗、检索、分析完成；失败时先查看来源报告。
7. 展开分析卡片的原文证据，核对日期、互动指标和应用建议。最多选择 5 项；涉及人物、品牌或作品名称的参考需逐项确认，随后点击“确认创作参考”。
8. 点击“去创作”。后续生成会带入仍有效的已选参考；在 AI 文案窗口可以继续选择已安装的文案 Skills。核对输出事实，按原流程完成敏感词检查和人工确认。

## 界面中几个容易混淆的地方

- **观察与假设不同**：观察要有原文依据，“可能的吸引点”只是待验证解释，不是流量保证。
- **未提供不同于零**：来源没有公开互动指标会显示“未提供”；约数保留原始写法。
- **新闻不等于社交热度**：RSS 仍是新闻线索，原有免费规则筛选入口折叠在页面下方。
- **本地存储不等于离线**：参考与索引在本机保存，搜索和 AI 处理需要发送必要文本至服务商；只有确认后才执行。
- **自装 Skills 的范围未扩大**：每个 AI 环节使用对应内置规则；用户安装的 Skills 仍用于文案生成，不会自动作用于所有步骤。

## 费用与恢复

每轮最多 3 次网页搜索、2 次小红书搜索及 8 条详情。网页搜索与可选 Qwen 向量请求共用每项目人民币 1 元研究实验预算；查询规划、参考分析另计原项目美元模型预算。预算记录是控制用量的估算，不是服务商账单。

“仅重新分析已保存参考”会跳过 AI 扩词和采集，重新检查资料时效再分析。适合修复模型连接或调整关键词后复用资料；仍可能产生分析及可选向量费用，不是免费重试。无可用近期资料时不会编造热点。

请求失败不会清空已有参考，已产生用量也不会撤回。进度最多自动刷新约三分钟；停止刷新不表示请求被取消，可手动刷新查看，最终响应仍会更新结果。

本轮验证未使用真实付费 API 或真实平台账号。完整边界见 [实际工作流程](RECENT-CONTENT-RESEARCH.md)，测试证据见 [验证记录](VALIDATION-1.11.0.md)。
