# 生长 STUDIO v1.4.1 飞书发布计划同步

## 新增功能

- 连接与设置新增“团队协作”：保存飞书自建应用凭证、检查表格权限、初始化标准字段。
- 发布中心新增项目同步面板：默认负责人、手动同步和显式开启的自动同步。
- 保存发布计划、修改时间、登记真实发布结果或取消后，可更新飞书对应记录。
- 记录防重复、请求快照、失败提示与有限重试；冲突需核对后决定是否采用 App 版本。
- 负责人首次填写后由团队维护，团队备注及额外列保留。示例项目和示例记录不上传。
- 新增待发布计划的时间修改入口。

首版单向同步排期字段，不包含自动生成一周排期、双向同步、素材上传或群通知。飞书同步不改变最终发布需用户确认的机制。

## 使用入口

先阅读包内《飞书发布计划接入指南》，创建团队应用和空白多维表格；再进入“连接与设置 → 团队协作”。凭证配置完成后，到真实项目的发布中心启用同步。

Windows 完整版与本机网页支持。独立联网网页版和静态版仅保留说明，不接收飞书应用密钥。

## 升级

从旧版托盘退出并停止后台，完整解压新版本后运行 `ShengzhangStudio.exe`。本机原用户、项目、素材、词库和模型密钥继续使用，无需迁移数据目录。旧 v1.4.0 包保留。
