# v2.0.0 服务端扩展边界

保留原本个人与团队后端，新增 Agent 草稿、交接、外部作品登记与任务日志 API。路由位于现有身份验证、来源检查、团队权限边界之后。

`GET/PUT /api/agent-workspace` 使用版本号避免覆盖另一窗口的同一草稿。`POST /api/projects/:id/agent-handoffs` 使用请求 UUID 幂等并固定账号。`POST /api/projects/:id/review-works` 只登记用户核对过的完整作品链接，不联网也不发布。`GET/PUT/DELETE /api/task-journal` 系列仅操作当前成员加密日志，恢复不重发外部请求。

`GET/PUT/DELETE /api/content-edit-drafts/:key` 保存当前成员尚未提交的编辑器正文，key 为项目、作品、账号三元组的 JSON 编码。后端重新校验作品归属与来源版本；更新和删除均校验草稿修订号，不能借该接口改写正式作品。团队成员即便编辑同一共享作品，其暂存仍独立；正文上游版本变更会呈现冲突，不自动应用旧草稿。

逐请求模型选择不能改变共享模型路由或使用另一用户密钥。并发按项目内资源划分，预算在共享原子事务内预留。同一内容遇到冲突操作会拒绝，其他内容仍可进行；集成设置修改保持任务期间保护。

静态/中转网页继续保留严格隐私屏蔽与单请求安全锁。完整多 Agent 私人数据包不通过独立中转；请使用 Windows 本机后端或已部署的团队工作区。

团队版不自动开放防火墙、启动系统服务或变更 DNS。飞书仍为现有多维表格排期同步，腾讯文档可以人工上传经验导出文件，未新增无授权通用云文档写入。
