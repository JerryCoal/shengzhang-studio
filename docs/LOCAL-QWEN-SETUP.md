# 本地 Qwen 接入（v2.0.1）

此入口连接你自行部署的 Qwen 文字模型，与百炼官方 Qwen 的地址、密钥和模型选择独立。工作站不会安装、启动或下载模型，也不会在失败时自动转用云 API。

## 准备与保存

1. 自行安装 Ollama 或 vLLM，并准备支持指令与 JSON 输出的本地 Qwen 权重。需要足够内存、显存和上下文容量；模型出现在列表不表示生成质量符合要求。
2. 让兼容服务只监听运行工作站的主机回环接口。Ollama 常用 `http://127.0.0.1:11434/v1`，vLLM 常用 `http://127.0.0.1:8000/v1`。工作站只接受明确的 1024–65535 端口、HTTP 和 `/v1` 路径；`localhost` 自动规范为 `127.0.0.1`，IPv6 可用 `[::1]`。不接受公网、局域网、代理路径、URL 凭据或重定向。
3. 在「模型连接 → 本地 Qwen」选择服务类型，填写 Base URL 与服务实际返回的完整模型 ID。界面的模型名称只是示例，不会触发下载。Ollama 通常不用密钥；vLLM 启用 `--api-key` 时填写对应本机服务密钥，不要填百炼密钥。
4. 勾选启用并保存。首次默认关闭；保存设置或密钥不会联系服务。可选密钥沿用当前工作区的 Windows 加密保险箱，不放入项目、普通备份或网站中转。
5. 主动点击「检查本机连接与模型」才读取 `GET /v1/models`，不会上传项目、生成内容或下载模型。列表为空或不包含所填模型 ID 会明确报错。探测通过后，在模型分工或 Agent 选择「本地 Qwen」。

生成使用非流式 `POST /v1/chat/completions`、`response_format: {type: "json_object"}` 和当前任务的输出上限。模型须返回完整 JSON 并通过工作站现有字段和证据校验；不支持 JSON、输出被截断或上下文不足时，任务失败并保留原内容。需要图像理解的任务仍应选择支持该能力的官方模型，本入口仅接文字。

## 本机与团队边界

团队版仅管理员能够保存连接和密钥、执行探测；成员选择本地 Qwen 时，调用的是团队服务主机上的模型，不是访问者自己的电脑。团队模型共享主机资源，账号归属和原有工作区权限不变。

静态网页版和网站中转不支持本地模型，也不会代理访问主机内网；本机连接设置从中转快照删除。不要为了连通而把本机服务暴露到公网。工作站不跟随 HTTP 重定向，不使用环境 HTTP 代理、不自动重试，也不执行 Ollama 拉取模型或服务管理接口。

## 费用与保密

本地模型的云 API 预算按 0 记录；这不包含机器、电力、托管和部署成本。此限制只约束工作站请求的目标地址，不能审计本地服务内部是否又调用云模型。请管理员关闭 Ollama 云端功能及其他服务的转发配置，使用本地权重；带 `cloud` 的模型 ID 会被工作站拒绝，但不能代替管理员核对部署。只有主动生成时，相关项目文本才会发送到所配置的本机模型。

水印：新设置下 Seedream 图片和官方 Seedance 视频默认请求不添加可见水印；旧设置中明确保存的 true/false 保留。工作站不额外叠加水印。第三方强制标识、原图内文字或模型生成的字样不能靠此开关保证去除；Redfox 视频接口暂无已核实的水印开关，界面会提示人工核对。

## 官方依据

- [Ollama OpenAI 兼容接口](https://docs.ollama.com/api/openai-compatibility)：`/v1/models`、`/v1/chat/completions`、JSON 输出与模型名。
- [vLLM OpenAI 兼容服务](https://docs.vllm.ai/en/latest/serving/online_serving/openai_compatible_server/)：本地部署、模型名和 API Key；其密钥并非保护服务所有管理接口，仍须限制监听范围。
- [火山方舟视频生成接口](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh&redirect=1)：Seedance watermark 开关，关闭不代表消除输入画面中已有标识。

接入边界于 2026-10-19 核对。本次验证使用模拟返回与本机临时 HTTP 服务，未请求任何真实收费模型。
