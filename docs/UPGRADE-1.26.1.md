# 生长 STUDIO 1.26.1 升级说明

本次修复热点研究中 DeepSeek 返回内容不符合结构要求的问题，并让素材列表按组、按单条默认折叠，方便先看概况再打开需要的内容。版本继续属于 Redfox 接入测试版，平台、账号、项目及服务配置沿用 1.26.0。

## 研究结果更短，失败原因更明确

热点研究会把完整的字段、文字长度和条目数量限制交给模型，通常生成 2–3 条简短分析，同话题分析每条通常提供 1–2 项建议。证据不足时允许减少条数，不要求模型凑满内容。

DeepSeek 在研究请求中关闭思考模式，让可用输出长度优先留给完整结果。这项调整只作用于研究流程，不修改其他创作任务的 DeepSeek 配置。系统不会因返回格式不合要求自动追加另一笔付费请求。

完整 JSON 外面的代码围栏、BOM 可以去除；截断或残缺的内容不会被补写成看似完整的结果。引用只有空白格式或外层引号差异时，可恢复成对应来源中的真实连续原文；来源不存在、平台不匹配或找不到原文的引用仍会被拒绝。

失败提示会区分输出截断、空内容、JSON 格式、字段要求及引用核验问题。失败后旧内容和已记录费用保留；已采集的参考仍可使用“仅重新分析已保存参考”。再次分析会重新调用文字模型并可能收费，但不会因此重新采集同一批资料。

## 素材按需展开

素材分组和单条素材默认折叠。先展开相关分组，再展开需要查看或处理的条目，可以减少长列表占用。折叠不删除素材，也不改变素材归属和历史记录。

## 更新方法

先查询正在执行的任务并导出备份，再退出旧程序。团队版使用原包的停止脚本关闭服务。将新包完整解压到新的程序目录，沿用原数据目录、登录方式和团队主机运行用户，不删除或重新创建主机密钥。

无需重填已保存的模型、Redfox 或平台连接。Redfox 仍固定使用 Seedream 5.0 Pro 生成图片、Seedance 2.0 生成视频；本次未新增模型或平台能力。Redfox 的支持范围和计费边界继续见 `REDFOX-TEST-REPORT-1.26.0.md`。

本次不宣称已经通过真实付费 DeepSeek 或 Redfox 请求验证。自动测试、界面检查及构建的实际结果统一记录在 `VALIDATION-1.26.1.md`。
