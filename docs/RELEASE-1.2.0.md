# 生长 STUDIO v1.2.0 · 手动发布与创作导出

本版将抖音与小红书发布统一为「导出 → 官方平台手动发布 → 回填作品链接」。发布不需要开放平台应用或投稿接口权限，工作台不再自动上传、投稿或按计划时间发送内容。

## 下载与升级

- [Windows x64 完整包](https://github.com/JerryCoal/shengzhang-studio/releases/download/v1.2.0/Shengzhang-Studio-1.2.0-windows-x64.zip)
- [SHA-256 校验文件](https://github.com/JerryCoal/shengzhang-studio/releases/download/v1.2.0/Shengzhang-Studio-1.2.0-windows-x64.zip.sha256)
- [升级与操作说明](https://github.com/JerryCoal/shengzhang-studio/blob/v1.2.0/docs/UPGRADE-1.2.0.md)

先在旧版托盘菜单选择「退出并停止后台任务」，完整解压新版后双击 `ShengzhangStudio.exe`。不要同时运行旧版。原工作区仍保存在 `%LOCALAPPDATA%\ShengzhangStudio`，不需要复制数据库或重新注册。

## 1. 彻底关闭自动投送

- 移除自动发布按钮、投稿授权选项和后台上传 / 创建作品的执行代码。
- 旧客户端调用自动发布接口会收到明确拒绝；联网网页版也不再接受此操作。底层抖音请求再次阻止上传和创建视频。
- 旧待投稿任务转换为手动待办，保留成品与记录。已提交或结果不明的任务显示「请先核对平台」，保留平台作品编号，避免重复发布。
- 历史已发布作品、链接与评论保留。到达计划时间、导出或打开创作中心都不会标记为已发布。
- 统一更新发布中心、设置、教学和操作说明；提供抖音、小红书官方创作中心入口。

## 2. 更清楚的导出面板

- 内容卡片和发布记录都提供「导出与发布」，可预览成品与完整文案。
- 图片可选择原格式、PNG 或高质量 JPG；实际转换像素，保持尺寸，JPG 使用白色背景，不覆盖原成品。
- 支持 ZIP 素材包、单独图片 / 视频、单独 TXT 文案，以及分别复制标题和正文。
- 文件按「标题—平台—成品版本」命名，过滤 Windows 不支持的字符。
- ZIP 中按素材、文案、发布指引分组；标题和正文分别保存，完整原文不截断；TXT 使用 UTF-8 BOM 和 Windows 换行。
- 视频保留真实的 MP4 / WebM 格式；WebM 明确提示用视频编辑器转为 MP4，绝不只改后缀假装转换。本版不内置视频转码器。
- 导出包不包含密钥、语料库、原始生成提示词或其他项目。内容已修改但未重新制作时不能导出过期成品。

## 3. 评论作为独立可选功能

评论文本导入、分类和复盘继续保留。已有接口权限的用户可选择连接抖音查询自有作品与同步一级评论，新授权不再请求 `video.create`。手动发布无需设置此连接。

个人开发者无法创建这条评论接口路线所需的移动 / 网站应用；企业认证也不保证获得接口权限。新版指引明确说明申请资格、未开通时的评论导入替代方式及真实联调尚未完成的限制。

## 验证范围

发布前检查涵盖自动发布拒绝、旧任务迁移及重启、手动登记、导出包内容和格式、浏览器本地工作区、评论同步回归、前端构建与 Windows 打包。测试使用隔离数据和模拟接口，不调用付费模型，不向真实平台发布内容。

保留 v1.1.0 的本地用户与加密存储、项目语料、新闻热点、策略、敏感词筛选、Seedream 封面与 Seedance 视频能力。外部模型仍需用户自己的可用密钥；真实抖音评论接口未完成获批应用联调。
