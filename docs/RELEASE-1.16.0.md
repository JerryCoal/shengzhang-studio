# 生长 STUDIO v1.16.0 本地测试版

热点研究扩展为小红书选题与高互动帖子发现，支持 MCP 查找、按真实互动筛选，再用 DeepSeek 分析并生成可验证的流量改进建议。

- 新增近七天、近三十天、不限时间，以及综合、点赞、收藏、评论排序和内容类型选择。
- 复用已有 DeepSeek 密钥，支持 Flash / V4 Pro；关键词直接查询 MCP，无额外扩词模型或搜索 API。
- 展示原帖、来源时间、采集快照和样本排名，未知指标与约数如实显示。
- 分析包含具体修改动作、引用来源与验证方法；选用后进入后续策略和文案生成。
- 历史帖子按照各自研究窗口验证，保留旧七天新闻流程；重新分析继续应用时间和内容类型筛选。
- 失败保留已有研究与选择，不自动重试收费请求；沿用后台任务、加密本地工作区和预算控制。

使用说明见「新版功能与使用说明.md」。本版尚未上传 GitHub。验证使用隔离模拟服务，没有调用真实账号的 MCP 或付费 DeepSeek；平台实际返回量受登录、网络和服务版本影响。
