# 升级到 2.1.0：总控与持久后台任务

本版基于本机已核对的 2.0.2 源码增量升级，保留旧平台创作、发布、复盘、素材与账号入口。新版默认导航为「总控 / 任务 / 账号 / 资料」。既有 2.0.2 安装包保留，不覆盖旧目录。

## 打开新版前

1. 在旧版核对正在生成或已提交的请求，选择托盘「退出并停止后台任务」，不要只关闭窗口。
2. 在停止所有写入进程后备份完整旧数据目录与配套用户、密钥文件；不要把它们放进 GitHub 或源码压缩包。Windows DPAPI 资料不能假定跨电脑可解密。
3. 完整解压新版到新文件夹，打开 `ShengzhangStudio.exe`。同一 Windows 用户继续使用原数据位置；不要同时让新旧程序写同一数据库。
4. 新表使用原工作区的加密密钥。升级不删除原账号、作品、素材和用量，不把旧任务检查点当成待执行指令。

## 新工作方式

- 在「总控」选择本轮账号并描述目标。AI 规划先估算、单独确认费用；也可选择不调用模型的免费规则草案。
- 草案不是执行授权。核对任务账号、模型、资料、Skills、依赖和每项额度，保存计划版本后再明确批准执行。
- 首期后台专业任务为：小红书文案与封面构思、抖音公开同话题研究、抖音脚本文案。图片/视频生成和最终发布仍使用原流程，并分别核对权限和费用。
- 在「任务」查看服务端真实活动、逐项结果、费用与固定版本。页面切换不重跑任务；修改成果另存版本，迟到结果成为候选，明确采用才交付给依赖任务。
- 任务对话仅属于该任务。AI 整理修订建议需要再次确认规划费用，产生待批准的新计划，不会凭一条消息自动重跑收费任务。
- 进展中心保留未读通知；系统提醒是否出现受 Windows 设置影响。点击通知定位到对应任务、运行和成果版本。

## 暂停、退出和恢复

暂停请求不等于服务商请求被撤销。已发送调用可能继续计费；结果未知时保留预留额度，并要求核对账单/回执，不自动重发。有已保存回执时优先保存回执，不重复生成。明确重试产生新运行，仍受任务、计划累计和项目额度限制。

个人版后台依赖本机进程；退出、关机或休眠后不能继续执行。团队版依赖部署主机。旧检查点只迁入仍存在的记录，不补造已删除历史。

## 备份与回退

「资料 → 导出含任务历史备份」包含当前成员可见业务资料与其任务、版本、事件、阅读位置，不包含登录密钥。**这是含私人业务内容的明文 JSON，请私密保管。** 它不是可执行授权或密码恢复工具。

移机恢复仅允许导入到同一归属、独立且完全空白的数据库；恢复后待执行记录暂停或待核对，原批准只作为历史，需重新建立并确认计划。开发恢复接口见开发交接；不提供覆盖现用工作区的入口。

回退 2.0.2 时停止新版所有写入，恢复升级前完整数据副本到独立位置，使用匹配密钥与旧程序。**不能让旧程序直接写已经升级的数据库。**

具体已验与未验范围见 `VALIDATION-2.1.0.md`；源码与 Release 发布状态以远端实际记录为准。
