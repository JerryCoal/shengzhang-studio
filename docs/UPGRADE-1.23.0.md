# v1.23.0 使用说明：养号图文

本次新增“养号 · 日常图文”运营目的，支持按主题、场景和自己填写的文案 Prompt 制作图文。原有新品上市与日常品牌传播项目继续使用。

## 打开新版

先从旧应用托盘选择“退出并停止后台任务”，再完整解压 `Shengzhang-Studio-1.23.0-windows-x64.zip`，运行 `ShengzhangStudio.exe`。数据继续保存在当前 Windows 用户的本地加密工作区，不需要复制旧数据库。

## 制作一篇养号图文

1. 工作台 → 新建项目 → 项目目的选择“养号 · 日常图文”。
2. 填写项目名称、养号发布主题、主要场景和文案 Prompt；可选填账号或栏目名称、受众，并上传一张 PNG、JPEG 或 WebP 场景图（最大 8MB）。
3. 选择图文渠道、截止日期和预算，点击“创建养号图文”。默认选择小红书；也支持抖音、TikTok、Instagram 图文任务。YouTube 不在图文渠道中。
4. 在内容制作中点击“生成养号文案”，确认使用已配置的文本模型。模型会读取本份任务保存的主题、场景和文案 Prompt，生成标题、正文和独立的画面要求。
5. 点击“AI 配图 · Seedream”，预览提示词、选择构图与水印选项并确认生成；检查候选图后采用。也可用“本地模板制作 · 免费”把上传场景图和文案排版为 PNG，无参考图时生成文字场景封面。
6. 核对文案与图片，点击“导出与发布”保存素材包，或前往发布中心选择匹配的平台账号。创建和生成不会自动发布。

主题、场景与 Prompt 的文字草稿自动保存。新建项目时上传的图片在当前工作区内暂存，创建成功后正式保存；刷新或退出应用前请先创建项目。已有项目的参考图修改后立即保存。每次生成图片使用请求开始时的当前参考图。

## 修改与费用

已建立的图文任务保存当时的文字要求。修改项目资料后，在“查看 / 调整养号方案”中新建并确认下一轮方案，才会产生采用新要求的内容；已有成品保留。

创建任务与本地模板免费。本地模板不执行复杂自然语言 Prompt；需要按自定义 Prompt 写作时使用“生成养号文案”。AI 文案与 Seedream 配图按服务商账户分别计费，沿用预算检查与失败保护。
