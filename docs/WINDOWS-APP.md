# Windows 完整版

当前正式版本为 **v1.0.0**。请先阅读 [v1.0.0 更新说明](UPGRADE-1.0.0.md) 和 [完整工作流程](../README.md)。文本支持 OpenAI / DeepSeek，小红书 AI 封面使用 Seedream，关键帧支持 GPT Image 2 / Seedream。无需先配置 API，可以直接开始免费练习。

从 [GitHub 正式发布页](https://github.com/JerryCoal/shengzhang-studio/releases/tag/v1.0.0) 下载并完整解压 `Shengzhang-Studio-1.0.0-windows-x64.zip`，双击文件夹里的 `ShengzhangStudio.exe`。应用已内置运行环境，不需要安装 Node.js、Python 或开发工具。

正式版整合快捷登录、项目语料库、敏感词替换、自动保存、Seedream 封面、输入辅助、热点标签和可搜索指南。完整版本历史见 README；下方为通用操作与验证范围。

## 第一次使用

1. 注册一个本地用户，牢记登录密码。
2. 按需在「连接与设置」选择 OpenAI 或 DeepSeek，保存对应密钥、检查连接并保存模型分工。
3. AI 封面配置 Seedream。AI 视频需配置 Seedance，再生成并检查 GPT Image 2 或 Seedream 首尾关键帧，确认后提交视频。
4. 抖音自动发布及评论同步需填入已审核的平台应用信息，并完成账号授权。每条发布计划都需要明确检查和启用。
5. 无 API 密钥时，项目、模板策略、本地图文和短片、素材导出、评论导入与规则复盘仍可使用。

菜单「工作台 → 在浏览器中打开」可打开连接到完整后端的本机网页。Windows 应用和这个网页共用同一批本地用户及工作区。

## 数据与后台任务

- 数据目录：`%LOCALAPPDATA%\ShengzhangStudio`。更新应用目录不会覆盖用户数据。
- 每个用户有独立的加密 SQLite 工作区。密码通过 PBKDF2-SHA256 600,000 次迭代派生密钥，并通过 HKDF 分开数据与凭证用途。数据采用 AES-256-GCM 加密。
- API 和平台凭证同时由用户密码派生的密钥与 Windows 当前账户 DPAPI 保护。不会写入浏览器持久存储、项目备份或发布包。
- 退出当前用户的最后一个会话时，停止新后台任务，等待已开始的请求收尾后清除内存中的解密密钥。再次登录会恢复可恢复任务，不会盲目重复提交付费生成或发布。
- 关闭主窗口会缩到系统托盘，后台任务继续执行。完全退出请在托盘或菜单中选择「退出并停止后台任务」。电脑关机、睡眠或退出账号时不会执行新的定时任务。
- 应用只监听本机地址。没有提供公网后端或手机远程访问；GitHub Pages 仍是独立的静态体验版。

密码无法找回。导出的 JSON 备份是明文文件，需要自行保管；当前不提供自动导入旧站点数据。原静态站点和原单工作区 `data/studio.sqlite` 均保留，不会自动迁移。

## 开发构建

`pnpm build` 生成完整前端；`node scripts/build-windows.mjs` 将后端与官方 Electron、Node 运行环境组装到 `outputs/windows/Shengzhang-Studio-1.0.0/`。打包 ZIP 使用 `node scripts/package-windows.mjs`。

官方运行组件来自 Electron v44.3.0，下载包 SHA-256 在构建脚本中校验。分发目录附带 Electron、Node 和后端依赖许可文件。开发用完整本机网页入口为 `node --use-env-proxy server/windows.mjs`，默认端口 4319。
