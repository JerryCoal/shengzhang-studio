# v1.10.0 本地测试版

- 项目语料可选择 Qwen `text-embedding-v4`，512 维向量与关键词混合检索，结果保留文档与段落出处。
- 用户主动确认才建立索引，更新时复用未变片段；最多 200 段，按每批 10 段调用。
- 策略、下期策划、普通文案接入；敏感词复核、评论统计及媒体模型流程保持原有范围。
- 界面展示数据发送范围、费用估算、启用状态、过期提醒、关闭和清除操作。
- 用户/项目隔离，本地加密保存索引；网页中转请求排除索引、授权和向量用量字段。
- 人民币检索预算独立记账，不确定调用保留估算；并发修改停止后续请求，过期结果不覆盖新资料。

本版为本地交付，未上传 GitHub，未调用真实付费模型。v1.9.0 安装包继续保留。
