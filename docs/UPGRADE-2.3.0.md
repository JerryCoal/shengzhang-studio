# 2.3.0 使用与升级

1. 退出旧版并备份项目。完整解压新的 Windows 包，运行 ShengzhangStudio.exe；保留原数据目录，不同时运行新旧程序。
2. 进入总控，在底部聊天框选择目标账号并发送需求。规划费用在小窗批准，取消后可从消息旁继续。
3. 计划出现在对话内。核对计划后，各 Agent 等待单独批准；可以改指令、选择 Skills、核对费用。
4. 执行结果持续留在对话里。“过程与依据”显示实际步骤；“在对话中修改”固定当前任务，刷新后仍保留回复对象。
5. 文案完成后发送“生成两张图片”，核对图片模型、Skills 和逐张指令，批准后逐张查看并采用。
6. 发送“发布”或点击成品旁的发布入口。先选已采用图片，再核对固定账号、文案和平台选项。没有连接时可导出并手动发布，成功后登记真实作品链接。

当前一次投稿包含一张图片和文案，多张配图不会自动拼成多图帖子或逐张投稿。图片和发布的批准互相独立。结果待核对时先查看平台或服务商回执，勿重复生成或投稿。

聊天记录、草稿、任务和成果保存在原有本地加密数据库。新版本的业务备份包含聊天记录；恢复到新工作区后不会自动执行旧任务。旧程序不能写入升级后的数据库。后台任务需要电脑与应用保持运行。
