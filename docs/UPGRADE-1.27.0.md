# 生长 STUDIO 1.27.0 升级说明

本版允许直接编辑工作站已有的默认 Skills。热点研究修复、素材折叠和账号身份记忆继续保留；Redfox 接入仍属于测试版，服务范围沿用 1.26.0。

## 编辑已有默认规则

进入「连接与设置 → AI Skills」，找到工作步骤，展开「默认规则」，点击需要修改的那一份规则旁的「编辑规则」。编辑窗口会显示当前生效正文和版本，保存后标记为「已自定义」。

正文不能为空，按 UTF-8 计算最多 24 KB。可以在窗口中查看出厂原文、下载当前草稿、取消修改，或在核对原文并确认后恢复出厂规则。取消不会改变已保存的规则；未保存草稿需要时请先下载。

每个工作步骤、每份规则分别保存。例如，只修改「小红书文案」中的一份默认规则，不会同步修改「抖音文案」中的同名规则。账号身份记忆与已选自装 Skills 继续按原设置叠加。

「联网新闻搜索」的规则用于千问联网搜索。Redfox 按关键词检索，不使用这一份规则，编辑它不会改变 Redfox 的关键词检索方式。

## 保存、生效与版本冲突

保存影响之后的新生成请求。已经运行的任务继续使用开始时取得的有效规则快照，生成记录保留对应版本，便于以后核对。

默认规则编辑与自装 Skills 共用规则版本检查。如果另一处已经修改规则，当前草稿会保留，并暂停提交。重新读取列表不会把旧草稿直接覆盖到新版本；请先下载或复制草稿，关闭后重新打开规则，核对最新内容再编辑。

## 不同版本的使用范围

Windows 个人版可编辑并实际使用定制规则，各登录用户的数据继续隔离。团队版由管理员编辑共享默认规则，其他成员可以查看；通过浏览器访问团队版时同样适用。规则随所属加密工作区保存，并随工作区备份保留。

静态体验版可以保存和管理规则，实际 AI 生成仍需完整版。独立的联网网页中转版只读默认规则；若导入的工作区在当前步骤含有定制规则，会提示并阻止该步骤生成。请使用 Windows 版或团队版继续，系统不会悄悄换回出厂规则。

## 更新方法

先处理正在执行的任务并导出备份，再退出旧程序。团队版使用原包的停止脚本关闭服务。将新包完整解压到新的程序目录，沿用原数据目录、登录方式和团队主机运行用户；保留原有主机密钥。

历史项目、平台账号、身份文件、自装 Skills 和已保存的服务连接继续使用。原本没有定制默认规则的工作区保持原有行为，无需重新导入规则或填写服务密钥。

本版全量自动测试为 859 项，857 通过、0 失败、2 项因 Python 测试环境未配置而跳过。所有构建、个人版程序包的 18 项检查及团队版程序包的 9 项检查通过。浏览器已经核对规则的保存、重开、取消、恢复出厂和空白禁用；多标签冲突、移动宽度及下载落盘尚未实测。详细结果见 `VALIDATION-1.27.0.md`。

Redfox 的支持范围与计费边界继续见 `REDFOX-TEST-REPORT-1.26.0.md`。
