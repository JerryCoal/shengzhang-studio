# v1.11.0 本地测试版：近期内容研究

把“找近期资料”接入创作流程：AI 规划查询 → 网页 / 小红书 MCP / RSS → 本地清洗 → 关键词或可选 Qwen 检索 → 证据分析 → 人工选择 → 带参考与写作 Skills 生成文案。

- 新增“热点与灵感”三步研究面板，原有 RSS 新闻筛选保留在折叠区域。
- 新增“联网检索”设置，独立保存火山联网搜索密钥，输入不回显完整密钥、不写浏览器本地存储。
- 按近七天窗口检查日期、去重、过滤禁用与争议信号；保留出处、必要摘录、日期依据、缺失及约数指标。
- 分开展示观察、假设、应用建议和原文证据；最多选用 5 项，名称风险需逐项确认。
- 支持阶段进度、来源报告、失败保留，以及“仅重新分析已保存参考”。
- 新增检索规划与参考分析的内置 Skills；用户自装 Skills 仍只在文案环节选用。
- 网页搜索默认每次预留人民币 0.02 元，可配置；搜索与研究向量请求共用每项目人民币 1 元实验预算，文字模型沿用原美元预算。实际账单以服务商为准。

仅加密本地 Windows 用户工作区及本机浏览器可运行联网研究。静态网页和中转网页版不提供此入口。外部搜索、模型与可选语义检索需要发送必要文本至服务商，本地存储不代表完全离线。

本版不宣称覆盖全网、识别真实爆款或保证增长；尚未新增抖音/TikTok 全站搜索及多次互动快照。界面验证使用模拟资料和响应，另有真实免费 RSS 70 篇清洗验证；未调用真实付费服务或平台账号。完整使用与测试范围见 [使用说明](UPGRADE-1.11.0.md)、[验证记录](VALIDATION-1.11.0.md)。

安装包、最终构建与发布位置以本次交付记录为准；本文不代表已经上传 GitHub。
