# 生长 STUDIO 1.26.0：Redfox 接入与测试说明

本版增加一个可选的 Redfox 服务入口，用于读取公开作品和评论、寻找参考资料，以及生成图片和视频。保存一份 Redfox API Key 后，可以分别开启“平台资料读取”“图片与视频生成”和“联网搜索”。原有模型、平台连接和个人数据保留。

这是完成代码和模拟接口验证的测试版本。**尚未使用真实 Redfox 密钥进行付费调用**，因此没有证明当前账号的接口权限、折扣、实时返回内容、生成质量或实际到账费用。保存密钥不会发起付费测试；界面的“已配置”表示密钥已保存，不等于所有接口已实测成功。

## 功能入口

| 想做的事 | 工作站入口 | 本版行为 |
| --- | --- | --- |
| 保存密钥、选择使用范围 | 连接与设置 → Redfox | 分别控制平台资料、图片视频和联网搜索；显示人民币估算用量 |
| 查找同话题作品 | 热点与灵感 → 同话题研究 → 资料读取服务选 Redfox | 读取所选平台的搜索结果和有限量详情，清洗后交给原有 DeepSeek 分析 |
| 查找近期网页资料 | 热点与灵感 → 近七天研究 → 联网来源 | 开启 Redfox 联网搜索后使用 Kimi 搜索；读取原网页并核对发布日期 |
| 看平台热门选题 | 热点与灵感 → Redfox 平台热榜 | 手动确认费用后读取近一天聚合榜单，可复制关键词继续研究 |
| 给图文生成画面 | 内容制作 → 图文任务 → 封面生成 | 使用 Redfox · Seedream 5.0 Pro，生成候选后由用户决定采用 |
| 从首尾帧生成视频 | 内容制作 → 视频任务 → 关键帧制作 | Seedream 5.0 Pro 生成首尾帧，再交给 Seedance 2.0 生成视频 |
| 读取作品指标 | 运营数据 → Redfox 读取指标 | 选择已发布作品，先核对预览，再保存指标快照 |
| 读取作品评论 | 评论分析 → Redfox 读取评论 | 选择已发布作品，先核对评论预览，再选择导入 |

生成继续带上原有项目事实、相关语料、账号身份和该步骤的 Skills。参考图片沿用工作站已有的本地选择、上传和拖拽入口。发送生成请求时，相关提示词、身份内容及参考图片会交给 Redfox；本机加密并不意味着云端模型可以离线完成生成。

## 哪些平台已接入

| 抖音 | 已接入 | 已接入 | 未接入：公开目录未列出对应接口 |
| 小红书 | 已接入 | 已接入 | 已接入，异步提交后查询原任务 |
| TikTok | 已接入 | 已接入 | 已接入，每次读取一页 |
| YouTube | 已接入 | 已接入 | 已接入，每次读取一页 |
| Instagram | 已接入 | 已接入 | 已接入，每次读取一页 |

“已接入”指已完成工作站适配和模拟接口测试。数据取决于供应商收录、接口开放状态和密钥权限，不保证覆盖所有作品、全部评论或每项指标。空结果不代表平台没有内容，未提供的指标不会伪装成零。评论和指标保留项目、平台、作品、账号和采集时间，导入同一预览不再次收费。

评论仅取首批或一页，最多保留 200 条，不包含回复。指标和评论入口只针对工作站已记录的真实已发布作品，不增加任意链接导入。YouTube 返回相对日期或没有时区的日期时，仅保留线索，不进入近期对比；国内来源无时区时间按北京时间解释并保留假设说明。

抖音、小红书部分接口来自收录库，存在 T+1 等更新延迟；广域库也有收录条件。官方将抖音广域、部分小红书评论及 YouTube/Instagram 接口标为“限时开放”，后续可能调整。热榜是小时级聚合数据，查询截至上一完整小时；上榜时间不是作品发布时间，各平台热度不能直接比较。

## 生成模型与任务处理

Redfox 图片路由在本版固定为 **Seedream 5.0 Pro**，视频固定为 **Seedance 2.0**。不会把用户原来选择的 GPT Image 2 名称用于展示这一新路由。官方目录虽有 GPT Image、Gemini 等生成接口，本版尚未把这些接口接入模型选择。

封面保持 3:4、1728 × 2304；关键帧保持 9:16、1440 × 2560。Pro 官方尺寸描述不完整，具体尺寸能否由当前服务接受仍待真实接口验证。水印选择会按请求提交，生成后沿用画面检查；服务商最终是否保留可见水印仍需检查成品。视频界面保留 5、8、12 秒和声音选项，提交 720p、9:16，使用首尾帧图片 URL。

图片和视频均使用异步任务。工作站先保存本地任务状态，再提交并保存上游任务编号；重启后，有编号的任务继续查询原结果。没有取得编号的中断请求显示“结果待核对”，不会自动重复生成。查询或下载失败也不自动重新提交；可以点击查询已有任务。核对服务商记录后解除锁定，再次生成会成为另一笔请求。

视频所需的本地首尾帧通过官方上传接口转换为 URL，并保存到对应帧记录。返回文件只从已核验的官方 OSS 域名下载，不将 API Key 发送到下载地址。生成期间修改文案，旧版本图片或视频作为候选保存，不覆盖新版本；切换账号也不会把异步结果记到后来选中的账号。

## 继续保留的能力与边界

- Redfox 不替代平台登录、发布授权、发布确认、桌面发布助手或 MCP。读取评论不会发送评论，也不会发私信或发布作品。
- 本版没有新增账号粉丝看板、全量历史账号作品库或自动持续监控。官方目录中存在其他账号接口，不代表本版已实现这些页面。
- Kimi 搜索回答仅作线索。只有读取到原网页正文与明确日期的资料，才可进入近七天研究证据；模型生成的回答不会冒充原文。
- Redfox 公开目录没有提供本版所需的通用多轮对话、结构化输出和工具调用替代接口。文案、策略、评论分析等继续使用原有文字模型；一份 Redfox Key 不能替代工作站全部模型密钥。
- 静态版与浏览器独立本地存储模式本版不接入 Redfox。请在 Windows 完整版或团队后端工作区使用；团队请求由主机执行，成员关闭页面不会关闭主机服务。

## 数据保存与退回原配置

个人加密工作区保存自己的 Redfox 凭证；团队版由管理员保存团队共享凭证，沿用主机密钥、Windows DPAPI 和加密保险箱。密钥不写入前端源码、业务活动记录或普通导出备份。共享团队成员可按角色使用服务，不因此获得查看完整密钥或修改密钥的权限。

Redfox 是工作区级服务凭证，平台账号是内容归属。生成使用提交时的账号身份快照；采集和导入校验原作品/账号；团队后台任务保留发起人。共用同一服务密钥不意味着把不同账号的内容和采集结果混在一起。

需要回到原服务时，先处理完已提交任务，再到 Redfox 设置关闭相应开关。原有 OpenAI、Seedream、Seedance、搜索和 MCP 配置不会被删除。关闭 Redfox 后，新请求按原配置执行；有上游编号的旧任务仍应先查询、核对，不能当作未提交再次生成。

升级前通过工作站导出备份；团队主机另按部署文档备份完整数据目录及恢复所需密钥环境。团队数据仍默认保存在 `%LOCALAPPDATA%\ShengzhangStudioTeam`，个人数据仍为 `%LOCALAPPDATA%\ShengzhangStudio`。本版不会自动迁移、合并个人与团队数据，不修改防火墙、DNS 或开机启动。
