# 生长 STUDIO v1.3.3 · 网页评论辅助采集

Windows 版新增抖音、小红书的网页评论读取。打开自己已发布的作品，登录并展开评论，再读取、核对和导入，减少逐条复制的操作。采集本身不调用付费模型；后续选择 AI 分类或分析时仍按模型用量计费。

## 使用步骤

1. 在「发布中心」确认作品已发布，填写正确的作品链接。
2. 打开「评论与复盘」→「导入评论」→「网页辅助采集」，选择关联作品。
3. 点击「打开作品并采集」。平台网页会在独立窗口中打开；需要登录或验证码时，由你在官方页面完成。
4. 展开评论。更多内容需要你自行滚动、展开回复。顶部菜单「评论采集」→「读取已加载评论并返回」可读取当前已加载的文字。
5. 评论较多时，先选「暂存已加载评论，继续查看」，展开更多后再次暂存，最后选「完成并返回工作台」。单批最多 1,000 条、12 万字符；单条最多 4,000 字符。
6. 回到预览后勾选需要导入的评论。默认只勾选一级评论；「全选（含回复）」可包含作者和读者的回复。核对作品归属，勾选确认框，再点击「导入所选评论」。
7. 继续使用原有分类、人工校正、分析评论和品牌经验流程。

抖音的个人主页弹窗链接会转换为同一作品的独立详情页。若短链接停留在推荐流或主页，可用菜单「打开独立作品页（抖音）」后再读取。

## 读取内容和局限

- 只读取已加载的网页评论，不代表作品的全部评论。页面显示的总评论数可能包含尚未展开的回复。
- 保存评论原文、可识别的评论 ID、页面显示的日期、整数点赞数及回复标记。无法确定的数字不推算，缺少年份的日期不补年份。
- Unicode Emoji 和有文字标签的平台表情按原位置保留。评论图片不做文字识别；纯图片评论可能跳过。
- 昵称、头像、IP 属地、登录密码和 Cookie 不进入评论库。评论原文中自行提及的个人信息仍属于原文，请在导入前自行核对。
- 相同作品优先按评论 ID 去重；没有 ID 时按规范化文本去重。不同 ID 的同文评论保留；纯文本导入无法区分不同用户说的同一句话，可能合并。
- 重复采集不覆盖原始评论、人工分类和无关标记；已知点赞数可以更新。
- 页面切换到其他作品时会拒绝读取。短链接需在官方页面解析出作品详情，并由用户核对归属；程序不验证账号所有权。
- 网页布局或登录策略改变时可能读不到。可在页面选中评论文字，用「读取选中的文字并返回（备用）」逐行预览；请排除昵称、日期、按钮等混入内容。原有 TXT / MD 和粘贴导入继续可用。

## 登录与保存

平台网页使用独立临时会话，不复用工作台登录和 API 密钥。工作台不读取平台密码或 Cookie；关闭采集窗口后清除该临时会话，下次可能需要重新登录。平台登录请求由平台页面处理。

评论在点击确认导入后，进入当前用户的本地工作区，与原有数据一同加密保存。平台网页本身仍需联网。网页版不能直接读取另一网站的页面，因此该采集窗口仅适用于 Windows 应用；网页版继续提供粘贴 / 文件导入。

已有抖音开放平台评论权限的用户仍可使用原有官方同步；网页辅助采集不要求填写开放平台 Client Secret。两平台的发布仍完全手动，不恢复自动投稿、回复或投放。

## 本次验证范围

2026-10-07 使用用户提供的两条公开作品链接检查实际网页：小红书当前加载到 14 条文字评论（含 5 条回复），另有 1 条无文字记录；抖音读取到 3 条一级评论及 1 条回复，表情、点赞与页面日期均能区分。该结果说明这两个页面可用，不代表对所有作品或登录状态的完整抓取保证。

新增检查覆盖来源校验、批次校验、去重、原文和人工分类保留、表情、临时窗口隔离、取消采集与切换作品。本版同时包含更新后的小红书文案 Skill，以及原有手动发布、封面、词库、语料库和语义替换功能。

## 更新安装

从系统托盘完全退出旧版本，完整解压 `Shengzhang-Studio-1.3.3-windows-x64.zip` 后打开 `ShengzhangStudio.exe`。数据继续保存在 `%LOCALAPPDATA%\ShengzhangStudio`，不需要复制旧版程序文件。建议先在设置中导出备份。此包暂未上传 GitHub。
