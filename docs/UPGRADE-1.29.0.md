# 升级与使用 1.29.0

1. 关闭旧版本，在新解压目录启动 ShengzhangStudio.exe；保留旧目录以便回退。使用原本的工作区用户名和密码登录。升级前建议从数据与费用导出备份。
2. 在项目与账号中维护长期资料和账号身份。新建内容只需账号、图文或视频、本次需求。
3. 有想法可直接在内容页新建；需要参考时到选题与资料。用来创作会先保存参考，再带到草稿。
4. 每篇内容有需求、文案、图片或视频、发布核对四个区域。生成、上传、评分等工具在对应区域打开。
5. 待发布内容进入发布核对；已有计划从发布记录继续。发布后从同一记录进入复盘。
6. 在已保存资料或复盘中维护经验。账号专属经验仅用于该账号，项目共享资料可以复用；停用和过期资料不再自动引用。

旧养号项目、策略、成品和发布记录保留，不强制转换、不批量重写。新项目资料编辑器默认收起详细字段，旧养号输入仍可在历史版本创作要求中查看。

本次登录内未提交的新内容输入与未保存编辑可以继续；退出登录或刷新前请保存正式草稿。费用及实际发布仍按原确认范围执行。

团队版沿用现有部署方式与数据目录。不要把运行中的 data、private、profiles 或主密钥复制进公开发布包。服务器扩展说明见 SERVER-EXTENSION-1.29.0.md。
