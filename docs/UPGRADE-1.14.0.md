# v1.14.0：收起等待窗口，继续处理其他项目

策略、下期策划、AI 文案、敏感词处理候选、评论分类与复盘，以及热点研究、Qwen 语义索引和语料查询，现在可以在应用内后台处理。

## 怎么使用

1. 按原流程确认内容与费用，开始处理。
2. 在处理中的弹窗点击“收起窗口”、右上角 X，或按 Escape。请求会继续执行，收起不代表取消，也不会退回已发生的费用。
3. 切换到其他项目继续编辑；Windows 版也可以启动其他项目的任务。正在处理的项目会暂时锁定相关修改与重复提交，避免改动生成依据。
4. 从右上角“后台任务”返回原项目查看结果或错误详情。任务完成不会自动切换页面。

敏感词处理等候选结果仍需人工核对，点击采用后，再保存编辑内容；完成任务不等于已经采用或保存候选。

## 运行期间

- 文字后台任务进行时，连接设置和退出用户暂时不可操作，完成后恢复。
- 请保持应用运行。Windows 版关闭主窗口仍会缩到托盘，应用继续运行。
- 菜单中的“退出并停止后台任务”、刷新页面或进程结束可能打断请求，并丢失尚未采用、仅保留在当前页面内存中的候选。此版本不承诺重启后恢复这些任务或候选；结果不明时先核对记录和服务商账单，不要立即重复提交。
- 封面、关键帧和视频沿用原有后台生成机制，请在对应素材卡查看状态和结果；本次新增任务列表没有统一追踪这些媒体任务。
- 联网网页版仍一次只允许一个联网请求；等待时可以切换页面、编辑其他项目的本地内容。不同项目同时执行 AI 任务仅适用于 Windows 版。

## 更新应用

先等旧版任务完成，核对并保存需要保留的结果，再从旧应用菜单选择“退出并停止后台任务”。完整解压 v1.14.0 后运行 `ShengzhangStudio.exe`，不要只替换单个 EXE。沿用原本的本地用户数据，无需删除或重建工作区。
