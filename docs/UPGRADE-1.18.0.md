# v1.18.0 使用说明

本次为 Windows 本地测试版，升级前从旧版托盘选择“退出并停止后台任务”，完整解压新版后打开 ShengzhangStudio.exe。同一 Windows 用户与本地工作站账号继续读取原有数据。

## 让文档真正帮助创作

1. 打开项目的“语料库”，导入文件或粘贴内容，选择用途：产品事实、活动安排、品牌规范、文风样本。旧语料默认作为产品事实，不需要重新导入。
2. 在“项目资料卡”选择本次需要的文档，点击“提炼项目资料”，确认后发送给当前“宣传策略”配置的模型。每次最多 8 份、合计 24,000 字符；超过时请拆分资料，不会只读开头却称已读全文。
3. 逐项打开“核对原文出处”，检查价格、条件、适用范围和事实含义，勾选可信条目后采纳。原文匹配不等于语义必然正确，不能省去核对。
4. 生成并确认一版新策略，再进入内容工作室生成文案。旧策略保持原有资料快照；新采纳内容不会偷偷改变已确认的历史。
5. 修改、停用或删除来源文档后，旧资料卡停止用于新策略，需要重新提炼和采纳。原文、历史策略和已生成内容仍保留。

文风样本只帮助表达，不进入产品事实检索，也不把别人的价格、功效、经历当作你们的事实。只有明确采纳的表达习惯对应样本才会用于后续策略；每次最多 3 份、各 1,200 字符节选。

## 降低文案的机械感

普通小红书与抖音文案已默认加入自然表达润色：减少空泛宣传、重复结构和生硬口语，保留品牌名、价格、条件和已确认事实。不需要单独安装或再按一个按钮。

润色包含在原来的一次生成中，不额外发起模型调用，但规则文本会占用输入 token。文档提炼是单独的主动操作，按当前模型和项目预算记录费用。效果仍需真实资料和模型输出核对，不保证流量或平台审核。

自装 Skills、固定敏感词替换、价格语义识别与改写后复检继续保留。

## 可选的复杂文档解析

原有 TXT、Markdown、Word、文字版 PDF 简单提取仍可使用。复杂表格、幻灯片或扫描 PDF 可以配置 Docling 本机增强解析；它是独立组件，不把大型模型强塞进安装包。安装流程、文件限制和模型准备见包内 Docling 指南。

增强解析在本机运行，不消耗 AI API 额度。提炼资料卡或生成文案时，选中的文字会按界面说明发送给你配置的模型服务。不要把“本机解析”理解为后续模型调用也完全离线。

## 小红书多个账号和登录保存

1. 在“连接与设置 → 账号与发布”打开外部小红书 MCP，给现有默认账号起一个易辨认的名称。
2. 为另一个小红书账号新增独立连接；分别选择已解压的 MCP 主程序、启动、检查连接和扫码登录。账号目录与端口独立，可同时保持服务运行。
3. 扫码后检查连接，并确认本机登录资料已保存。重启工作站后选择对应账号，点击重启已保存的服务，再检查登录状态；无需每次重新选程序。
4. 发布或评论采集前核对弹窗显示的账号。设置切换后，旧发布窗口会要求重新核对，防止投错账号。

原默认账号的登录目录原位保留。连接密钥仍由本地加密工作区保存；外部 MCP 的登录文件由上游服务管理，并通过 Windows 当前用户目录权限保护，不混入公共安装包。

账号名称是本地备注，不能证明扫码人身份。独立运行多个不同账号不代表同一个小红书账号可在多个网页端同时登录；平台过期、风控或别处登录造成失效时仍需重新扫码。此版多账号和登录保存针对外部 MCP；内置页面助手不共用外部 MCP 登录。

## 使用范围

本次新资料卡、Docling 与 MCP 服务管理主要用于 Windows 本机完整版。静态网站不能运行本地后台组件；联网网页不会自动上传新资料卡、文风快照或原始解析结构。本版不会自动部署服务器，也不会自动发布内容。

规则来源与开源许可见 [第三方 Skills 说明](THIRD-PARTY-SKILLS.md)，验证结果见 [验证记录](VALIDATION-1.18.0.md)。
