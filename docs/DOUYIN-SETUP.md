# 抖音自动发布与评论同步接入指南

适用：生长 STUDIO v1.1.0。官方文档核对日期：2026-10-03。

## 先了解需要准备什么

普通抖音账号负责发布作品；抖音开放平台应用负责提供接口权限。只有普通账号和密码，不能直接获得后台发布或评论接口。本版本使用用户或机构自己的开放平台应用，不把开发者的公共 Client Secret 放进安装包供所有人共用。

需要准备：通过平台审核的适用应用、实际开通的接口权限、符合平台配置的回调地址、将要发布内容的抖音账号。应用准入条件、权限申请入口和是否支持当前主体，以开放平台实时控制台为准；文档中存在接口不等于每个新应用都能申请到。

## 第一步：创建并审核应用

打开 [抖音开放平台控制台](https://developer.open-douyin.com/console)，注册开发者，按自己的真实主体完成认证，在移动 / 网站应用中创建适用应用并提交平台需要的资料。不要使用小程序专用凭证替代移动 / 网站应用凭证。

在应用详情中核对权限：

| 用途 | Scope | 必要程度 |
| --- | --- | --- |
| 上传和创建视频 | `video.create` | 自动投稿需要 |
| 查询自己作品与公开状态 | `video.data` | 确认投稿结果、核对关联作品需要 |
| 获取自己公开作品的一级评论 | `item.comment` | 评论同步需要 |
| 在工作台读取作品列表供选择 | `video.list` | 可选；没有时仍可填写已知平台 item_id |

找不到权限或平台拒绝申请时，先通过平台支持渠道核对；工作台无法替你审批。也可以只连接已经开通的能力，例如“仅发布”或“仅关联作品与读取评论”。

## 第二步：登记回调，填写凭证

在开放平台应用的开发设置中登记授权回调域名 / 地址，再到工作台“连接与设置 → 抖音发布与评论”，填写 Client Key、Client Secret 和对应的完整回调地址。

Client Secret 是应用密钥，不是抖音登录密码。回调必须属于你管理且已经在平台配置的应用；不要填写随便找来的网址。地址不带额外查询参数和 `#` 片段。平台若不允许 localhost，必须使用可登记的 HTTPS 地址。桌面版本地服务的端口可能在重启后改变，不应把临时端口当成固定公网回调。

桌面版在内置授权窗口中接收到精确匹配的回调后，将授权码交给本地后台换取令牌，无须你再手工复制；这不会绕过平台对回调地址的校验。网页版使用设置中给出的当前网站回调地址，保持原工作区打开。

## 第三步：在工作台连接账号

1. 保存应用凭证，选择“发布视频与读取评论”“仅发布视频”或“仅关联作品与读取评论”。
2. 需要从列表选择已有作品时，先确认已开通 `video.list`，再勾选“同时授权作品列表”。
3. 点击对应账号的“连接抖音账号”。Windows 版优先打开应用内的官方授权窗口，按抖音页面提供的扫码等方式登录并确认授权。请核对实际登录账号；工作台里的账号名称只是本地标签。
4. 应用内登录失败时，点击“改用浏览器登录抖音”。完成授权后，复制浏览器地址栏的完整回调网址，在工作台“浏览器授权后，手动完成连接”中粘贴并提交。一次性授权请求在工作台最多保留 15 分钟；抖音授权码还受平台自身有效期限制。
5. 检查“可自动投稿”“可同步评论”是否齐备。只拿到部分权限时，仅使用已获准的功能；重新授权会暂停旧的待发布计划，需要重新检查。

密码和验证码只在抖音官方页面输入。授权码不写入项目备份；应用密钥和令牌在桌面本地后台的当前用户凭证库加密保存。内置授权窗口使用临时会话，不具备 Node 或工作台的桌面操作桥接，关闭后清理该授权会话。它不替你记住抖音密码。

## 第四步：自动发布一条视频

制作并保存完成的视频 → 发布中心 → 选择账号和时间加入计划 → 点击“启用抖音自动发布”。在弹窗中检查视频、投稿文案、实际账号和时间；可勾选“公开发布后自动获取这条作品的评论”，并选择 5、15、30 或 60 分钟间隔。

逐条确认后才会安排任务。到时先上传，再提交作品，然后查询平台状态。工作台会区分“正在上传”“正在创建作品”“已投稿、等待审核”“已发布、平台确认”。提交成功不代表已经公开；如果网络在创建作品时中断且结果不明，系统不会自动重复投稿，应先在抖音核对。

当前自动投稿界面支持已完成的视频和最多 55 字的投稿文案，不包含图文直发、楼中楼互动、自动回复或复杂锚点挂载。小红书原有手动素材发布流程保留。

## 第五步：自动获取评论

在发布确认时选择了自动评论同步，平台确认作品公开后会开始采集。也可以到“评论与复盘”按作品开启或暂停同步、修改间隔或立即同步。

已经在抖音发布的作品，可在发布记录中点击“关联已有抖音作品”：有 `video.list` 权限时，读取授权账号的作品并选择；没有时填入开放平台返回的完整 `item_id`。不要把分享链接中的数字直接当成加密 `item_id`。关联时再次查询账号下的公开作品，避免把别人的内容关联进来；已关联的不同作品不能直接替换，以免混合评论。

每页请求 20 条，单轮最多 10 页、200 条，更多内容保留游标在后续检查中续采。完成后从首页重新扫描，按作品和评论 ID 去重，保留原文、发表时间、点赞数与来源；更新互动数据不会覆盖人工分类、无关标记或已有原文。只采集官方接口可见的一级评论，不采集楼中楼回复，也不把本轮未返回的评论认定为已删除。

页面显示本轮新增、更新数量、最近同步时间和错误。权限失效或多次失败时会暂停自动采集；已获得的评论保留。恢复权限后可以重新启用。评论可接着用于已有的分类、分析、采用经验和下期策划流程。

## 运行与排查

- 桌面版：保持工作区已登录、电脑唤醒且联网。关闭主窗口可继续在托盘运行；退出登录、完全退出程序或关机会停止任务。错过计划时间后重新启动，会检查尚未执行的已确认任务。
- 网页版：需要可用的联网后端，原工作区页面保持打开。纯 GitHub Pages 静态站不能单独运行这些后台接口。
- “重定向地址非法”：核对 Client Key 所属应用和注册地址，尤其是协议、域名、端口和路径。
- “没有权限”：申请接口权限后还需要重新做用户授权；普通抖音登录不会替应用开通接口。
- “没有评论 / 没有作品”：核对授权账号、公开状态、审核状态和完整 item_id。列表接口查询范围以平台为准。
- “发布结果待核对”：先到抖音检查，不要反复点发布。已取得作品编号时可查询状态；必要时关联已存在的作品。
- 不再使用：关闭自动同步或停止尚未开始的投稿；在设置删除本机凭证，并按需要到抖音账号与安全的授权管理中撤销平台授权。
