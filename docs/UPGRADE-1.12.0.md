# v1.12.0：Qwen 接入修复与平台连接引导

更新前请在旧应用菜单选择“工作台 → 退出并停止后台任务”。点窗口关闭按钮只会缩到托盘，可能继续打开旧版本。完整解压新版后运行 ShengzhangStudio.exe，登录原来的本地用户。安装包与本地数据分开，原项目和密钥保留。

## Qwen：先保存，再验证

1. 进入“连接与设置 → 文字模型”，选择 Qwen。
2. 在百炼控制台 API Key 页面创建密钥，选择相同地域。不要填写 AccessKey ID / Secret、Coding Plan 或 Token Plan 专用密钥。
3. 粘贴完整 API Key，点击“加密保存到本机”。现在不强制密钥以 sk- 开头，支持较长密钥，并处理复制时带入的外围空白、Bearer 前缀和配对引号。
4. 点击“检查连接”。保存只检查格式，连接检查才请求官方模型列表；两者都不发起付费生成。检查通过不代表余额足够。
5. 点击“文字任务使用 Qwen 分工”，再“保存模型分工”。各 AI 环节才会按此调用。

地域与业务空间设置只允许官方阿里云地址。Qwen 语义检索的模型、预算暂按北京地域核验，其他地域使用本地关键词检索，不会把其他地域密钥误发往北京。

## 推荐起步：应用自带页面助手

1. “账号与发布”中选择“应用自带页面助手”，保存后点击“检查服务连接”。
2. 如失败，点击“修复内置连接”。仍失败时从托盘完全退出，确认已完整解压新版，再打开。
3. 点击“打开官方登录窗口”。在小红书或抖音官方页面自行登录，完成后关闭该窗口。窗口关闭本身不表示登录已验证。
4. 发布中心可查看内容并确认投送；评论与复盘中，先登记自己作品的真实发布链接，读取可见评论、核对预览后导入。

内置助手不需要模型 API Key、不需要单独安装 MCP。登录状态在当前桌面会话内按本地用户隔离；退出用户或应用后需重新登录平台。本机 MCP 请求直接连接，不经过系统代理。

## 外部 MCP：先下载并启动，再连接平台

| 平台 | 适配项目 | 默认地址 | 本次支持范围 |
|---|---|---|---|
| 小红书 | xpzouying/xiaohongshu-mcp，接口按 v2.5.5 核对 | http://127.0.0.1:18060/mcp | 登录、图文/视频发布、评论、近期内容检索 |
| 抖音 | panwenda/douyin-publish-mcp，接口按 v0.3.6 核对 | http://127.0.0.1:18080/mcp | 登录、图文/视频发布；上游未注册评论工具 |

1. 从页面链接下载对应项目的 Windows 主程序。外部项目独立维护，不包含在工作站安装包内。
2. 在设置中选择外部服务，点击“选择程序并启动”，选中刚下载并解压的 .exe。工作站按正确 HTTP 参数启动，自动保存本机地址与随机访问令牌。取消文件选择不会更改连接。
3. 首次运行可能需要下载驱动或浏览器，进程启动不代表服务已经就绪。连接未完成时稍候再点“检查服务连接”。
4. 完成该外部服务自己的扫码登录，并点击“检查平台登录状态”。它不会共享内置助手的登录。
5. 抖音外部 MCP 没有评论工具。需要评论时明确切回自带页面助手，再采集自有作品。

抖音 v0.3.6 Windows 程序发布在作者的 Gitee Releases，GitHub 仓库用于查看源码。默认直接双击程序是 stdio 模式，不能当 HTTP 服务器连接；工作站启动按钮会传入 --http 等固定参数。已有服务也可手工启动后填写地址。

工作站只停止它自己为当前用户启动的服务，不按端口或程序名结束其他进程。端口被其他服务占用时，请先检查已运行服务。退出工作台用户或应用会停止受管理的服务。

外部平台登录资料由社区服务自行保存在独立本机目录，不属于工作站的加密 API 密钥保险箱。请只选择你从对应项目下载、确认信任的程序。不要把 Cookie、平台密码或模型 Key 填进 MCP 访问令牌框。

## 故障提示对应的下一步

- **保存时提示输入格式不正确**：检查是否复制了完整 API Key，是否误填 AccessKey、网址或打码文本；这时尚未请求模型。
- **Qwen 鉴权未通过**：核对密钥对应的地域、业务空间和密钥类型；不要仅反复重建密钥。
- **MCP 地址没有服务运行**：启动对应程序；填写地址不会自动安装。内置模式可以修复连接。
- **服务响应但工具不兼容**：核对平台、仓库及版本，尤其不要把 18060 小红书地址填到抖音。
- **服务已连接但无法操作**：继续平台登录，检查浏览器依赖；服务连接与登录是两步。
- **发布连接中断**：先核对官方作品列表。程序保留尝试记录，不自动重发。

## 验证范围

本版使用隔离数据验证密钥保存、用户隔离、代理绕过、服务启动/停止、接口契约和界面。没有使用用户真实密钥，也没有进行真实账号发布。实际平台登录、验证码和页面变化仍需用户在官方窗口完成核对。

参考：[阿里云接入域名](https://help.aliyun.com/zh/model-studio/base-url)、[小红书 MCP](https://github.com/xpzouying/xiaohongshu-mcp)、[抖音 MCP](https://github.com/panwenda/douyin-publish-mcp)。本版通过接口适配接入外部服务，未把第三方服务源码或二进制嵌入安装包。
