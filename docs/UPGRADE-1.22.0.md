# v1.22.0 使用说明：清爽协作界面

本版按照选定的飞书风格整理工作站界面：浅色背景、蓝色重点操作、清晰分组与更紧凑的工作内容区。保留原有功能与本地存储，不需要迁移数据。

## 如何升级

1. 在旧版系统托盘菜单选择“退出并停止后台任务”。
2. 完整解压 `Shengzhang-Studio-1.22.0-windows-x64.zip`，双击 `ShengzhangStudio.exe`。
3. 使用原来的本地用户登录。项目、平台账号标识、语料、词库和模型配置沿用原数据。

同一 Windows 账户下的数据仍在 `%LOCALAPPDATA%\ShengzhangStudio`。不要删除数据目录，也不需要把它复制进新版本文件夹。旧版安装包可以保留。

## 新界面在哪里用

- **左侧分组导航**：按工作流程查找功能；“平台账号”可直接进入账号与发布设置。
- **工作台**：优先展示可处理的任务与项目，减少装饰内容占据的高度。
- **连接与设置**：桌面侧栏按“创作能力、账号与协作、工作区”分类；窗口较窄时，在“设置分类”下拉菜单切换。
- **API 与模型**：配置密钥和分配模型保持原流程，布局根据可用宽度自动调整。
- **AI Skills**：每个步骤的默认规则、已选规则和导入入口按行展示。导入与选择方式沿用 v1.21.0，切换设置分类不会丢弃未保存表单。
- **外观与阅读**：仍可调整字号和重点加重，放大文字后内容会换行。

## 保留的使用边界

本版只调整界面，不新增付费服务或自动发布权限。实际发布继续核对账号并确认；各平台 MCP 是否可用取决于服务启动、登录及实际提供的工具。

Windows 版继续按工作站用户保存本地资料和密钥。网页版仍按原方式在本地保存数据，不会因换肤获得跨设备同步。网页自装 Skills 仍保持不外传的现有边界；使用默认规则可继续生成，选中自装规则时需按页面提示切换或使用 Windows 版。

本地升级包未上传 GitHub。实际验证范围见 [验证记录](VALIDATION-1.22.0.md)，Skills 详细操作见 [v1.21.0 使用说明](UPGRADE-1.21.0.md)。
