日期：2026-10-10 初验，2026-10-13 发布前复核。性质：测试版；没有真实账号最终发布验证。

## 通过的验证

- 发布前全套回归：211 项全部通过，包含 Python 对照，无失败或跳过。
- 新增平台工作流测试：10 项通过。覆盖指标范围、零与缺失值、父子评论与时间、本地接口、结果不明防重试、错配回执、登录隔离与退出期间竞态。
- TypeScript 与前端生产构建通过。
- 独立 Electron 离线集成：小红书、抖音模拟编辑器分别通过真实文件输入、中文 / Emoji / 平台表情填写、保留已有草稿、取消确认零提交、确认后单次提交与回执保存。
- 面板在常规宽度与 760px 宽度检查，无横向溢出；远端页面未获得本地工具栏接口，测试暂存文件已清理。

离线报告：`test-results/creator160-native/result.json`。自动化测试：`tests/platform-workflow.test.mjs`，现有评论与发布测试继续保留。

## 不能由这些测试证明的事项

- 没有对两个平台当前真实账号做最终投稿，不能据此宣称真实线上全流程已验收。
- 模拟编辑器验证原生浏览器事件与桥接逻辑，不覆盖平台所有编辑器变体、审核规则、上传失败、验证码或风控。
- 作品指标只取当前作品的官方页面响应，缺失值留空；没有完整创作者数据后台或全量评论保证。
- 登录复用仅在同一次工作台会话内，退出应用不保留平台登录；没有导入外部浏览器 Cookie。

## 真实账号验收顺序

先用自有已发布作品测试评论和指标；随后用一条自有测试素材验证上传与文案填写。最终提交需用户核对内容、账号、可见范围并亲自确认。先检查平台回执和作品状态，再登记发布结果；状态不确定时不能直接重发。
