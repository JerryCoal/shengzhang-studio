# 生长 STUDIO v1.5.0 本地测试版

## 这次更新

- 发布中心增加成品、待办、已发布概况卡，以及运营数据入口；飞书同步功能保留。
- 评论与复盘改为清晰的分析工作流：导入去重、本地初筛、AI 语义分类、人工核对、复盘采用。
- 新增分类理由、原文片段高亮、待核对队列和人工核对备注。
- 复盘使用当前筛选范围，可回看不同时间生成的结果；支持导出当前范围的分类报告。
- 新增“运营数据”页面，支持作品指标手工记录、修正、汇总与导出，保留采集时间和未知值。
- 数据接入规划区明确区分已可用、手工录入、待接入和待定义能力。

## 建议测试顺序

1. 完整退出旧版，解压新包，运行 ShengzhangStudio.exe。原有本机数据继续使用，旧包保留。
2. 打开一个已有发布记录的项目，在“评论与复盘”导入评论。
3. 检查自动生成的主题和理由。试输入“多少钱”“价格不贵”“好用但是会闪退”，查看它们是否需要核对。
4. 使用“待核对”筛选，打开一条评论，修改主题、情绪或备注并保存；确认它离开待核对队列。
5. 选择一条作品或时间范围，点击本地规则复盘，核对样本数量与引用原文，再采用一条建议。
6. 配置模型后可选 AI 语义分类（每批最多 30 条，长评论时更少）或 AI 复盘（每次 1–200 条有效评论）。每次调用前确认模型和费用，结果应人工检查。
7. 打开“运营数据 → 记录作品数据”，填写平台实际显示的累计数据；未知项留空。
8. 再记录同一作品的另一个时间点，检查总览只使用最新快照；“采集记录”保留两个时间点。需要改错时使用“修正”。

示例项目与真实项目应区分，运营数据默认排除示例。静态版可用本地分类、人工核对和手工数据台账，AI 需要可用的完整版或联网服务。

## 解释与限制

AI 分类有理由和引用，但并不保证语义判断正确；本地规则只做初筛。历史人工分类继续保留，旧记录没有理由时不会伪造理由。

本版没有自动采集平台播放、收藏和成交数据，没有虚构转化率或收益预测。最新快照汇总不等于同一周期的增长。真实平台指标口径和后续接入路径需进一步验证。

调研与技术设计见《评论工作流与运营数据调研》。版本目前仅本地打包，不代表 GitHub 已发布。
