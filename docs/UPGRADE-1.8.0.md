# v1.8.0 · 创作 Skills 本地测试版

更新日期：2026-10-14。保留 v1.7.1 的 Windows 应用、MCP 连接、评论导入及原有工作流程。

## 怎么使用

1. 进入「连接与设置 → 文案与词库 → 创作 Skills」。展开内置规则即可阅读平台默认的宣传文案规范；不用安装也会生效。
2. 点击「下载模板」，填写自己的受众表达、语气和行文结构。也可直接粘贴 UTF-8 Markdown；每份最多 24 KB，最多安装 30 份。
3. 点击「安装 Skills → 预览安装内容 → 确认安装并启用」。安装的是文本规则，外部引用文件、代码和工具不会安装或执行。
4. 在 Windows 版「内容制作 → AI 文案」弹窗中，选择本次写作规则并填写修改要求，再开始生成。内置规则始终保留；选装规则补充风格，不能改写已确认产品事实或关闭复检。
5. 生成后核对文案及敏感词检查。编辑/预览窗口的「上次 AI 写作规则」可以查看当时版本和原文。停用或删除 Skills 不会改动已有内容；人工编辑后的文案可能与原始规则不同。

本轮只在普通「AI 文案」中提供选装项；策略、评论分析、敏感词专用改写、价格语义识别继续使用各自规则。内置规则参考开源营销与小红书项目的设计思路后独立编写，详见 [来源与许可](CREATIVE-SKILLS-SOURCES.md)。社区关注度不代表已验证的增长效果。

## 数据和模型调用

- Skills 随当前用户工作区加密保存在本地；不同用户隔离。安装、预览、启停不调用模型。
- Windows 版生成时，会把本次选中的规则正文和必要项目资料发送给当前配置的文字模型。其余已安装规则不发送；API 密钥仍由原有本地保险箱保存。
- 联网网页版本轮仅使用内置规则；可以在本地管理自装 Skills，但暂不向远程后端传输。界面会明确此限制。
- 现有静态网页仍需完整后端才能执行 AI 功能，安装规则不会为静态页面自动增加后端。
- 生成期间若选中规则被停用或删除，结果不会覆盖当前稿件；已经发生的模型请求仍按返回用量记录。

## 近期爆款参考库

本版交付 [调研与开发方案](RECENT-CONTENT-RESEARCH.md)，尚未新增跨平台爆款搜索。建议先做“近七天高互动内容参考库”：检索与采集 → 本地时间复核/去重/指标整理 → 参考库检索 → AI 分析证据与爆点假设 → 用户挑选 → 结合 Skills 创作并复检。

已有新闻关键词相关度不能当作平台互动热度；阅读、点赞、评论等缺失指标不能补零或由 AI 编造。

## 升级

先从旧版托盘选择「退出并停止后台任务」，完整解压新文件夹，再运行 `ShengzhangStudio.exe`。沿用同一 Windows 用户和本地登录账号，数据继续保存在 `%LOCALAPPDATA%\ShengzhangStudio`。保留旧安装包，更新不会覆盖它。

本轮未重新执行真实平台发布，也未用付费 API 测试写作效果。原有小红书 MCP 真实评论验证见 [v1.7.1 验证记录](PLATFORM-ASSIST-VALIDATION-1.7.1.md)。
