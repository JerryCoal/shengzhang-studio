# 生长 0.4.0 使用与升级说明

本次新增快捷登录、项目语料库、可编辑敏感词库和项目编辑自动保存。

## 更新应用

1. 在旧应用的托盘或菜单选择「退出并停止后台任务」。仅关闭窗口会缩到托盘。
2. 完整解压新版 Windows x64 压缩包，运行其中的 `ShengzhangStudio.exe`。
3. 使用原来的本地用户名和密码登录。原数据继续保存在 `%LOCALAPPDATA%\ShengzhangStudio`，不需要复制数据库到新文件夹。

请保留原密码。快捷登录并不是密码找回方式；在其他 Windows 账户、其他电脑或清除数据后，不能依赖原来的快捷入口。

## 1. 点击用户名快捷登录

登录或注册时勾选「自动登录 · 下次点击用户名即可进入」。以后回到登录页，点击该用户名卡片即可解锁；卡片旁可以「取消记住」。

这是按你选择启用的便利功能。同一个 Windows 账户的使用者可以直接打开被记住的工作区。解锁凭据由 Windows DPAPI 加密保存，不保存明文密码；项目和 API 凭证仍分别加密。未勾选的用户继续使用密码登录。

快捷入口仅在 Windows 完整版及其本机网页提供；公开静态网站继续使用密码登录。

## 2. 导入项目介绍并查询语料

在左侧「项目语料库」选择当前项目，点击「导入项目介绍」。支持 TXT、MD、DOCX 和文字型 PDF，也可以粘贴文字。检查提取出的正文，再点击「确认导入语料」。

保存的是提取的正文、文件名和段落，原始文件仍在你的文件夹。单文件最多 8 MB、30 万字符；PDF 最多 100 页；每项目最多 50 份文档、200 万字符。扫描件暂不提供 OCR，请先转为文字。中文字体映射资源随应用打包，导入与查询不需要把文档上传到外部服务。

输入关键词可查询当前项目启用的语料；最多返回 5 个相关段落。可以停用某份语料，保留正文但不参与后续检索，也可以删除。不同项目、不同用户分别保存。

生成策略、下期策划和 AI 文案时，先自动查询相关语料。策略生成弹窗可以填写关键词和预览结果；结果中保留本次参考的文档及段落快照。使用 AI 时，检索片段会与必要的项目资料一起发送给模型服务商。已确认的项目事实优先，资料冲突仍需核实。

本地模板会把相关资料写入制作要求，并展示引用；它不具备 AI 的理解和重写能力。检索采用本地关键词匹配，不消耗模型费用。

## 3. 编辑敏感词与替换方式

打开「连接与设置 → 敏感词与替换词库 → 管理词条与替换方式」。内置 26 条基础示例，支持添加、编辑、停用、删除和批量添加。每行可用 `敏感词=替换词` 批量输入，替换词为空表示删除，编辑后点击「保存词库」。最多保存 500 条规则，当前用户的所有项目共用。

生成流程为：检索项目语料 → 生成策略与文案 → 按词库筛选和替换 → 人工检查成品。处理范围包括生成的标题、核心表达、正文、方向、制作提示和分镜文字；完成后可以展开查看命中及替换记录。原始项目事实、语料正文和评论原文不会被改写。

若新词库改变了旧成品的可见文案，重新制作前会先检查并保留旧版本。图片或视频像素中的文字不提供 OCR 审核。词库是基础文字匹配工具，不是平台官方完整禁用列表，也不能保证平台审核结果；替换后请检查语义和事实。

## 4. 项目编辑自动保存

新建项目或「编辑品牌资料」时，停止输入约 0.25 秒后保存到当前用户的加密工作区。编辑框上方显示保存状态。

- 新建或尚未填完整的内容作为草稿保存，重新打开编辑框会恢复。
- 已有项目的必填资料完整时直接自动更新；已确认的历史策略保留原资料快照。
- 点击关闭或「保存并关闭」会等待本次保存。保存失败会保留编辑框并提示重试。
- 两个窗口同时修改时会提示冲突，避免用旧资料覆盖另一处的新修改。可自行复制保留当前输入，再选择「放弃当前草稿，恢复最新项目资料」。

刷新、重启可恢复已成功保存的内容；若系统在最后一次输入尚未落盘时强制结束进程，最后少量输入仍可能丢失。关闭前确认上方已显示保存完成。草稿不会以明文写入浏览器持久存储。

## 版本范围

Windows 完整版包含四项升级，继续支持既有 AI、视频、发布和评论流程。公开静态版同步增加本地语料、词库和自动保存；AI 与平台调用仍需 Windows 完整版。两种版本的数据分别保存，不会跨设备自动同步。
