# v1.3.2 · 手动发布与界面整理

本次继续采用手动发布，清理会让人误以为能自动投送的旧提示与布局。保留 v1.3.1 的语义替换、自定义敏感词、项目语料、热点、封面和视频功能。

## 发布流程

1. 在「内容制作」完成图片或视频，再打开「发布中心」。
2. 在「待发布成品」点击「导出素材」。不必先添加计划。可下载 ZIP 素材包、单独图片 / 视频、TXT 文案，也可分别复制标题与正文。
3. 打开小红书或抖音官方创作中心，核对登录账号、素材、文案、话题和内容标识，亲自完成发布。ZIP 须先解压；图片支持 PNG / JPG，视频保留实际格式。
4. 需要管理记录时，给成品「添加待办」，选择账号和计划时间。发布成功后，在待办中「登记结果」，粘贴作品链接并确认。
5. 到评论页导入反馈，继续复盘。

导出素材、打开平台、保存待办和到达计划时间，都不会上传或发布。旧任务继续停用，历史素材和作品链接保留。旧任务若曾提交而结果不明，仍需先在平台核对，避免重复发布。

## 为什么不自动发布

发布中心和「设置 → 账号与发布」均保留可展开说明与官方文档入口。

- 抖音官方投稿能力有权限、应用类型和场景限制，SDK / H5 投稿仍需要用户在抖音内完成操作。本应用的营销创作场景不据此接入自动发布。[官方发布能力说明](https://developer.open-douyin.com/docs/resource/zh-CN/dop/operation-standard/platform-capabilities/useclue)
- 小红书：本应用没有接入可用的官方自动发布接口，采用导出后手动发布。[官方开放平台](https://agora.xiaohongshu.com/doc)

这些说明描述本应用的能力边界，不表示平台所有产品都无法提供发布接口。抖音发布说明已于 2026-10-07 核对；小红书文档本次读取超时，因此没有新增或推断其接口能力。

## 设置怎么找

| 设置分组 | 内容 |
| --- | --- |
| 文字模型 | OpenAI / DeepSeek 密钥、模型分工、连接诊断 |
| 图片与视频 | Seedream 封面和关键帧、Seedance 视频 |
| 文案与词库 | 自定义词条、固定替换、AI 改写、价格语义替换、导入导出 |
| 账号与发布 | 本地账号名称、平台入口、手动发布说明 |
| 数据与费用 | 工作区备份、存储方式、模型费用 |

切换分组保留当前页面尚未提交的输入，但离开设置或关闭应用前仍须点击对应保存按钮。键盘可用左右方向键切换分组。

评论读取是独立可选功能，收在「账号与发布 → 抖音评论读取 · 可选设置」。已有官方接口权限的用户可继续连接；无权限用户直接导入评论即可。此功能不申请发布权限。真实抖音评论联调仍取决于获批应用与账号授权。

## Windows 升级

完整解压 `Shengzhang-Studio-1.3.2-windows-x64.zip`。在旧版托盘菜单选择「退出并停止后台任务」，再打开新版 `ShengzhangStudio.exe`。同一 Windows 账户继续使用原本地数据；不要删除 `%LOCALAPPDATA%\ShengzhangStudio`。
