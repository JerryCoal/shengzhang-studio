# Qwen 语义语料检索

核对日期：2026-10-14。本文件说明本轮本地工作区的实现约定与验收边界；不代表已经用真实账户完成收费调用测试。

## 用户怎么使用

1. 在设置中保存阿里云百炼**北京地域**的 Qwen API Key。沿用已有密钥；能生成 Qwen 文案不等于已验证向量模型权限，还需确保所属业务空间可调用 `text-embedding-v4`。[API Key 权限说明](https://help.aliyun.com/zh/model-studio/application-permission-management-overview)
2. 在当前项目的语料库导入介绍文档，检查正文并启用需要参与检索的资料。仅导入文档不会自动建立云端向量。
3. 明确点击建立语义索引并确认发送范围、费用后，程序把本次启用的语料片段发送给阿里云计算向量。首版一次最多处理 200 段，每批最多 10 段；超出时应先精简资料，不能静默遗漏后面的文档。
4. 索引有效时，查询语料库以及生成策略、下期策划、普通 AI 文案会结合关键词与语义相关性检索，再把少量命中原文交给生成模型。即使换一种说法，也有机会找到同一意思的资料；相关性得分不等于事实可信度。
5. 修改、删除或停用参与索引的语料后，需要重新建立索引；过期、未建立、预算不足或暂时不可用时回退到本地关键词检索，并说明当前模式。

这个功能检索的是**当前项目已导入的资料**，不会联网搜索热点。首版自动接入策略、策划和文案，不表示所有 AI 环节都用了向量检索；评论分类与复盘仍按选定评论范围处理，原有统计口径不变。生成结果仍须核对来源和已确认的产品事实。

## 数据与费用

项目语料和向量索引保存在当前用户的本地加密工作区。建立索引会发送待索引正文；后续语义查询会向阿里云发送查询文本，也可能计费。命中的原文还会随创作请求发送给当次选择的生成模型。不要将“索引本地保存”理解为“资料完全不出设备”。

百炼官方声明不将数据用于模型训练，同时说明会依法存储模型与应用调用产生的数据；本功能不承诺服务商零留存，也不自行推定保留天数。具体以服务协议和账户设置为准。[官方隐私说明](https://help.aliyun.com/zh/model-studio/privacy-notice)

本轮为每项目设置 **1 元人民币的向量实验累计预算**，与原有美元文案生成预算分别记账。建索引和后续查询都占用这笔预算；删除或重建索引不应清零已发生的费用。北京地域当前公开原价为每百万输入 Token 0.5 元，因此 10 万输入 Token 的向量费用原价约 0.05 元。每次十条的同步请求不属于半价 Batch File 服务。预算提醒与预留是应用侧控制，真实用量、优惠、欠费状态以百炼控制台账单为准。[模型价格](https://help.aliyun.com/zh/model-studio/text-embedding-v4)

## 技术约定

```text
用户确认建索引
  → 当前项目启用语料分段
  → 每批最多10段请求Qwen向量
  → 验证完整返回、维度与来源对应
  → 索引连同来源和版本写入本地加密工作区

查询／策略／策划／文案
  → 核对索引与语料是否一致
  → 查询文本向量化
  → 本地关键词结果＋向量相似度结果融合、去重
  → 返回原文片段及出处
  → 当前步骤Skills＋确认事实＋相关原文交给生成模型
```

| 项目 | 本轮设置 |
| --- | --- |
| 接口 | `POST https://dashscope.aliyuncs.com/compatible-mode/v1/embeddings` |
| 模型与输出 | `model: text-embedding-v4`、`dimensions: 512`、`encoding_format: float` |
| 批量限制 | 最多 10 条输入；官方同步接口规定每条最多 8,192 Token，字符数不能直接当成 Token 数 |
| 索引绑定 | 用户、项目、语料内容与启用状态、分段版本、模型及维度；其中任一不一致就不使用旧索引 |
| 保存内容 | 片段标识、文档来源、内容指纹、向量与索引版本；API Key 仍通过现有凭据存储管理 |
| 失败处理 | 不把半成品索引标记为可用；已发出但结果不明的调用保留费用预留，不静默重复付费 |

旧北京域名目前仍支持上述接口。官方推荐业务空间专属域名 `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`，并明确现有域名继续可用；本轮可沿用现有主机，无须要求用户额外填写空间域名。[兼容接口与迁移说明](https://help.aliyun.com/zh/model-studio/embedding-interfaces-compatible-with-openai)

512 维、十条输入及 `encoding_format` 均有官方接口依据。兼容接口不支持稀疏向量输出；不要加入 DashScope 专属的 `output_type=sparse`。响应中的每个 `index` 必须与输入片段一一对应，费用解析兼容仅返回 `usage.total_tokens` 的情况。[同步接口参数](https://help.aliyun.com/zh/model-studio/text-embedding-synchronous-api)

## 发布前验证清单

先用人工构造资料和模拟服务商响应验证，不读取真实用户项目或自动发起收费测试。

- 未确认建立索引、未配置密钥、零预算、超过 200 段时，不发送请求；11 段拆成 10＋1，跨项目和停用文档不进入请求。
- 响应乱序时依 `index` 正确归位；缺项、重复标识、空向量、非 512 维、非有限数值或零向量均不安装为有效索引。
- 中间批次失败、超时、401、403、429、重复点击及生成途中更改语料，不提交过期或半成品索引，也不自动重复收费。
- 记录真实返回用量；结果不明保留预留；验证 1 元边界、并发预留、重启后累计费用及删除索引不清账，美元预算不受混用。
- 同义查询可以召回已知相关片段，品牌专名仍有关键词命中；结果有可核对出处，没有相关资料时不编造引用。
- 修改、删除、停用语料及模型/维度不匹配时显示回退状态；评论原文、统计和人工校正不受影响。
- 本地账户之间索引隔离；锁定后不可读取；持久化文件、日志和错误提示不泄露密钥；无关联网请求不附带整份向量库。
- 真实验证限定在用户已授权的范围和预算内，使用少量非敏感测试资料核对模型权限、费用及效果；接口成功不等于检索质量已达标。
