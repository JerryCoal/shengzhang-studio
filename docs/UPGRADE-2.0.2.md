# v2.0.2 本地升级与使用

先在旧版导出备份、核对未完成任务，再退出旧版。将新包完整解压到新目录，个人版运行 `ShengzhangStudio.exe`，团队版沿用包内部署说明。保留 v2.0.1 和 v2.0.0，不要让两版同时修改同一工作区。旧版不能完整编辑新增对话字段，因此不建议在新版保存对话后反复切回旧版写入。

## 像聊天一样使用灵感 Agent

1. 左侧选择主编辑项目，进入“灵感 Agent”。输入需求，例如“想给新手做一组露营选题”，点发送前核对。
2. 在确认窗口看清目标平台、账号、模型与费用，再确认生成。取消或关闭确认窗口不会生成。输入中提到单个平台时，会提出对应目标建议，但不自动替你挑账号。
3. 在聊天区域查看执行阶段与返回方案。继续说“更生活化一点”“保留第二个方向，面向学生”，即可基于同账号上下文修改。显示的是实际执行状态，不是内部思维全文。
4. 需要选历史经验、项目资料、模型或 Skills 时，展开“资料、经验与模型”。热点研究仍由“热点与参考”进入并按原流程确认，普通聊天不会自行采集。图片/文档从资料库导入并明确选用。
5. 满意后展开方案下的交接区域，核对目标账号，点击“确认交接，不发布”。平台 Agent 保持原界面，继续制作图文或视频。

Enter 换行；Ctrl / Command + Enter 只打开生成确认。聊天区可独立滚动，翻看旧消息不会强行拉到底部，可点“回到最新消息”。

## 安全暂停、失败与历史

“请求暂停”在安全检查点生效，不能撤回已经发给服务商的请求。异常后原方案保留；先点“核对已保存结果”，不要连续重试，以免重复费用。没有提交到模型的待处理轮次可手动恢复输入；服务已接受的轮次不能假定取消成功。

输入与对话自动保存。等待保存提示后退出；断电、强制结束进程或服务不可用仍可能使最后尚未保存的输入丢失。每段最多 20 轮，需要继续时先导出再新建对话，历史策略和作品保留。导出文件为明文。

切换创作账号会隔离其历史并清除当前方案及资料选择；回到原账号后，可明确采用该账号的已完成方案。通用灵感不借用其他账号的身份；交接时必须选择真实账号。

本次仅本地交付，没有上传 GitHub。其他 Agent 不做对话式改造。界面实机验证和真实模型测试的限制见 `VALIDATION-2.0.2.md`。
