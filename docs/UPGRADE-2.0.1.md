# v2.0.1 本地升级与使用

先在旧版导出备份并核对正在进行的生成/发布，再退出旧程序。将修正版完整解压到新目录运行，保留 v2.0.0；不要同时用两版修改同一工作区。个人版启动 `ShengzhangStudio.exe`，团队版沿用包内团队部署说明。原本机用户与数据目录不改变，不额外迁移或删除资料。

## 项目、账号与发布

左栏上部勾选项目与账号；“主编辑项目”独立控制当前创作页面。主栏的常驻摘要会一直提醒范围。多个项目被选中不代表混合它们的事实进行生成。

在各平台 Agent 做好各自成品，然后到发布中心点“多选平台 / 批量发布”。每条先点“核对账号与内容”，填写该平台必要的可见范围、素材地址等，保存本条核对结果；最后勾选批次确认并提交。完成后逐条核对真实回执与平台审核结果。连接尚未配置的平台不能绕过授权发布。

只有一个平台的内容时，先点“增加平台 / 账号”多选改编目标。每个账号得到独立草稿；进入相应 Agent 调整身份、语气、素材和规则，完成后再放进发布批次。创建草稿不产生模型调用或实际投稿。

## 经验、图片与失败报告

经验选择展示完整标题和正文区域。图片无法加载时，先看保留的文字及图片描述；有既有图片分析会单独标注来源，未读取图片不会生成虚假的视觉结论。

来源读取失败时展开来源报告，按显示的阶段排查服务、令牌、平台登录或参数兼容。搜索摘要属于线索，未核实的内容不直接进入证据分析。请勿粘贴 Cookie、完整令牌或原始错误响应。

## 无水印与本地服务

新配置的官方图片/视频可选水印默认为关闭。曾明确保存的偏好不会被静默覆盖，可在图片/视频设置中关闭水印。平台依法或按规则添加的标识不属于这个开关，已制作的素材不会自动改写。

在文字模型设置选择“本地 Qwen”，按 `LOCAL-QWEN-SETUP.md` 填写本机服务地址和模型 ID。先自行部署并启动模型，再保存设置并检查列表，最后在 Agent 选择本地 Qwen。团队版连接团队主机；远程静态网页版不转发到内网。

连接与设置中的“本地 MCP 管理”支持 Windows 小红书/抖音已安装主程序的启动、状态刷新和停止；工作站不自动下载安装。启动后需明确确认才能用新地址替换当前账号手动连接。其他平台可复制部署说明给模型协助核对，实际安装、授权仍由用户确认。

本版没有上传 GitHub，第十项对话式创作仍保留现状，等待用户另行确认。
