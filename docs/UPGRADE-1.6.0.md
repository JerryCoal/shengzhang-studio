# v1.6.0 平台工作流测试版

升级 Windows 应用的小红书 / 抖音官方页面助手，保留原有导出、手动发布、评论分析和飞书排期。旧版安装包与用户数据保留。本版以 GitHub Pre-release 测试版提供，正式版历史下载保留。

## 发布流程

1. 发布中心选择成品，打开「发布助手」，选择关联账号。首次打开时建立待办；已有同版本待办会复用。
2. 在内嵌官方创作中心登录，进入与素材相符的图文 / 视频编辑页。
3. 点「自动上传与填写」。助手上传本次素材，等待编辑器出现，填写标题、正文；也可以分别执行上传、填写或复制。
4. 核对官方页面实际账号、素材、封面、上传 / 转码状态、话题、可见范围与定时设置。点「确认提交发布」，勾选确认框后才会点击平台发布按钮。
5. 平台返回可识别的作品编号后，回执写回本地待办；返回工作台打开作品核对，再登记为已发布。平台接受提交不等于审核通过。
6. 没有回执或中途退出时，待办保留「结果待核对」并锁定再次提交。先检查平台作品列表；确认没有发布成功后，在助手中解锁。收到回执的记录优先在平台处理审核结果，不重复投稿。

当前为单张 PNG / JPG（WebP 先转 PNG）或单条 MP4，标题按 20 字、正文按 1000 字保守预检。计划时间仍是待办，不执行无人值守定时投稿。编辑器无法识别、出现验证或平台按钮不可用时停止，保留手动方式。

## 评论与作品数据

- 「评论分析 → 导入评论」：选择已登记的自有作品，打开官方页，登录后开始自动采集。自动滚动、展开回复；按作品和评论 ID 去重，再由用户预览勾选导入。
- 本版增加父评论编号与真实发表时间保留。重复采集更新可用互动数据，不覆盖原文或人工分类。昵称、用户主页、Cookie 不写入评论记录。
- 「运营数据 → 从作品采集」：选择自有作品，在窗口点「读取作品数据」，返回核对后保存。可以只采集指标，无需先采到评论。
- 从当前页面实际加载的结构化响应读取点赞、评论、收藏、分享，以及平台提供的播放数据。小红书公共笔记响应未提供阅读量时留空，不推算。
- 各次采集保存独立时间与来源。缺失为「—」，真实零保留；汇总只取每个作品最新一次记录，不叠加多个累计快照。
- 评论数量有上限，页面风控、删除 / 折叠、分页和虚拟列表会影响可见范围，采集结果不表示全部评论。

## 登录与本地数据

同一工作台登录中，发布和评论窗口可复用对应平台的内存会话。切换平台账号时，在发布中心点「清理平台登录 / 切换账号」。退出工作台、刷新主窗口或退出应用会清理会话；不把平台登录凭据写入项目、备份或明文磁盘文件。项目与 API 密钥继续使用原有按用户隔离的本地加密存储。

## 实现来源与边界

参考 [Spider_XHS](https://github.com/cv-cat/Spider_XHS) 和 [DouYin_Spider](https://github.com/cv-cat/DouYin_Spider) 的作品归属、评论 / 回复结构、发布阶段与回执处理思路，独立实现本项目适配层。未复制上游私有接口签名、Cookie 提取、上传或发布源码，也没有把两个仓库打包进应用。审查时仓库未提供明确的可再分发开源许可，XHS 项目另有禁止商业化说明。

通过官方页面本身发出的请求读取结果，不生成签名或重放平台私有请求。发布适配器需要桌面窗口打开、用户登录与确认；不是官方开放平台投稿授权。

## 验证范围

新增作品范围、缺失指标、父子评论、提交去重、回执匹配、本地接口和登录隔离测试。另以独立 Electron 环境拦截全部 HTTPS 请求，检查真实文件上传、中文 / 表情填写、取消确认不提交、确认后只提交一次、回执保存和面板布局。

这些测试验证程序逻辑与模拟页面兼容性，不能证明当前真实平台所有账号、编辑器版本与作品类型均可用。本次没有操作真实账号最终发布，需要使用者登录并以自有内容继续联调。遇到未知页面时不要重复投稿，可用保留的手动上传与链接登记。

## 升级

先在旧版托盘菜单退出，再完整解压 `Shengzhang-Studio-1.6.0-windows-x64.zip`，运行 `ShengzhangStudio.exe`。继续使用原本的本地用户；不要把旧数据库复制到新版程序目录。数据目录仍为 `%LOCALAPPDATA%\ShengzhangStudio`。
