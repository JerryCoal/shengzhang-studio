# v1.16.0：小红书选题与高互动帖子研究

这次把「热点与灵感」扩展为内容研究：除了新闻和近期热点，也能通过小红书 MCP 找到相关话题、可借鉴的高互动帖子，再用 DeepSeek 生成可执行的创作改进建议。

## 开始前

1. 在「连接与设置 → 账号与发布」连接外部小红书 MCP，启动后扫码登录并检查连接。内置页面助手仍用于发布与评论，不提供这项搜索能力。
2. 在「连接与设置 → 文字模型」保存自己的 DeepSeek 密钥。新模式复用该密钥，不需要另填搜索或向量服务密钥。
3. 打开一个项目，在「热点与灵感」选择「小红书选题与高互动帖子」。

## 使用步骤

1. 输入 1–3 个具体关键词，例如「大学生自习」「学习搭子」「校园社交」。
2. 选择近七天、近三十天或不限时间；再选择综合、点赞、收藏或评论排序，以及全部、图文或视频。
3. 选择 DeepSeek Flash 或工作台已有的 DeepSeek V4 Pro，点击「查找帖子并分析」，核对发送内容和费用后开始。
4. 在帖子列表核对原文、发布时间、采集时间与可见互动。再查看 AI 的观察、可能吸引点、项目应用方法以及具体流量改进实验。
5. 选中合适的创作参考并确认保存。后续策略、文案生成会带入已选参考及建议，不会自动发布。

等待时可以切换其他页面或项目，结果保留在原项目。想调整分析模型或关键词，可点「仅重新分析已保存参考」，不会重复采集；新的时间与内容类型筛选仍会应用于已有样本。若筛选后没有足够帖子，请重新查找。

## 这套流程实际做了什么

用户关键词 → MCP 搜索与详情 → 本地校验日期、去重、敏感来源过滤 → 按匹配词和可见互动排序 → DeepSeek 分析最多 10 条参考 → 人工确认 → 后续创作。

- 每轮最多搜索 3 个关键词，每个读取最多 4 篇详情，总上限 12 篇；重复、无法打开、日期或类型不符合的帖子会减少实际数量。
- MCP 目前没有“近一个月”筛选。工作台先请求其“半年内”候选，再按详情中的真实发布时间筛选近 30 天；不能保证找全整个时间段。
- 综合排序先看关键词的字面匹配数量，再看已知互动合计；单项排序按该项可见数值排列。缺失不是零，「1.2万」等保留约数标识。互动合计只统计已知项。
- 高互动是本次返回样本内的比较，不是全站榜单。不限时间的历史帖子用于借鉴，不当作近期热点。一次累计数据快照无法判断近期增长速度。
- AI 根据实际可见的标题、正文摘录及数据，提出标题、开头、正文结构、标签和互动提问的修改建议，并给出验证方法。没有封面图、视频内容或评论正文时，不会把这些内容当作已分析证据；没有曝光量等分母时，不计算点击率、转化率。
- 每项建议引用本次分析中真实存在的帖子，引用摘录必须能在来源原文中找到。仅采用你确认的建议，不把外部帖子的效果当成本项目的成绩。

## 数据与费用

研究资料、选择结果与模型密钥仍按本地用户保存。研究仅保留必要的帖子标题、短摘录、无凭据的来源链接、日期、类型与公开互动，不保存作者资料或评论。请求 AI 时，会将必要项目资料和采集摘要发送给所选 DeepSeek 模型。

MCP 采集与本地排序不触发模型调用；分析按服务商用量计费，并计入项目现有美元预算。请求失败不自动重试；已经发生或无法确认的费用继续记录。没有合格样本时不请求 DeepSeek。模型给出的是待验证的创作建议，不保证流量增长。

## 原有功能与升级

「近期热点与网页」仍保留原有 RSS、网页搜索与可选 Qwen 语义检索；新闻仍按七天核验。字号、重点阅读、后台任务、发布与评论流程继续保留。

先保存旧版结果并从托盘完全退出，完整解压新版，再运行 `ShengzhangStudio.exe`。原有本地用户和数据会继续使用，无需重建。此版本尚未上传 GitHub。
