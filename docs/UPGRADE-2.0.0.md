# v2.0.0 使用与升级

## 从旧版升级

1. 在旧版导出工作区备份；保留原安装目录与数据目录。
2. 等待或核对正在生成、发布、采集的任务，再完全退出旧版。
3. 将 v2.0.0 完整解压到一个新目录，个人版打开 `ShengzhangStudio.exe`，团队版按包内团队部署说明启动。不要同时用两个版本修改同一工作区。
4. 使用原来的本地用户和密码登录。个人数据继续位于 `%LOCALAPPDATA%\ShengzhangStudio`，团队数据继续使用原团队配置目录。密钥不包含在普通导出备份中；忘记密码不能通过新版找回。

## 完成一轮运营

在“灵感 Agent”选项目并填写运营需求。需要近期热点时进入“热点与参考”，核对读取平台账号、来源、时间范围与预算，确认后研究。分析结果保留来源、统计口径和局限，选择认可的结论带回灵感。

从经验库选择以前验证过的做法或团队共享资料，再选择本次文字模型及适用 Skills。明确选中的经验优先决定创作方向与文风；真实产品信息、事实和新的用户要求不被经验覆盖。不是所有历史经验都自动进入本轮请求。

生成灵感后可修改标题、核心表达、方向和创作提示，也可直接交付明确的需求。交接前选择平台账号和图文/视频形式；YouTube 使用视频。每个交接产生独立绑定账号的草稿，重复提交同一次交接不会复制内容。

进入平台 Agent 后补充要求、参考资料和素材，生成或编辑文案，检查词库与事实，再制作/导入图片或视频。多条 Skills 只适用于其声明的阶段与平台，默认规则可在设置中改写。资料不会因为切换账号而转归新账号。

满意后前往发布 Agent，核对当前版本、平台、账号、计划时间和交接要求。可增加账号或为其他平台建立改编稿；这不会直接重复投稿。实际投送仍由既有确认流程执行。连接飞书后可以选择记录新计划，已经开启的项目自动同步保留原授权范围。

在结果分析 Agent 选择作品，或登记之前发布的完整作品链接与真实账号。短链接应先在浏览器展开。先获取并核对指标/评论，再确认需要的模型分析。手动采集时间与原始指标口径保留，缺失值不是 0。将认可的结论保存成账号专用或项目共享经验，之后选择性使用；也可导出 Markdown 上传共享文档。

## 任务、暂停与退出

任务中心可在工作页之外查看。不同作品可以同时生成，预算统一预留；同一作品的文案与媒体冲突操作会被拦截。文字/研究任务支持在已定义的安全检查点暂停，外部模型已经收到的请求可能继续运行。图片和视频使用服务商任务编号跟踪，不能虚构“已取消”。

轻提示音可关闭；浏览器可能要求先与页面交互才允许声音。初次打开已有完成作品不会集中响铃。

窗口关闭时可选择后台继续，或者保存进度再退出。恢复记录标为待核对，不自动重发生成、采集或发布请求。先查看服务商任务/账单与当前作品，再决定是否继续。网络或保存错误会明确提示，不能把“保存失败”当成已保存。

尚未点击正式保存的编辑器正文也会加密暂存。重新进入同一账号、项目和作品时可恢复；如果正式作品已被其他窗口或团队成员修改，旧暂存会保留供复制或明确舍弃，不直接覆盖新版本。正式保存成功后才清理该成员对应的临时正文。

## 服务与版本范围

Qwen、GLM、DeepSeek 分别保存官方密钥；GLM 设置见同包 `GLM-SETUP.md`。新用户默认 Seedream 图片和 Seedance 视频，仍需配置凭证。已有 OpenAI/Redfox 选择保留，修改服务不会迁移账单或模型任务。

Windows/团队版提供完整 Agent 工作流。独立浏览器中转版暂不传送私人 Agent 数据包，保留草稿与原有可用功能；不建议把它当成桌面版的同步备份。团队主机需要持续运行，软件不会替你开放公网、防火墙或自动配置第三方付费服务。
