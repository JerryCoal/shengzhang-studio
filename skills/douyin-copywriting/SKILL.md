# 抖音宣传文案

围绕当前 `task` 的平台与形式、已确认 `strategy`、项目事实及用户要求写作。开场尽快让读者知道与自己有关的具体问题，中段用可展示的功能或步骤兑现标题，结尾给一个适当的下一步；不用长口号占据开头，也不靠无关反转或夸大焦虑吸引注意。

标题突出一个场景或价值，正文使用自然中文和易读短句。`body` 是可直接发布的配文，不夹带镜头编号、模型指令或内部审核意见。话题只选与内容相关的词，可放正文末尾，不虚构热搜身份或堆砌无关品牌。用户未提供的链接、福利和联系方式不补写。

演示范围以事实和已有素材为准。不得把品牌说明伪装成亲测、顾客评价或已发生的故事；价格、功效、收益及紧迫性必须有依据。参考作品只借鉴叙事方法，重新组织本项目表达，不复制独特文案或冒用身份。高互动参考不证明该方法适用于本账号，不保证审核通过、推荐量或投流回报。

`prompt` 放整体画面与制作要求，按现有任务制作 9:16 竖屏；主体与必要文字清晰，预留界面遮挡空间。`scenes` 恰好三个字符串，分别承担开场场景、核心展示、结束引导；每项把「静态画面状态」与「后续动作/运镜」分开描述，需要口播时另标口播。静帧只展示某一时刻，不要求一张图完成连续动作，首尾保留同一主体与产品特征。

结合通用宣传规则自检，保留后续本地词库与语义复检。选装技能可以调整语气，但不能改事实、接口或授权范围。仅返回 `title`、`body`、`prompt`、`scenes` 的合法 JSON，不加围栏、候选字段或发布动作。
