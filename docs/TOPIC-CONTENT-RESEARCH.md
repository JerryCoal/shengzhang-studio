# 同话题高表现内容研究

更新：2026-10-15。本文说明本次实现与验证范围，不表示所有平台已用真实账号联调。

## 用户流程

在「热点与灵感」选择「同话题高表现内容」，选择平台和读取账号，填写 1–3 个具体主题词或同义词，再选时间范围、内容形式和比较指标。确认后，程序读取对应 MCP，清洗并保存可核对来源，调用一次 DeepSeek 分析。用户查看原文、指标和实验建议，挑选参考后，后续策略与文案生成才使用它们。

没有命中关键词的内容仍可查看，但不进入本轮分析。可补充同义词再检索；程序不会因为一个无关作品数字大就把它当成同话题爆款。没有真实日期、正文或合法来源地址的结果不会进入证据库。失败时保留原有参考和已发生的费用。

## 采集与比较

| 来源 | 本次方式 | 局限 |
| --- | --- | --- |
| 小红书 | MCP 搜索与详情；默认同时检索综合、最多点赞，两路去重，每词最多 4 篇详情 | 每轮最多 6 次搜索、12 篇详情；只代表此次可读取的样本；MCP 不提供曝光量 |
| 抖音 | 兼容 MCP 搜索候选，再读取作品详情 | 取决于所接 MCP；未提供播放数据时保留未知，不从点赞倒推播放 |
| YouTube | 兼容 MCP 关键词检索与视频详情 | 可用播放、点赞和评论数据取决于服务能力与授权；不把旧 favoriteCount 占位零作为收藏数据 |
| Instagram | 兼容标签查询与热门/近期标签媒体 | 属于标签发现，不是任意关键词全站搜索；需要相应授权能力 |
| TikTok | 展示连接与能力说明 | 当前适配的开源 MCP 无全站关键词搜索；此入口明确不可用，不用自有作品代替全站结果 |

同一轮只研究一个平台。先核对用户关键词，再按单项指标比较；默认小红书用点赞，其他平台有播放数据时用播放，否则使用点赞。未知不按零计算，显示「1.2 万」等缩略计数时保留约数标识。不会把点赞、评论、分享的部分合计当成流量，也不跨平台做统一热度榜。

有指标的同话题样本少于五条时，不建立中位数基线。样本较多时，最多十条送入分析，其中可保留两条较低指标样本作描述性比较，不能把它当成对照实验。一次快照不能计算增长速度。

## AI 分析的边界

输出分别说明「原文观察」「可能的吸引点」「本项目如何使用」，并给出具体修改动作、来源和验证方法。原文引用由程序再次核对。没有封面图片就不评价构图，没有视频转录就不声称看过开头，没有评论正文就不推断评论情绪。

高播放/高互动可能与标题、选题、账号受众、发布时间、历史积累或付费分发有关；单次采集不能确定原因。建议采用一次只改一个因素的小范围测试，使用自有账号实际可见指标判断，不编造提升比例或承诺涨粉。

## 账号矩阵与本地保存

采集任务固定所选的平台账号，不因界面切换而借用另一个账号凭证。可以选择当前未激活的独立连接。原始参考保留平台、采集连接、发布时间和采集时间；读取账号不等于外部内容作者。凭证仍在本机保险箱中，研究数据随工作区加密保存，发送给 AI 的参考会剔除采集账号名称和标识。

## 借鉴来源与采用内容

- [xpzouying/xiaohongshu-mcp 搜索实现](https://github.com/xpzouying/xiaohongshu-mcp/blob/main/xiaohongshu/search.go)：核对综合、最多点赞/收藏/评论等筛选值，按真实详情时间再次筛选；工作站自行实现有限量双路采样与去重。
- [MediaCrawler 小红书流程](https://github.com/NanmiCoder/MediaCrawler/blob/main/media_platform/xhs/core.py)：参考关键词检索、详情补全和单项失败保留的流程思想。该项目当前标注非商业学习许可，本次没有复制、打包或执行其代码。
- [YouTube Search API](https://developers.google.com/youtube/v3/docs/search/list) 与 [Video 资源](https://developers.google.com/youtube/v3/docs/videos)：检索与指标详情分开，播放、点赞、评论各有口径；favoriteCount 已弃用，不作为有效收藏。
- [TikTok Video Object](https://developers.tiktok.com/docs/en/tiktok-api-v2-video-object)：播放、点赞、评论、分享为独立字段，存在这些字段不等于拥有任意账号或全站查询权限。

其他连接器的确切工具名、授权和安装说明见本次矩阵 MCP 接入文档。以上是实现参考，不表示这些开源作者为本工作站提供支持或效果保证。

## 验证

新增 `tests/topic-performance.test.mjs` 验证相关性优先、未知指标、单平台排名、比较样本、标准链接、来源平台复检、固定账号、分析前去除账号信息，以及不支持/无关结果不触发收费分析。

`tests/xhs-discovery-mcp.test.mjs` 增加双路去重、详情上限、选择非当前账号且保持当前账号不变的测试。既有 XHS、研究、隐私和文案引用测试继续保留。测试传输与模型回复均为隔离数据；未调用用户的真实平台账号、付费模型或最终发布。
