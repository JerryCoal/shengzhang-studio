## 浏览器实际操作

使用 CUA 在隔离测试环境中打开「小红书文案」的自然表达润色规则，实际完成以下操作：

1. 展开默认规则，进入编辑窗口，保存 85 字节测试正文；列表出现自定义状态和 `local.1` 有效版本。
2. 重新打开，确认正文与保存内容一致。
3. 修改后取消，看到放弃草稿确认；确认放弃并重新打开，仍为此前已保存的正文。
4. 核对恢复确认后执行恢复出厂，再次打开显示 2,960 字节出厂原文和原版本。
5. 输入空白正文，保存按钮禁用。

浏览器多标签并发冲突、移动宽度和草稿下载实际落盘未验证。并发版本冲突已有自动测试覆盖，不能将该结果写成浏览器多标签操作通过。
