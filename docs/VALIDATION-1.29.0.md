## 验证结果

- 完整测试：946 项，944 通过，0 失败，2 跳过。跳过的是需要 STUDIO_TEST_PYTHON 的独立 Python 文档适配器与文案引擎一致性检查，当前环境未配置该测试运行时。
- TypeScript 检查与内置 Skills 编译一致性检查通过。
- 普通前端、联网网页、静态体验版、Windows 个人包和团队主机包构建全部通过。
- 浏览器交互：五入口导航、单篇四步编辑、资料带入新草稿、绑定账号与参考资料预览、模拟文案生成、另一账号不带入专属资料、缺少图片时仍可前往发布并查看原因、已发布状态与对应记录、发布记录进入同一作品复盘、复盘经验保存到资料库、错误持续显示与修改后重试成功。
- Windows 包隔离冒烟：21 项检查通过，包括登录、页面服务、默认 Skills、加密凭证、直接图文/视频草稿、资料和经验修改、幂等、版本冲突、重启恢复。测试进程已退出，未发起外部请求。
- 团队包隔离冒烟：12 组检查通过。打包 Node/Caddy 以本机私有 CA 验证 HTTPS；编辑成员能保存草稿/知识，不能发布或修改模型/凭证；管理员共享读取与重启持久化正常。测试端口 48445、44322 已关闭。
- 浏览器本地适配另有自动测试：加密 IndexedDB 保存、退出重登、用户隔离、本地幂等与版本冲突；static/web 资料按钮开放及忙碌禁用行为。

## 测试边界

界面使用内存工作区与固定模拟模型响应，所有未模拟的外部请求被禁止；发布包测试使用新的隔离数据目录与合成密钥，没有读取真实用户工作区。此次没有验证真实模型生成质量、Redfox 当日服务、真实图片/视频生成或平台投稿，也没有进行公开发布。

独立联网网页可在浏览器加密保存草稿和知识，但携带单篇要求与账号身份的联网生成明确要求 Windows 或团队主机服务；不会丢失私有上下文后退回匿名生成。团队版当前为单台主机方案，不包含生产分布式任务队列。

构建仍有既有前端大块文件大小提示，不阻止构建。未保存编辑只在本次登录中暂存，刷新或退出前须保存正式草稿。旧版发布目录保留，未修改用户运行数据。

发布文件与文档以包内 release-manifest.json 和 ZIP 的 SHA-256 文件核对。服务器替换存储、鉴权和任务扩展边界详见 SERVER-EXTENSION-1.29.0.md。
