# 内容研究的实际工作流程

v1.16.0 新增“小红书选题与高互动帖子”：输入 1–3 个关键词，选择七天、三十天或不限时间与图文/视频类型，通过外部小红书 MCP 读取最多 12 条详情，本地筛选后由 DeepSeek 分析前 10 条参考，输出带证据和验证方法的创作建议。只需已有 MCP 与 DeepSeek，不使用额外扩词、网页搜索或向量 API。详细步骤见 [v1.16.0 使用说明](UPGRADE-1.16.0.md)。

下文说明仍保留的“近期热点与网页”模式。

日期：2026-10-14。工作站已接入“近七天内容研究”：把与项目相关的网页、笔记与新闻整理成有出处的参考，经用户选择后用于写作。这里的“近期参考”不等于全网爆款榜，也不保证流量或转化。

## 从研究到创作

1. **设置范围**：打开“热点与灵感”，填写 1–8 个关键词，每个最多 30 字；选择联网网页、小红书 MCP、中文 RSS 新闻。只有确认传输与费用后才执行。
2. **规划查询**：公开新闻、火山与小红书来源沿用“评论分类”模型整理最多 3 个查询；选择 Qwen 联网时直接合并用户关键词，省去额外扩词调用。程序决定实际来源与请求上限，模型不能凭空创建来源。
3. **受控采集**：默认公开新闻，不需要搜索密钥。可选 Qwen 复用已有北京地域密钥，一次请求取得来源后读取最多 6 个公开网页；或选择豆包搜索 Custom版（火山），最多 3 次、每次 8 个网页候选。小红书最多 2 次搜索、8 条详情。各来源分别报告结果，不自动改用未选的收费服务。
4. **清洗与保存**：删除导航等噪声、去重，重新核对七天窗口，排除未知日期、未来日期、过期、禁用词与争议信号。成功一轮最多保留 80 条参考，每条保留必要摘录、原文链接、发布时间、采集时间及日期依据。外部参考与项目事实语料分开。
5. **检索与分析**：默认本地关键词检索；可勾选 Qwen `text-embedding-v4` 做语义与关键词混合检索。把少量相关参考交给“评论复盘”模型，输出观察、吸引点假设、应用建议、标签、连续原文引用与局限。无关键词命中时可使用少量近期候选，但明确标记为回退，不能冒充语义命中。
6. **人工选用**：最多选择 5 项；涉及人物、品牌或作品名称的项目需逐项确认。后续创作带入仍有效的所选参考与项目事实，使用当前环节的内置 Skills；用户安装的 Skills 仍只在文案生成窗口选用。生成后继续原有词库检查与按需语义复核。

界面提供阶段进度，约每 3 秒刷新、最多 60 次。停止自动刷新不等于停止已发送请求；可以手动查看，最终请求返回仍会更新结果。仅重新分析已保存参考会跳过 AI 扩词与所有采集，重新清洗、检索、分析；仍需确认模型传输，过期资料会被剔除。

## 来源范围与证据边界

| 来源 | 实际能力与限制 |
| --- | --- |
| Qwen 联网 | 复用北京地域 Qwen Key，使用原生接口实际返回的来源，不使用模型回答充当原文。程序检查公开网页采集规则，再获取正文和明确发布日期；不能核实的内容只保留为待核实线索。 |
| 豆包搜索 Custom版（火山） | 使用专用搜索 API 返回的正文或摘要，程序本地执行近七天筛选。日期来自搜索服务，尚未逐页核实；不依赖最新接口未列出的时间筛选参数。 |
| 小红书 MCP | 使用已配置并由用户登录的外部 MCP；内置发布助手不提供热点搜索。搜索返回与详情复核受登录、平台验证和上游工具能力限制，不保证分页完整或覆盖全站。不会自动替用户登录。 |
| RSS 新闻 | 提供新闻选题线索，读取原有来源；没有点赞收藏不代表零互动，报道数量不代表社交平台热度。 |

抖音/TikTok 全站检索、自动增长速度统计、定时无限采集尚未包含。点赞、评论、收藏、分享缺失时保留 `null`；“1.2 万”等保留原始值与约数标记。跨平台不比较绝对计数，单次采样不能证明增长速度，互动量不证明曝光、成交或因果。

分析引用必须来自本次输入中的连续原文。通用词、禁用词和争议信号继续过滤；风险提示和确认不等于取得授权。生成前重新核验所选来源的时效与证据，失效参考不能进入新的创作。

## 连接、存储和费用

仅 Windows 版的**加密本地用户工作区**及其本机浏览器页面可运行。静态网页、联网中转网页和旧式未加密工作区不开放联网研究；原有 RSS 区域与已保存内容继续保留。

“连接与设置 → 联网检索”先选择研究方式。公开新闻无需新增密钥；Qwen 联网直接读取文字模型页保存的北京地域密钥；可选火山独立搜索在高级区配置，并提供开通、按量密钥、订阅密钥直达链接。火山搜索密钥与 Seedream/Seedance 分开。切换不会删除已有密钥，保存后输入框清空，只显示末尾字符，不写入浏览器 `localStorage`。

| 费用 | 控制方式 |
| --- | --- |
| 公开新闻 | 不收搜索服务费；后续模型规划和分析另计。 |
| Qwen 网页搜索 | 一次合并查询预留 0.2 元，模型与搜索费按返回用量估算；缺失用量保留估算。预留不是实际费用上限。 |
| 火山网页搜索 | 默认每次预留 0.02 元，可按套餐调整；最多 3 次默认合计预留 0.06 元。预留不是服务商真实账单。 |
| 研究向量请求 | Qwen 为可选项，按返回用量或失败估算记录；与网页搜索共用每项目人民币 1 元研究实验预算。 |
| 查询规划、参考分析 | 沿用选定文字模型，计入原项目美元预算。与人民币研究预算分别记账。 |

参考库与索引保存在本机，但必要项目资料、查询词和来源摘录会发送到本次所选服务；启用语义检索还会把必要参考文本和查询发送至阿里云。不是完全离线功能。实际计费和账户权限以服务商控制台为准。

失败时保留此前参考和本轮已采集资料，并展示来源报告；已发生用量不会撤销。可以修复连接后重新分析已保存参考，避免再次搜索。页面不会因打开而自动启动研究，也不会自动发布内容。

## 验证与后续

本版使用隔离合成数据和模拟接口验证，未调用真实付费搜索/模型、未读取真实平台账号。历史 v1.11.0 验证过公开 RSS 返回内容，不代表持续可用或全网覆盖。真实搜索账号权限、费用与分析质量仍需实测，见 [本版验证记录](VALIDATION-1.13.0.md)。

后续方向是抖音/TikTok 已授权来源、同作品多次快照和同类样本比较，以及用真实采用与修改记录评估检索效果。不能把这些规划描述成本版已经上线的能力。
