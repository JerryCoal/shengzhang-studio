# 生长 STUDIO 1.28.0 升级说明

本版安装并适配 Redfox 社区的四份小红书 Skills。在「创作」页面的「小红书创作助手 · Redfox Skills」中使用，在「连接与设置 → AI Skills → Redfox 小红书助手」中编辑默认规则或恢复出厂内容。

## 六个创作入口

- 创作图文：围绕主题和项目事实起草标题、正文与画面要求。
- 改写文案：保留原意，结合账号身份调整表达。
- 10 个标题：查看不同切入点、参考匹配分和理由，逐个选择。
- 标题六维评分：显示 0–10 分、S/A/B/C 等级、逐项理由、改进建议及替代标题。
- 3 套封面方案：查看画面、文字层级、配色与提示词，采纳后进入原有封面制作窗口。
- 正文四维诊断：显示 0–100 分、等级、优点与修改建议。

这些分数是模型辅助判断，不是小红书官方评分，也不代表流量或爆款概率。标题总分由六维分数按权重在本机计算；正文总分为四维分数的平均值。模型不能自行抬高总分。

## 使用步骤

先在创作页选择目标小红书账号，必要时选择已有成品。填写一个主题关键词，按需获取近 1、3、7 或 30 天的参考样本。参考默认折叠，可展开核对标题、可用原文、采集时间和来源。

获取参考通过 Redfox 小红书样本接口，当前基础费用为每次 ¥0.06，特殊关键词费用以服务实际提示为准。模型生成另行显示预算并确认；重复分析可以复用已经取得的样本。评分至少需要一条真实参考，不足五条会提示样本不足。其他模式可以没有参考，但结果会注明依据限制。

三家文字服务继续沿用工作站模型设置，每次只调用所选型号。封面可以额外开启「看图分析」，将最多十张参考样本的公开封面交给当前所选模型；现有 GPT-5.4 系列和 DeepSeek Flash 支持，DeepSeek V4 Pro、Qwen Plus/Flash 使用文字方案。不会悄悄换模型或同时调用三家。图片分析包含在本次预算确认中。

生成不会自动覆盖成品。查看结果后点击采纳；采纳前检查目标成品版本、账号与身份记忆是否仍匹配。未关联成品时，可以保存和复制结果。封面方案的采纳只填入设计要求，实际出图仍走现有制作窗口与费用确认。

## 保存与更新

四份默认 Skills、账号身份记忆和账号自选规则共同参与生成，任务记录保留当时版本。新功能不会清空旧规则、账号或历史成品。Windows 个人版和团队版支持完整功能；静态体验版与独立网页中转版不能发起本助手的付费请求。

退出旧版本，完整解压新包到新程序目录，继续使用原数据目录和登录方式。团队版先用旧包停止脚本关闭服务，再使用新包启动，保留主机密钥与运行用户。详细核验结果见同目录 VALIDATION-1.28.0.md。

社区源码完整保存在 vendor/redfox-community；工作站使用适配后的默认规则，不自动执行社区脚本或调用其使用记录上报接口。
