# 生长 STUDIO v1.19.1 升级与试用

更新日期：2026-10-16。**本地修复测试版，尚未上传 GitHub。** 本版针对外部小红书 MCP 的话题传递修复，沿用已有本机用户、项目、账号连接和登录资料。

## 升级

1. 在旧版托盘菜单选择“退出并停止后台任务”，避免两个版本同时操作同一工作区。
2. 取得本地测试包后完整解压到新文件夹，再运行 `ShengzhangStudio.exe`；不要只替换一个可执行文件。
3. 使用原来的 Windows 用户和工作站用户，核对项目及目标小红书账号。不需要删除数据目录、保险箱或重新创建登录资料。
4. 保留旧版安装目录及已有备份。已发布作品不会因升级自动补加话题；有提交记录的作品先核对平台结果，避免重复发布。

## 如何选择话题方向

已有“AI 文案 → 希望怎样修改？”可以直接填写方向，例如：

> 话题方向优先校园学习、大学生和自习室预约，请结合正文选择 3—6 个相关话题，避免无关热门标签。

模型会在正常文案生成中选择候选，仍按原来的生成流程和费用处理，不额外增加话题模型请求。新规则将候选放在正文末尾，以 `#校园学习 #大学生 #自习室预约` 的形式输出；候选本身不证明平台存在同名话题或正在热搜。

## 外部小红书 MCP 发布

1. 核对连接和实际账号，打开待发布内容的 MCP 发布弹窗。
2. 查看自动提取的“话题候选”，每行填写一个名称，也可用中英文逗号分隔；可以增加、替换或清空候选。清空表示本次不添加话题。
3. 修改正文后，如需重新采用正文末尾的话题，点击“从正文重新提取”。以候选列表和下方投送预览为准。
4. 检查正文与话题合计字数、素材和账号，再确认提交这一条内容。原成品正文与导出文件不会被本次编辑覆盖。
5. 到平台检查实际话题及作品链接，再登记发布结果。MCP 返回不代表每个候选都已成功关联。

本工作站限制为最多 10 个候选、每个最多 40 个字符；正文与话题合计不超过 1000 字，包含井号和分隔符。前两项是工作站输入限制，不是对平台统一规则的声明。

## 试用边界

旧正文末尾的 `#词`、`#词#`、`#词[话题]#` 均可提取，不要求重新生成历史内容。提取和手动编辑不产生 AI 费用。

内置页面助手仍需用户在平台选择话题；其他平台不启用本次独立候选编辑。外部小红书 MCP 可能选择首条建议或跳过未匹配项，且不返回逐项绑定状态。本轮未进行真实发布，详见 [验证记录](VALIDATION-1.19.1.md)。
