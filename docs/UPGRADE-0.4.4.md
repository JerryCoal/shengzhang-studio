# 生长 Studio 0.4.4 · 上手更轻松

本次重点是桌面端的新手教学与操作引导。Windows 0.4.3 保留可用；网络部署仍暂停。

## 第一次打开

登录后进入“工作台”，点击 **开始免费练习**。应用会为当前用户创建一个独立的“新手练习 · 山野咖啡”示例项目，预算为 $0。

1. 检查策略，点击“确认并开始制作”。
2. 在图文卡片上点击“本地模板制作 · 免费”，完成后点击画面预览。
3. 点击“导出素材包”，在下载位置查看图片与文案。

练习不调用付费模型、不自动发布。可以随时暂停；再次进入“使用指南”即可继续。步骤根据实际制作状态更新，重复开始不会覆盖已有练习或原有项目。导出完成状态表示已准备并发起下载，请实际检查保存的文件。

## 随时获得帮助

- 左侧“使用指南”、顶部问号和 F1 都可以打开内置指南。
- 搜索“Seedream”“密钥”“自动保存”“导出”“复盘”等词，即可查找对应操作。
- 项目、策略、制作、发布等页面增加“这页怎么用”。不需要时可以隐藏，在使用指南中重新开启。
- 引导进度与提示设置按本地用户独立保存，关闭应用后仍保留。

## 其他体验改进

- 工作台“新建项目”直接打开项目表单，不再需要多次跳转。
- 内容卡片明确标注“本地模板制作 · 免费”，导出改为“导出素材包”文字按钮。
- 工作台的下一步会跟随策略、制作、发布、评论复盘和下期策划进度更新。
- 使用指南解释了本地模板与付费 AI 的区别，以及“加入发布计划”与“已发布”的区别。

## 正式使用

完成练习后，点击“创建自己的项目”，填写真实品牌资料并导入项目介绍文档。文本可选 OpenAI 或 DeepSeek；关键帧可选 GPT Image 2 或火山 Seedream；视频可接 Seedance。各服务仍需用户自行配置有效密钥、模型权限与额度。敏感词筛选、语料检索和自动保存沿用原有功能。

## 更新方法

1. 从旧应用的托盘菜单选择“退出并停止后台任务”。
2. 将新压缩包完整解压到一个新文件夹。
3. 双击 `ShengzhangStudio.exe`，使用原来的本地用户登录。

用户数据保存在 `%LOCALAPPDATA%\ShengzhangStudio`，独立于程序目录。新版本不会清空旧项目和 API 设置。请牢记登录密码；导出的工作区备份不含 API 密钥，且是明文文件。
