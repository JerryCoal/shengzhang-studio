# v1.27.0 默认 Skills 编辑

工作站已有的默认规则现在可以按工作步骤分别编辑。版本继续沿用 Redfox 测试版的服务范围，保留热点研究修复与素材折叠。

- 在「连接与设置 → AI Skills → 工作步骤 → 默认规则 → 编辑规则」修改现有正文，并显示有效版本及「已自定义」状态。
- 每个步骤的每份规则独立保存；正文要求非空，UTF-8 上限为 24 KB。
- 支持下载草稿、取消、查看出厂原文及确认恢复出厂规则。
- 使用统一 Skills 版本检查防止覆盖其他修改。发生冲突时保留草稿，重新读取不会自动把草稿改为最新版本。
- 新请求使用保存后的有效规则快照，已运行任务继续使用原快照；账号身份记忆与已选自装补充规则继续叠加。
- Windows 个人版按用户隔离，团队版仅管理员可编辑共享默认规则；规则随加密工作区与备份保留。
- 静态体验版可以管理规则。独立联网网页中转版只读，遇到当前步骤已有定制规则时会阻止生成并提示使用完整版。
- 「联网新闻搜索」规则作用于千问联网搜索；Redfox 按关键词检索，不使用这一份规则。

全量 859 项测试中，857 通过、0 失败、2 项 Python 环境检查跳过。Skills、类型检查、各版本前端及个人和团队程序包构建通过；个人程序包 18 项、团队程序包 9 项检查通过。

浏览器已实际核对默认规则的编辑、保存、重开、取消、恢复及空白禁用。多标签冲突、移动宽度和下载落盘未实测。详细结果见 `VALIDATION-1.27.0.md`；本次未调用真实付费 DeepSeek 或 Redfox 服务进行验证。
