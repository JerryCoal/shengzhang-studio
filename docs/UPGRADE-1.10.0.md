# v1.10.0 本地测试版：Qwen 语义语料检索

保留 v1.9.0 的十二份内置 Skills、自装文案规则和已有工作流程，新增可选的项目语料混合检索。

1. 完整解压并运行 `ShengzhangStudio.exe`，登录原本的本地用户。原有数据目录不变。
2. 在“连接与设置”保存阿里云百炼北京地域 Qwen API Key。文本模型连接成功不保证 `text-embedding-v4` 的向量调用权限，请在控制台确认。
3. 打开项目的“语料库”，导入并启用需要参与检索的文档。
4. 在“Qwen 语义检索”中预览段落数与人民币费用估算，阅读云处理说明，确认建立索引。每次最多 200 段。
5. 输入自然语言查询验证出处；启用后生成策略、下期策划、普通 AI 文案也会自动检索相关资料。文案模型仍可自行选择。

Qwen 只负责计算语义向量，工作站在本机结合关键词匹配结果排序。文档和向量索引在当前用户本地加密保存，但建立索引时待处理原文、查询时的问题会发给阿里云，命中片段还会发给当次生成模型。不是完全离线功能。

修改语料后，旧索引不再用于语义检索，需要手动更新。可随时关闭语义检索或清除索引；语料与已发生用量仍保留。每个项目设 1 元人民币的向量实验累计预算，与文案美元预算分开；预算或密钥不可用时回退关键词。服务商实际费用以控制台为准。

纯静态网页、联网中转网页及旧式未加密工作区继续用关键词检索。Windows 本地工作区的浏览器页面同样可用。新闻与自媒体热点采集未在本版新增；评论统计没有改成抽样检索。

本轮用模拟响应验证功能、费用和隐私边界，没有调用用户真实密钥。真实同义词召回质量需用少量非敏感资料试用。详见 [Qwen 检索设计与官方来源](QWEN-RAG.md)。

安装包附有 `语义检索体验资料.txt`，内容是明确标注的虚构校园项目。可导入后依次查询“想找个人一起学习”“晚上几点结束”“是不是要交钱”“能帮我做作业吗”。核对返回原文与出处，再生成一份测试文案；不要把虚构事实用于真实宣传。
