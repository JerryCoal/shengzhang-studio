# 生长 STUDIO v1.3.4 · 评论自动加载与采集

这一版优先减少手动滚动和展开：在 Windows 应用内打开自己的小红书 / 抖音作品，完成登录后点击一次「开始自动采集」。程序按轮次读取当前已加载的文字评论，再滚动评论区；勾选「包含回复」时还会自动点击页面中的展开回复控件。

## 使用方法

1. 在「发布中心」登记自己已发布作品的正确链接。
2. 进入「评论与复盘」→「导入评论」→「网页辅助采集」，选择作品。
3. 选择本次数量上限：50 条适合快速查看，200 条适合日常复盘，1,000 条适合较大的批次；按需勾选「自动展开并包含回复」。数量包含回复，是上限而非保证采集数量。
4. 点击「打开作品与采集面板」。在下方官方网页完成登录或打开评论区，然后点击顶部「开始自动采集」。登录和验证码仍需你自行完成。
5. 顶部显示已采集条数、回复数、轮数和状态。可随时「暂停」，处理页面提示后「继续自动采集」；也可「只读当前页」。开始取得评论后，本批次的数量和回复设置会锁定。
6. 点击「返回预览」，用关键词筛选和勾选内容，核对作品归属后点击「导入所选评论」。筛选仅影响显示，不会取消已勾选的评论。
7. 继续原有评论分类、人工校正、复盘及品牌经验流程。

如果关闭采集窗口前已有内容，会询问返回预览、留在窗口或放弃。评论尚未导入时只在本次窗口内存中暂存；退出程序后无法恢复。确认导入后才保存到当前用户的本地加密工作区。

## 自动停止与继续

- 读取当前批次后才滚动；边读边按评论 ID / 文本合并，减少网页移除早期评论节点时的漏采。
- 到达选定数量或 12 万字符时停止。每条最多 4,000 字符。
- 连续 5 轮没有新增且没有继续滚动时暂停；单轮运行最多 60 次，每次操作间隔约 4 秒。需要时可检查后继续。
- 网页显示没有更多评论、要求登录验证、切换作品或加载出错时暂停，保留已经读到的内容。
- 采集窗口 30 分钟到时后，已有内容会返回工作台预览；仍需你确认导入。

抖音个人主页的作品弹窗链接会转换为同一作品的独立详情页。短链接需要先在平台页面解析到作品详情；必要时使用窗口菜单「打开独立作品页（抖音）」。无法自动识别页面时，可选中评论文字，点击「读取选中文字」备用。该方式可能混入昵称、日期和按钮文字，务必在预览里排除。

## 范围与限制

这是官方网页的辅助读取功能，不保证采集全部评论。总数可能包含未显示的回复、图片或受限内容，页面变化也可能导致读取失败。纯图片评论不做识别；无法确认的点赞数留空，日期按页面显示保留，不推算年份。

采集与自动滚动本身不调用付费模型。AI 分类与复盘仍按所选模型用量计费。只应导入自己的已发布作品；程序校验链接与作品一致性，但不验证账号所有权。

平台页面与工作台控制区分开运行，使用临时登录会话，远程页面不能调用工作台的本地接口。程序不提取登录密码或 Cookie，也不调用私有签名接口。关闭采集窗口清除本次平台会话，下次可能需要重新登录。

该采集窗口仅适用于 Windows 应用。网页版保留粘贴 / TXT / MD 导入，已有抖音接口权限时仍可使用独立的官方评论同步。两平台发布继续全部手动。

## 更新安装

在旧版系统托盘菜单选择「退出并停止后台任务」，完整解压 `Shengzhang-Studio-1.3.4-windows-x64.zip`，打开其中的 `ShengzhangStudio.exe`。同一 Windows 账户下继续使用 `%LOCALAPPDATA%\ShengzhangStudio` 的数据，不需要复制旧程序文件。旧版 v1.3.3 安装包保留，本次未上传 GitHub。

## 验证说明

页面读取规则沿用 v1.3.3 对用户提供的两条公开作品的检查结果；本次另核对了小红书笔记内滚动容器、展开回复控件和登录提示，以及抖音整段评论列表和结束提示。自动多轮、暂停继续、虚拟列表缓存、上限和验证暂停使用可重复的模拟页面测试。没有使用真实平台账号验证大批量采集，不把模拟结果当作平台全量采集承诺。
