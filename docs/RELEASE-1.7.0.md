# 生长 STUDIO v1.7.0 · MCP 与 Qwen 开发进度测试版

保存于 2026-10-14。应用户要求暂停后续开发并上传当前进度；不是正式生产版。

## 更新内容

- 新增平台 MCP 设置：Windows 内置小红书/抖音官方页面助手，小红书可配置社区 `xpzouying/xiaohongshu-mcp`。
- 发布中心支持 MCP 单条投送：自动准备素材文案、用户确认后执行；结果不明锁定，防止重复投稿。
- 评论支持 MCP 采集、预览选择、去重导入，保留人工分类。
- 新增 Qwen Plus / Flash 文字接口和分步骤模型选择，继续支持 DeepSeek、OpenAI。
- Qwen Key 与可选 MCP 令牌按本地用户加密保存、重启保留，备份不含密钥。

## 验证与限制

226 项本地回归全部通过；离线 Electron 验证了两个平台的自动填草稿、取消不发布、确认后单次提交，以及各 3 条模拟评论的自动采集返回。

**外部小红书 MCP 真实握手尚未成功，真实账号发布/采集、真实 Qwen 付费生成及新界面完整验收尚未完成。** 请先测试内置连接，不把社区 MCP 适配视为已完成实机联调。详细进度见仓库 `docs/DEVELOPMENT-HANDOFF-1.7.0.md`。

## 下载和升级

下载下方 `Shengzhang-Studio-1.7.0-windows-x64.zip`，完整解压后运行 `ShengzhangStudio.exe`。升级前从旧版托盘退出后台。原有用户数据继续保存在本机，v1.6.0 测试版及 v1.2.0 正式版仍保留。

入口：连接与设置 → 文字模型 / 账号与发布；发布中心 → MCP 投送；评论分析 → MCP 获取评论。

排期不会自动触发无人值守发布。平台登录、验证码及最终内容确认仍需用户处理。GitHub 静态站不能替代本机 MCP。
