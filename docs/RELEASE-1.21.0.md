# 生长 STUDIO v1.21.0

- 新增设置中的独立 **AI Skills** 页面，按五类展示 20 个 AI 工作步骤，每一步有默认规则和自装规则下拉列表。
- 导入 Skill 时先指定步骤，切换步骤或改动正文必须重新预览。允许同一文件分步骤使用，保留旧文案 Skill 的兼容范围。
- 策略、各平台文案、审核、评论、资料提取、研究、封面、首尾帧与视频生成接入中央选择。运行中冻结规则快照，禁用或删除自动回到默认。
- 生成界面显示本步规则摘要；媒体提示词预览包含所选规则，过长时提示精简。文字预算与关键帧输入预留包含规则成本。
- 保留用户隔离、现有敏感词配置、原文证据校验与发布确认。
- 累计包含 v1.20.0 介绍文档自动填写项目概要及 v1.19.1 小红书话题传参修复。

本版为本地 Windows 升级包，尚未上传 GitHub。功能边界与测试结果见 `VALIDATION-1.21.0.md`。
