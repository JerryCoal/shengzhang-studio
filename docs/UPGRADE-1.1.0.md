# v1.1.0 · 抖音授权与自动运营流程

本版完善抖音官方接口接入，保留 v1.0.0 的项目、语料、策略、图文视频生成、热点和本地用户功能。

- 设置中新增完整的六步开通指南、权限对照表、常见问题和官方控制台链接。
- Windows 优先在应用内打开抖音官方授权窗口，完成后自动返回；失败时提供浏览器授权与手动回调入口。内置窗口为隔离临时会话，不具备本地文件或 Node 操作能力。
- 可以分别授权发布、评论功能；可选授权作品列表，从账号中选择已有公开视频。
- 发布确认时可选择审核公开后自动获取评论，支持 5、15、30、60 分钟间隔。
- 修正评论接口每页数量为官方规定的最多 20 条；保留分页续采、去重、人工分类和互动数据更新。
- 显示最近同步、本轮新增、更新和下次检查时间，停止时保留已有评论。
- 平台授权过期会提示重新连接抖音，不再把它误当成工作台本地登录失效。

完整说明见同目录的“抖音开通与使用指南.md”，或工作台“连接与设置 → 抖音发布与评论”。应用拥有接口权限且用户完成授权后，才能实际执行投稿与评论采集。

## 更新方法

完整解压新包，关闭旧版后运行新目录里的 `ShengzhangStudio.exe`。本版与 v1.0.0 使用相同的本地数据目录，安装包不含用户数据，不需要覆盖或删除原数据。记得本地登录密码；应用不把账号或密钥上传到公共仓库。

原版仍可保留作为安装文件备份，但请勿同时运行两个版本操作同一工作区。自动任务需要登录工作区并保持电脑联网、唤醒；完全退出应用会停止任务。

本次尚无已开通权限的真实抖音应用，交付不代表已经完成真实平台授权、内容审核或真实评论采集验证。
