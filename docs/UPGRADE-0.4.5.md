# 生长 AI 运营工作台 · Windows 0.4.5

本版增加 Seedream 小红书封面生成、分步骤提示词和快捷输入辅助。保留 0.4.4 的本地加密账户、自动登录、项目草稿自动保存、语料库、敏感词库、免费练习与使用指南。

## 更新和打开

退出旧程序（托盘菜单 → 退出并停止后台任务），完整解压新版本，双击 `ShengzhangStudio.exe`。同一台电脑、同一 Windows 用户下，原来的本地账户、项目和密钥可继续使用。请不要只复制 EXE；数据另存在 `%LOCALAPPDATA%\ShengzhangStudio`。旧版压缩包已保留。

## 用 Seedream 制作小红书封面

1. 在“连接与设置 → Seedream 封面与关键帧”配置已开通的模型与火山方舟 API Key。以前保存的 Seedream 配置可直接复用，无需 OpenAI 或 Seedance 密钥。
2. 为正式项目填写真实产品资料，设置足够的模型预算，选择小红书渠道，生成并确认策略。新手免费练习项目预算为 $0，不能发起付费请求。
3. 在“内容制作”上传真实产品图（可选但建议），在小红书图文卡片点击“AI 封面 · Seedream”。
4. 选择自然生活感、简洁产品摄影或杂志风格，选择构图及是否使用当前标题；补充场景、光线等要求。可以点击快捷标签，也可以展开语料引用。
5. 展开“查看将发送的提示词与资料”，核对品牌事实、产品参考图、相关语料、模型及预算预留，然后点击“确认并生成封面”。生成期间保持应用运行。
6. 检查候选图中的产品外观、文字、标识和留白，满意后点击“确认采用为封面”。之后可预览、导出素材包，原成品作为历史版本保留。

输出为单张 1728 × 2304（3:4）静态封面，支持服务商返回的 PNG 或 JPEG。视频首尾帧仍为 1440 × 2560（9:16），Seedance 继续用于视频。

请求会先检查预算与版本，再保存任务；重复点击不会重复提交。网络超时等无法确认是否扣费的情况会锁定重试，需先核对火山方舟记录，再手动解除。生成期间修改文案时，旧候选图不能覆盖新版本。重新生成可能再次收费，采用已有候选图不再次调用模型。

## 更快填写输入

- 项目目标、受众、卖点、事实、表达要求、策略方向、文案和画面要求提供适合当前步骤的标签；点击会追加，未继续编辑时可以撤销添加。
- “从本项目语料库引用”按关键词检索当前项目启用的介绍文档，显示文档名和段落，核对后引用原文。新建项目不会检索其他项目资料；先保存项目并导入文档即可使用。
- 事实模板中的“待补充”需要填写真实内容。标签不会替你编造价格、参数或产品效果。
- 检索在本地完成，不调用付费模型。实际生成时，相关资料会随请求发送给所选服务商。本版是关键词检索，不包含向量模型或跨设备同步。

## 提示词的使用方式

每一步可展开“本步骤的输入与输出”；封面、首尾帧和视频支持查看实际组装的提示词。已确认策略中的资料优先，资料与评论作为参考数据；生成提示词保留规范版本和引用来源。画面提示词最多带入 3 段语料，长字段截取时会明确标注。详细规则见同目录的《提示词与输入辅助说明》。

策略写目标和方向，文案写标题与正文，封面写静态构图，首尾帧写起止状态，视频写连续动作与运镜。已有手动提示词保留，新流程按步骤添加明确边界。

敏感词库继续用于文字筛选，并在提交画面提示词前执行匹配替换。它不能检查生成图片里的文字或判断全部语境；采用和发布前仍需人工核对。

## 验证范围与保留进度

封面请求、预算、错误恢复、版本保护、语料引用和 PNG/JPEG 导出通过模拟服务响应验证；打包后使用独立测试账户验证本地加密与升级。未使用用户密钥发起付费出图，实际图片质量、账户权限和额度需要在你的火山账户上验证。

Windows 应用为本地完整版本；网页源码同步适配了新流程。本次继续暂停公网部署和上传，未变更旧网站。
