# Shengzhang Studio v2.0.1 · 本地修正版

本轮仅生成本地个人版和团队版，不上传 GitHub，不覆盖原 v2.0.0。保留既有技术架构、账号与数据。用户第十项“对话式创作”尚未批准，本版没有实施该交互改造。

## 本轮修改

1. 发布中心新增多选批次：可选择当前范围内不同项目、平台的已完成作品，逐条核对素材、运营账号、MCP 连接和平台选项，再统一确认。不同平台并行，同平台和桌面页面助手顺序执行；每条独立记录回执，不因失败重发整批。另支持多选平台账号建立独立改编草稿，不把一篇内容未经调整原样发到所有平台。
2. 修复经验复选框被全宽输入样式撑开、标题与正文被挤走的问题。经验文字与账号归属保持可见，非目标账号的私人经验不会混入生成。
3. 官方 Seedream、Seedance 的可选水印默认关闭；继续支持用户明确选用水印。此处不是删除现有图片中的版权标识，也不绕过平台强制 AI 标识。
4. 项目与账号选择移到左侧栏上部，支持多选查看与批量操作范围。主栏目常驻显示选中项目、账号和当前主编辑项目；一次创作仍使用一个明确项目，不混合项目资料。
5. 研究失败增加安全的故障分类、失败阶段与下一步提示，区分服务未启动、认证、登录、浏览器依赖、格式和详情失败。已取得的搜索摘要可保留为未核实线索，旧参考不会清空；没有有效内容时不发起新的 AI 分析。
6. 图片不可显示时继续展示已取得的标题、正文、来源描述及已有图片分析。来源文字描述与实际视觉分析明确区分，不把“有图片链接”当成模型看过图片；图片加载需用户主动选择。
7. 增加独立本地 Qwen 接口，兼容 Ollama / vLLM 的 OpenAI 兼容服务。仅访问工作站主机的回环地址，密钥与官方 Qwen 分开加密，连接探测只读取模型列表；不自动下载模型、不转用付费云模型。说明见 `LOCAL-QWEN-SETUP.md`。
8. 收紧发布页空白、卡片与按钮布局，修复勾选项宽度及窄屏换行；实际视觉验收限制见验证记录。
9. 将本地 MCP 管理入口集中展示：Windows 小红书/抖音支持选择已准备的主程序并启动、停止和查看状态；保留手动配置连接，只有再次确认才替换当前连接。其他平台提供适配说明与可复制给模型的部署核对文本，不声称任意 MCP 都已内置或可一键安装。

## 使用边界

Wereus 当次失败只有用户提供的汇总提示，未取得对应详细来源报告，不能宣称已确认或修复其实际登录/服务故障。本版先修复明确存在的诊断信息丢失与内容展示问题；请在新版重新核对服务，必要时提供脱敏来源报告。

未使用真实账号投送、付费生成或安装第三方模型服务。当前浏览器控制实例不可用，界面依据用户截图、结构渲染测试和 CSS 回归检查，未声称已完成实际点击和逐像素验收。Windows 与团队打包后端验证另见 `VALIDATION-2.0.1.md`。
