# v1.3.0 敏感词自检升级

这次升级增加可编辑的处理方式、命中位置、修改预览与复检。原有项目、用户和自定义替换词仍按原方式保存在本地。

## 开始使用

1. 在旧版托盘菜单选择“退出并停止后台任务”，完整解压新版，打开 `ShengzhangStudio.exe`。不要仅复制 EXE。
2. 打开“连接与设置 → 敏感词与替换词库 → 管理词条与替换方式”。旧词条继续使用原来的固定替换。可点“补充示例词条”，检查合并结果后保存，获得上下文改写示例；同名词不会覆盖你的设置。
3. 选择处理方式：**固定替换**用你指定的文字（空白表示删除）；**上下文改写**只提示、不机械替换；**允许词条**豁免精确匹配的文字。允许词条不豁免整段，长词优先。
4. 可导入或导出 UTF-8 TXT / CSV，也可以继续粘贴原来的 `敏感词=替换词`。导入先合并到编辑列表，点击“保存词库”才生效。
5. 到“内容工作室 → 编辑与自检”。标题和正文实时显示命中位置：黄色是固定替换，橙色是上下文改写。可展开具体位置与修改预览，点击“应用固定替换 · 免费”。
6. 仍有待复核词时，点“AI 处理待复核词”。它使用设置中“文案”步骤选择的 OpenAI 或 DeepSeek 模型；确认费用后只调用一次。原文保留，返回候选并再次本地检查。
7. 核对候选，点“采用到编辑框”，再点“保存修改”。采用不等于保存。若词库、文案或成品版本已变化，需要重新生成候选。
8. 修改标题后重新制作画面；最后导出并在平台手动发布。

## 词库与表情

推荐格式：`敏感词|处理方式|推荐替换|风险类型`。

```text
最好|replace|更适合|A
治愈|rewrite||M
官方认证|rewrite||Q
[笑哭R]|allow||E
❤️|allow||E
```

A 表示夸张承诺、M 表示功效表达、Q 表示资质依据、P 表示平台表达、E 表示表情。它们是便于复核的分类，并不是官方禁词判定。支持自定义英文数字分类名。

导出增加第五列 `enabled`，保留停用状态。文件使用 UTF-8，普通 Emoji 和平台表情文本可原样复制。`❤️` 和 `❤` 底层字符不同；不会自动去除变体选择符或连接符。平台表情代码不保证在导出文件或其他平台渲染成图形。

本地检查、固定替换和复检免费且不联网。AI 改写按服务商计费，只发送当前标题、正文、命中信息和必要的项目事实，不把完整词库塞进模型提示词。静态体验版保留本地检查，AI 仍需可用后端。

## 使用边界

这是一套辅助检查，不是法律意见或平台审核保证。词库可能误报或漏报，固定替换可能造成语病；需要结合完整语义核对。已有图片或视频中的文字不会被 OCR 检查，也不会随着正文修改自动重绘。AI 残留词会继续提示，不会无限重试产生费用。

应用运行筛查使用内置 JavaScript，不要求用户安装 Python。包内另附 Python 3 本地检查器、基础词库、两份 SKILL.md 和开发交接文档，供二次开发使用。发布流程继续全部手动完成。
