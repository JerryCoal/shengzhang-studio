# 生长 STUDIO v1.19.1

日期：2026-10-16。**本地修复测试版，尚未上传 GitHub。** 本文不代表已有公开下载或完成真实平台发布验证。

本版修复外部小红书 MCP 发布时固定传入空话题列表的问题。原来正文中的 `#话题` 只是文字，发布工具没有收到独立话题候选；现在会分离正文末尾的话题，并在提交前让用户核对、增删候选，再分别交给 MCP。

## 更新内容

- 外部小红书发布弹窗增加话题候选编辑、从正文重新提取和实际投送预览。兼容正文末尾的 `#词`、`#词#`、`#词[话题]#`。
- 本工作站最多接受 10 个候选，每个最多 40 个字符；正文与话题合计不超过 1000 字，包含井号与分隔符。10 个和 40 字符是工作站输入限制，不代表平台公布的统一规则。
- 小红书与通用写作 Skills 统一输出格式：优先用户指定的主题、受众和使用场景，默认将 3—6 个 `#词` 候选放在正文末尾，以空格分隔。不生成 `[话题]`、HTML 或虚构话题 ID，不将候选说成热搜或已关联话题。
- 本次提交记录保留实际候选及“关联未核验”状态；原成品、历史正文和导出原文保持不变。提取、编辑和传递话题不额外调用模型。

## 使用与边界

在“AI 文案”的“希望怎样修改？”中可写：“话题方向优先校园学习、大学生和自习室预约，请结合正文选择 3—6 个相关话题。”生成后，在外部小红书 MCP 发布弹窗核对候选、账号和投送预览，再确认本次提交。

外部 MCP 可能选中搜索建议的首项，也可能因没有匹配项而跳过；当前返回结果不提供逐项话题绑定状态。候选已传入不等于平台已关联成功，提交后仍需在平台检查实际话题和作品链接。本轮没有执行真实发布。

独立话题编辑仅用于外部小红书 MCP。内置页面助手仍需在平台手动选择话题，其他平台的发布方式不变。
