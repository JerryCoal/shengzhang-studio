# v1.15.0：阅读设置与 MCP 启动引导

## 调整字体与重点显示

进入「连接与设置 → 外观与阅读」。

- 字号有标准、舒适、大字、特大四档，选择后立即预览并自动保存。
- 打开「重点文字加重加深」，界面标题、操作步骤与关键提示更清晰；内容制作卡片、文案详情、编辑与自检阅读区会突出项目名、品牌、产品、卖点短语及已确认标签。
- 输入框、复制内容与导出文件仍保持原文。这里是阅读辅助，不会让 AI 自动判断重点，也不代表已通过敏感词检查。
- 偏好按当前用户在本地加密保存，重开应用后继续使用。不同用户互不影响。保存失败时保留预览，可点击「重试保存」；保存期间暂不可退出当前用户。
- 等待 AI 回复时也可以调整。点击「恢复默认」可回到标准字号并关闭重点强调。

字号调整覆盖导航、正文、表单与弹窗，不缩放制作出的图片或视频。

## 如何启动外部 MCP

进入「连接与设置 → 账号与发布」，选择对应平台的外部 MCP。按页面上的三个步骤操作：

1. **下载并解压**：点击项目发布页，下载对应 Windows 程序。小红书选择主程序 `xiaohongshu-mcp-windows-amd64.exe`，不是单独的登录工具；抖音选择该项目提供的 Windows 服务程序。
2. **由工作台启动**：点击选择并启动程序，选择解压后的主程序。启动成功后，工作台会保存连接并检查能力。首次使用可能需要准备浏览器或驱动；如果仍在启动，按页面提示稍后重试连接检查。
3. **登录平台**：按页面提示扫码或在官方窗口登录，随后检查登录状态。模型 API 密钥不能代替小红书或抖音账号登录。

如果外部 MCP 已由你自行启动，展开「手动填写连接」，填写它实际提供的地址与令牌，再点击「保存并检查连接」。填入地址不代表已经启动服务；提示未连接时，先确认该程序仍在运行。

外部 MCP 可以集成。本版已经集成选择程序、启动、连接检查和登录入口，但没有把第三方主程序与浏览器依赖一起打包，也不会自动下载执行它们。第三方版本、所需浏览器和登录状态需要分别管理；应用内已展示的可用工具决定当前能执行哪些动作，连接成功不等于已经登录或拥有所有平台能力。

参考：[小红书 MCP 官方仓库](https://github.com/xpzouying/xiaohongshu-mcp#readme)、[抖音 MCP 项目仓库](https://github.com/panwenda/douyin-publish-mcp#readme)。本版保持最终发布前由用户核对确认。

## 更新应用

等旧版任务完成并保存结果，从托盘或应用菜单选择「退出并停止后台任务」。完整解压 v1.15.0，再双击 `ShengzhangStudio.exe`。不要只复制 EXE，也不要删除旧用户数据；应用沿用原来的本地工作区。

本版为本地测试版，尚未上传 GitHub。验证使用隔离测试用户与模拟网络响应，没有进行真实付费生成或真实平台发布。
