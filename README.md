# 生长 · 个人运营工作台

用于 GitHub Pages 的独立静态发布包。页面位于 `docs/`，发布源为 `main` 分支的 `/docs` 目录。

支持注册与登录、独立本地用户、项目资料、模板策略、图文和短片制作、素材导出、手动发布记录、评论导入与复盘。

账号和工作区数据仅保存在访问者当前浏览器中，使用登录密码派生的 AES-GCM 密钥加密。刷新或退出后需要重新登录，不上传工作区数据、不跨设备同步，没有密码找回。清除站点数据会删除本地工作区。

AI 生成及平台自动发布、评论同步需使用本地完整版；此静态页面不接收 API 密钥。

首次打开网站，选择「注册本地用户」开始。静态资源、PWA 图标和离线缓存兼容 GitHub Pages 仓库子目录。
