# 生长 STUDIO v1.4.0 · 平台发布助手与评论读取

本次按“登录官方页面 → 上传素材 → 填写文案 → 用户核对发布 → 回收评论”开发。独立实现，没有包含 Spider_XHS / DouYin_Spider 的源代码、签名算法或依赖。

## 发布助手（Windows）

1. 在内容制作完成成品，然后进入发布中心，点击 **打开发布助手**。
2. 在预览中调整本次标题、正文；原成品保留。两个平台的标题暂按 20 字、正文按 1,000 字进行保守预检。最终限制以平台编辑器为准。
3. 打开官方发布助手，在窗口内自行登录自己的账号。进入平台的图文或视频发布页。
4. 点击 **① 上传本次素材**。支持 PNG、JPG、MP4，WebP 在本地转 PNG；单次一张图片或一个视频，最大 128MB，小红书图片最大 32MB、抖音图片最大 50MB。等待官方页面显示上传或转码完成。
5. 点击 **② 填写标题与正文**。不会覆盖平台输入框里已有的不同文案。如果编辑器无法识别，使用复制标题、复制正文与另存素材。
6. 自行核对实际账号、话题、@ 提及、封面、素材完整性、可见范围和平台要求，再亲自点击平台的发布按钮。本应用不会点击最终发布、保存草稿、勾选协议或选择可见范围。
7. 平台确认发布成功后，返回工作台添加待办、登记真实作品链接，之后采集评论。

“已交给平台上传”仅表示文件已选入上传框；“文案已填写”也不代表已经保存或发布。平台草稿是否保存以官方页面提示为准。未改变旧版本定时待办和自动发布任务的关闭状态。

## 评论采集

在评论页关联自己的真实已发布作品，打开采集面板，按需选择上限与包含回复，再开始。

- 读取官方网页自身收到的当前作品评论响应，取得评论 ID、文字、点赞、时间和回复标记。
- 继续自动展开回复、滚动评论区，分批合并；页面文字读取作为补充。
- 按 ID / 内容去重、校验作品归属。昵称、个人主页、IP 地区与 Cookie 不进入导入记录。
- 达到上限、无新增、登录失效或验证时暂停，保留当前结果；返回预览后由用户确认导入。
- 不保证采集全部评论，平台折叠、删除、未加载或权限不可见的评论可能不在结果中。

## 登录与数据

每次官方窗口使用独立临时会话，不读取其他浏览器的登录状态；正常关闭后清理临时会话与上传暂存文件。项目、模型密钥和其他素材不会传入官方发布页面。所选素材与填写的文案会发送给对应平台，平台可能自动保存草稿。不会要求在聊天中提供 Cookie、验证码或密码。

## 验证范围

本地自动化测试与真实账号验收分开记录。发布助手的表单适配、平台上传结果和登录后的评论分页仍应以真实账号实测为准。未完成真实测试的平台不能标记为“全流程已验证”。浏览器连接器中的登录与 Windows 临时窗口互不共享。

源码参考资料：[Electron Debugger](https://www.electronjs.org/docs/latest/api/debugger)、[DOM.setFileInputFiles](https://chromedevtools.github.io/devtools-protocol/tot/DOM/#method-setFileInputFiles)。本实现仅将选中的临时素材文件交给官方网页上传框，并读取已加载的评论响应。

更新方法：退出托盘中的旧版，完整解压新版后运行 ShengzhangStudio.exe。保留原有 %LOCALAPPDATA%\\ShengzhangStudio 数据目录；无需删除旧版或重新导入项目。
