# v1.25.0 本地团队版

按照浏览器 → Caddy HTTPS 反向代理 → Node 应用 → 共享加密数据目录的结构新增团队部署模式。个人版、联网浏览器独立存储版与静态版保留。

- 主机管理团队身份、会话、限流和加密主密钥；关闭本机免密码快捷登录和自由注册。
- 初次管理员通过一次性主机初始化码建立，管理员管理创作者、发布员及其他管理员。
- 独立区分密钥管理、内容创作和发布权限；接口与界面同时提供权限反馈。
- 共用项目和账号资料，按成员隔离当前账号、创作方案、未保存草稿与新项目文档提取记录。
- 活动与后台媒体任务记录操作人，成员退出不会停止其他任务。
- 复用 AI、RAG、研究和外部 MCP；针对并发切账号、重复提交和旧视频查询回写增加保护。
- 新增 Windows 启动、停止与 Caddy 配置文件；无防火墙或系统服务自动变更。

本地交付包、使用步骤与验证结果分别见团队部署文档及 `VALIDATION-1.25.0.md`。本版本没有上传公开 Release，也没有使用真实平台账号进行发帖验证。
