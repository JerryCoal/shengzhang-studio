# Shengzhang Studio 2.3.0

制作界面改为连续聊天：在总控底部输入需求，计划、Agent 进度、文案、图片及发布结果都保留在同一段对话中。

- 总控规划、Agent 派工、图片生成与发布分别弹窗批准。派工前可修改指令，明确选择 Skills 或默认规则，并核对费用。
- 展示真实执行步骤、依赖依据和结果状态；不展示隐藏推理，不伪造进度百分比。
- 需求发送即保存。取消批准、刷新或重新打开后能继续；同一需求的重复批准只启动一次规划。
- 续聊保留原需求、补充问答和回复任务。输入“生成两张图片”“这篇可以发布了”可打开对应核对窗口；消息本身不授权生成或投稿。
- 修订文案时，总控和写作 Agent 都取得当前已采用稿件的固定版本。批准前版本变化会阻止旧请求，执行中的新编辑继续受候选版本保护。
- 图片逐张生成、检查和采用后，在总控内选择成品并核对平台投稿，或导出后手动发布并登记真实作品链接。未知提交状态不能直接重复投送。
- 继续保留 2.2.0 的自装 Skills 编辑、终态任务删除和历史数据兼容。

本轮以 Windows x64 个人版和源码预发行包提供。当前聊天发布每次提交一张图片和文案，不支持自动合成多图帖子；脚本配图不代表生成视频。真实模型、图片、平台连接和权限需要用户自行配置。已知边界与验收范围见 VALIDATION-2.3.0.md。
