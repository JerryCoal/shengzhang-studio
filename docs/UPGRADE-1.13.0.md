# v1.13.0：用已有密钥完成内容研究

这次把联网研究改成三种可选方式，不再要求先申请火山搜索密钥。原有项目、密钥、MCP 和创作功能保留。

## 最少配置：公开新闻 + 已有文字模型

1. 在“连接与设置 → 文字模型”配置你已经使用的服务，为规划与分析选择可用模型。
2. “联网检索”选择“公开新闻”，保存。
3. 打开“热点与灵感”，填写项目关键词，勾选“公开新闻”，点击开始研究。
4. 核对原文、日期和分析，再选用标签进行创作。

新闻采集不需要搜索 API Key，也不收取搜索服务费；AI 规划与分析仍按你选择的文字模型用量计费。来源范围是已配置的公开新闻订阅源，不等于全网热榜。

## 集成方案：复用 Qwen 密钥

如果文字生成已经使用北京地域的 Qwen，可以在“联网检索”选择“Qwen 联网”，保存即可，不需要再输入搜索密钥。想只使用这一家文字服务，可在“文字模型”点击“文字任务使用 Qwen 分工”并保存。研究时勾选“联网网页”，也可同时勾选公开新闻补充来源。

单次研究把本轮关键词组合成一次 Qwen 联网请求，省去额外的 AI 扩词步骤。程序只接受接口实际返回的来源链接，再读取最多 6 个公开网页，核对原文和明确的发布时间。读取失败、只有模型回答或时间不明确的结果会放在“待核实线索”，不会伪装成近七天热点。

本次适配北京地域的 qwen-plus。其他地域不自动改址或转发密钥，可继续用公开新闻。已有的北京 Qwen 密钥也可用于可选语义检索；默认本地关键词检索不额外调用向量模型。文字模型、搜索、向量仍是不同计费能力，即便共用一个密钥也不代表免费。

## 可选高级方案：豆包搜索 Custom版（火山）

原“联网搜索 / 融合信息搜索”现名为“豆包搜索 Custom版”。它的搜索密钥与 Seedream / Seedance 的方舟密钥不同。

- [开通搜索服务](https://console.volcengine.com/search-infinity/web-search)
- [创建按量付费搜索密钥](https://console.volcengine.com/search-infinity/api-key?tab=post_paid)
- [订阅套餐搜索密钥](https://console.volcengine.com/search-infinity/api-key?tab=subscription_plan)

在设置展开“高级连接”，粘贴对应套餐密钥，点击“保存并使用火山搜索”。只保存到本机加密空间；切换搜索方式不会删除已有密钥。删除火山搜索密钥不会删除 Qwen 密钥或切换当前搜索方式。

## 费用与边界

- Qwen 网页搜索：单次研究最多一次联网模型请求，预留 0.2 元，按返回的模型和搜索用量估算结算；用量缺失保留预留。预留不是服务商价格上限，最终以账单为准。
- 火山网页搜索：最多 3 次，默认每次预留 0.02 元，可按自己的套餐调整。
- 扩展搜索与可选向量请求共用每项目 1 元研究实验预算；其余文字模型规划、分析沿用项目美元预算，分别记录。
- 不会自动调用未选服务，也不会在失败后切换另一家收费服务。选择了公开新闻时，即使扩展搜索失败，成功采集的新闻仍能用于分析。
- 引用只能来自实际读取的资料；没有原文或明确日期时，不让模型补齐证据。打开来源链接可自行核对。

## 更新应用

从旧应用菜单选择“退出并停止后台任务”，完整解压新版后运行 ShengzhangStudio.exe。只关闭窗口会缩到托盘。更新不会覆盖本地用户数据。此次仅生成本地 Windows 测试版，没有上传 GitHub。

接口依据：[Qwen 联网搜索](https://help.aliyun.com/zh/model-studio/web-search)、[Qwen Plus 地域能力](https://help.aliyun.com/zh/model-studio/qwen-plus)、[豆包搜索 Custom版](https://www.volcengine.com/docs/87772/2272953)。
