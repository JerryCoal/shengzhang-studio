# 生长 STUDIO v1.25.0：团队共享工作区

团队版由一台 Windows 主机运行，成员在浏览器中登录，共享项目、账号身份、Skills、素材、排期和运营记录。主机保存加密数据和凭证，浏览器上传的文件进入共享工作区。个人版仍使用原来的独立用户目录。

## 使用入口

团队包内附 Node.js、Caddy 和操作说明。首次启动默认仅本机 HTTPS 访问；管理员按 `TEAM-DEPLOYMENT-1.25.0.md` 配置内网地址和证书。首次创建管理员需要主机数据目录中的 `setup.code`，初始化后该文件删除。成员由管理员在“连接与设置 → 团队协作”添加。

管理员可以管理成员、密钥和平台连接；创作者可以制作、编辑和导出内容；发布员增加发布计划、发布确认与平台提交权限。模型仍按配置的服务商计费，实际发布仍需在界面确认。

## 多人一起工作

- 项目、素材、账号身份 MD/TXT、账号创作方案及工作区 Skills 共享。
- 每位成员的当前平台账号、项目创作账号、方案选择、编辑草稿、外观和引导进度分别保存；后台任务捕获发起时的账号和身份。
- 保存项目、内容和账号身份时检查版本，发生冲突显示刷新核对提示。团队更新在概览页自动刷新；编辑中提示有更新，避免覆盖未提交表单。
- 操作记录显示成员。长任务保留发起人；退出个人会话不关闭团队工作区。
- 重置密码、停用成员、调整角色会使该成员旧会话失效。至少保留一个可登录管理员。

## 平台连接与数据

浏览器不能调用个人桌面程序内置的登录窗口和发布助手。团队模式使用主机上的独立 MCP 服务，管理员配置连接后，成员按权限操作；也可导出成品后手动发布。界面会说明桌面助手不可用的原因。

团队数据默认保存在 `%LOCALAPPDATA%\ShengzhangStudioTeam`，与 `%LOCALAPPDATA%\ShengzhangStudio` 的个人数据分开。不会自动合并个人账号和项目。团队密码只用于身份认证；共享数据库与凭证由主机密钥加密，Windows 主密钥受当前运行用户保护。备份和恢复说明见部署文档。

网络端口、防火墙、DNS 和系统开机启动没有自动修改。关闭网页不等于停止主机服务；请使用包内停止脚本。
