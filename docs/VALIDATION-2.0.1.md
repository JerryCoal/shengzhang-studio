## 两套真实打包后端

个人版和团队版均使用包内 Node v24.19.0 与最终后端，在独立临时目录、仅本机回环连接且拒绝外部网络的条件下，各通过 12 项检查：

1. 后端启动、版本健康检查和编译后静态页面服务。
2. 未登录时不能访问私人 Agent 草稿、临时正文与任务日志。
3. 新工作区默认 Seedream，Redfox 路由默认关闭。
4. Seedream/Seedance 默认无可选水印；本地 Qwen 默认关闭，保存合成回环配置不发起探测；研究/MCP 设置读取不启动服务。
5. 合成 GLM/Redfox 密钥仅加密保存，不发起连接测试或自动启用服务。
6. Agent 草稿修订冲突、幂等交接、同任务编号及共享作品临时编辑按成员隔离。
7. 正常关闭及退出登录仅撤销对应会话。
8. Windows DPAPI 保护存在；隔离磁盘文件不含测试密码、合成密钥、需求或检查点明文。
9. 重启准确恢复需求、未提交标题/正文/要求、账号绑定和暂停检查点，不重复生成或新增草稿。
10. 恢复任务转为人工核对状态，不重放付费请求或改变另一成员的任务。
11. 清理一名成员临时正文不影响另一名成员暂存。

以上分组归纳了各报告的 12 条断言。两包外网尝试均为 0，真实付费、投稿与第三方 MCP 启动均为 0。四个启动/重启进程均以退出码 0 正常退出，独立进程检查确认无残留。首次沙箱执行受 Windows DPAPI 权限限制，按正常 Windows 用户权限重跑后通过，不是绕过加密。
