# 生长 STUDIO v1.13.0

- 默认使用公开新闻和已有文字模型，取消必须先配独立搜索密钥的引导。
- 新增 Qwen 联网搜索选项，复用北京地域已保存的文字模型密钥，合并查询并省去额外扩词调用。
- 获取真实搜索来源后受控读取公开网页，核对发布日期；无法核实的网页单独显示为线索，不进入近期内容证据。
- 火山入口改为“豆包搜索 Custom版”，补齐开通、按量与订阅密钥直达链接，移除最新文档未定义的请求参数。
- 重新布局搜索方式、费用确认和高级配置；切换服务不删除密钥，不自动切换收费来源。
- 保留 v1.12.0 的 Qwen 格式与地域修复、内置 MCP 修复和外部抖音适配。
