## 重点业务断言

- MCP 访问令牌只进入保险箱，不出现在状态、设置响应或工作区备份；不支持的平台内置模式和非本机 MCP 地址被拒绝。
- 失效/错误目标账号在工具调用和素材暂存之前阻断；采集任务固定读取账号。
- YouTube 评论先预览再确认导入，重复导入去重，保留已有人工分类与修正。
- Instagram 缺少可读取公开素材 URL 时不提交；不会自动上传素材到其他服务。
- YouTube、Instagram、TikTok 未连接、尚未核对能力或缺少发布工具时，即使填写了其余选项，最终确认和提交仍不可用，并提供检查连接入口。
- TikTok 拒绝前端注入权限、未知/过期预检、切换账号/连接与授权身份变化；发布前重查允许选项。模拟提交进入日志后不会盲目重发。
- 抖音同账号主服务用于发布、采集服务用于评论/研究，合并显示能力但不混用令牌。
- 同话题研究保留指标缺失，避免英文子串误判话题；无相关且可比较证据时不调用 AI。各平台不混合排名。
- 所有发布计数来自假工具，未执行真实平台发布；测试目录与浏览器资料独立于用户工作区。
