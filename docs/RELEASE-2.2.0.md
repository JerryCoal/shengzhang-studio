# Shengzhang Studio 2.2.0

工作流程集中到总控：提出需求、整理计划、逐项批准派工、查看成果与配图，在同页完成。

- 主入口为总控、账号、资料；任务列表、活动与成果内嵌。旧任务链接与通知保留项目、任务、运行及成果版本定位。
- 确认计划只建立待批准任务。每项 Agent 调用都需核对可修改指令、显式选择 Skills 或默认规则、估算费用并单独批准。前置成果完成不会代替下游批准。
- 文案和脚本下接续配图，默认两张、可选一至四张；逐张保存状态、采用和重做。图片模型、Skills、指令与合计费用在弹窗单独批准。
- 派工与图片未提交设置自动保存；刷新后恢复草稿和已有任务，费用估算与批准需要重新确认。
- 导入 Skills 可修改保存；已批准任务保留冻结版本。完成、失败及取消任务可移除，费用、成果和依赖证据保留。
- 重新编辑的成果各自关联媒体草稿；历史缺失映射按选中版本修复。
- 失败重试重新批准，已完成的图片不随失败项整批重做；历史请求重放不重复提交收费请求。
- Start-App.cmd 按项目版本启动对应新包，修复一直打开1.5.0旧包的问题。新2.2.0包独立输出，旧2.1.0包保留。

AI规划费用独立批准；派工不包含发布。图片依赖用户自己的Seedream或Redfox连接。脚本配图不包含视频生成。后台执行需要本机或团队主机持续运行；外部结果未知时先核对回执与账单。验证范围见 VALIDATION-2.2.0.md。
