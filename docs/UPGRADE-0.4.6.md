# 生长 STUDIO 0.4.6：近七天热点与文案标签

解压新版文件夹后运行 `ShengzhangStudio.exe`。先退出旧版，再启动新版；原来的本地用户、项目、语料、密钥与草稿继续使用。无需重新注册。旧版 0.4.5 安装包保留。

## 怎么使用

1. 在左侧打开 **热点与灵感**，确认顶部的当前项目。
2. 输入或点选宣传关键词，例如 `学习搭子，大学生，校园社交`。可选 1–12 个，每个最多 30 字。优先写受众和具体使用场景。
3. 选择新闻来源，点击 **更新近七天热点**。只有点击才联网采集；两次采集至少间隔一分钟。
4. 查看来源状态，再展开候选卡片的 **为什么推荐？查看信息与出处**，核对新闻日期、短摘要、原文和匹配依据。
5. 最多选 5 个。人物、品牌、作品等名称需要逐项确认使用条件，再点击 **确认选择并生成标签**。
6. 到 **策略与 Prompt → 生成 / 调整策略**，或 **内容制作 → AI 文案**，点击输入框下的“项目热点”。话题标签和场景切入标签会追加写作方向、新闻短摘录、日期与来源，不覆盖已有内容。
7. 在正文编辑框点选时，只插入 `#话题#`；不会把内部写作要求写进正文。添加后可撤销。标签也能在热点页停用。

标签属于当前项目，其他项目和用户不能混用。支撑新闻超过七天后，标签不再出现在快捷输入建议中；已写进正文的内容不会被自动删除，请在发布前再核对。

## 运行逻辑与效率

手动更新 → 读取公开新闻订阅与最多 6 篇相关网页 → 按原始发布日期筛选七天内内容 → 提取短摘录与候选词 → 本地关键词及相关词匹配 → 排序 → 人工挑选 → 生成可复用文案标签。

- 来源为中新网教育、生活、消费财经频道，IT之家及少数派。使用媒体公开提供的 RSS，并按站点采集规则读取部分网页。无需登录或新闻服务密钥。
- 仅覆盖这些来源当前提供的条目及本机之前采集的有效条目，**不是完整七天新闻档案，也不是全网热搜榜**。来源失败时显示失败状态，并保留尚未过期的本地新闻。
- 缺少原始发布日期、日期在未来、超过七天的内容不会进入排名。同标题的转载不重复增加推荐分；同一媒体的多个频道不算多个独立来源。
- 候选来自内置主题词、项目关键词、标题名称及作品名等规则，结合相关词检索；第一版不使用付费大模型进行语义识别，可能漏掉新词。可以补充更具体的关键词后重新筛选。
- 匹配分由关键词相关度（65）、时效（20）、独立来源（10）和报道覆盖（5）组成。它是本地规则估算，不是传播量或商业效果预测；只有一篇报道支持时只是话题线索。
- 筛选与标签生成均免费，不占用模型预算。只有之后主动调用 AI 写文案，才按已有服务商配置计费。
- 展开“管理禁用词与通用词过滤”，可继续添加项目专属词表。更改后点击“仅保存并重新筛选”，不用再次联网。

这能减少逐个搜索新闻、反复复制出处和重复输入写作方向的操作。新闻信息只用作选题参考，文案仍以已确认的产品事实为准。

## 名称和内容边界

内置通用词会被过滤。标题或短摘要包含明确版权、侵权等争议信号的报道不进入推荐；人物、品牌、影视动漫、游戏作品等候选保留，并要求单独确认。规则无法识别全部争议，**风险提示和勾选确认均不等于已获授权**。已知不适合本项目的词请加入禁用词。

系统仅保存标题、短摘要、日期、链接与匹配结果，不保存新闻全文，不绕过登录、验证码或付费访问。生成标签会提醒模型区分新闻事实和产品事实，不虚构联名、代言或参与新闻事件。

## 数据与版本

Windows 数据继续保存在 `%LOCALAPPDATA%\ShengzhangStudio` 的当前本地用户工作区，加密保存。网页版沿用浏览器本地加密存储；新闻采集需要连接运行中的后端。新闻请求不携带模型密钥、产品介绍、语料文档或成品素材。静态体验版可管理已有标签，但不能独立执行网页采集。

本次未恢复公网部署。此前 Seedream 小红书封面、文本模型、语料检索、敏感词替换及自动保存功能保留。
