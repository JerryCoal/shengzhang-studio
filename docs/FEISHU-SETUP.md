# 飞书发布计划接入指南

适用：生长 STUDIO Windows v1.4.1，以及连接该本机后端的网页。独立联网网页版和静态体验版暂不支持此连接。

## 1 创建团队应用

1. 进入 [飞书开放平台](https://open.feishu.cn/app)，在团队下创建自建应用。
2. 在权限管理中查找多维表格相关权限，为应用开通读取字段、新增字段、读取记录、新增记录和更新记录的能力。具体权限名称以后台为准；也可查看官方“查看、评论、编辑和管理多维表格”权限是否满足团队配置要求。
3. 发布应用版本；按团队管理制度完成审批。
4. 从应用凭证页面获取 App ID 和 App Secret。只填入工作站设置，不要发送到聊天或放进共享表格。

## 2 创建团队排期表

1. 在飞书新建一个空白多维表格，名称可设为“团队内容发布计划”。
2. 将默认首列改名为“计划编号”，保持文本类型。这样同步后的首列不会留空。
3. 在表格菜单找到“添加文档应用”，添加第 1 步的应用。如果启用了高级权限，还需允许应用读写对应行列。
4. 选中具体数据表，复制完整链接，例如 `https://团队.feishu.cn/base/…?table=tbl…`。
5. 第一版不接受知识库 `/wiki/` 链接。请在飞书打开原始多维表格后复制 `/base/` 链接。

## 3 在工作站连接

打开 **连接与设置 → 团队协作**：

1. 填写 App ID、App Secret 和数据表链接，点击“保存并检查”。
2. 出现缺少字段时，点击“初始化标准字段”，确认目标链接。
3. 提示“标准字段已就绪”后，可以打开团队表格核对。

程序只新增缺少的列。发现同名列类型不匹配时停止，不删除或重建原列。

| 列名 | 类型 | 更新规则 |
| --- | --- | --- |
| 计划编号 | 文本 | App 管理，保持不变，用于防止重复行 |
| 项目 | 文本 | App 更新 |
| 平台 | 单选 | 小红书 / 抖音 |
| 发布账号 | 文本 | 本地账号标识，不代表平台授权身份 |
| 标题 | 文本 | 发布记录快照中的标题 |
| 计划发布时间 | 日期时间 | 按绝对时间写入，请核对飞书时区 |
| 发布状态 | 单选 | 待发布 / 已导出 / 已发布 / 已取消 |
| 作品链接 | 超链接 | 用户实际发布并登记后更新 |
| 负责人 | 文本 | 创建行时填写项目默认值，后续由团队维护 |
| 团队备注 | 文本 | 由团队维护，App 不覆盖 |

可以在飞书自行增加日历、看板等视图，以及团队需要的其他列；不要删除 App 管理列。

## 4 同步项目计划

打开真实项目的 **发布中心 → 团队发布计划**：

- 填写可选的默认负责人，保存同步设置。负责人是普通文字，首版无需通讯录权限，不会自动提醒或 @ 成员。
- 点击“立即同步计划”，确认将本项目排期字段上传。每批最多处理 50 条有变化的计划；较多记录可继续点击。
- 勾选自动同步并保存后，会同步本项目已有及后续发布计划。程序运行、联网且工作区已登录时，每轮最多处理 5 条待更新计划。
- 创建计划、修改时间、登记发布链接或取消计划后，对应行会更新；取消不会删除飞书记录。
- 修改已确认策略或成品，不会自动改变此前保存的发布快照。需要新内容时，请创建相应的新计划。
- 发布记录下可查看同步状态，也可以只同步其中一条。

飞书保存和展示排期，不代表作品已在抖音或小红书发布。实际发布仍需在官方平台确认，再回填作品链接。

## 5 处理异常

- **权限不足**：同时检查接口权限、应用是否发布，以及表格是否添加该应用。高级权限可能限制特定行列。
- **字段未准备好**：重新检查并补齐字段。列名或类型变化后需要调整回标准结构。
- **飞书有不同修改**：打开表格核对涉及列，选择“按 App 更新”才会覆盖本次冲突。负责人和团队备注不在覆盖范围内。
- **重复计划编号**：在飞书核对并合并重复记录，再重试。
- **原行被删除**：程序停止同步，不静默重建。请在飞书恢复原记录后核对。
- **断网或结果不明**：本地保留原请求和防重复编号，先核对已有行再重试。自动补偿最多三次，之后手动处理。
- **待同步版本较旧**：上一次请求结果不明时，会先核对原请求；本地后续修改在下一轮同步，避免同一个防重复编号对应不同内容。

改变表格或应用后，所有项目自动同步关闭；检查新表并重新确认开启。断开连接会删除本机飞书应用密钥并停用自动同步，已经上传的飞书行仍保留。

## 6 数据范围

排期字段同步后保存在飞书云端，按该表格权限供团队访问。正文、图片、视频、项目语料、评论和模型密钥不随此功能上传。飞书 App Secret 按本地用户加密保存在保险箱，工作区备份不包含该密钥。

电脑关机后停止同步，已上传的记录仍可在飞书查看；不同电脑的工作区不因此自动合并。本进程会串行写入同一张表格，多台电脑共同编辑同一计划前应约定 App 管理列的编辑方式。

## 验收建议

用一条测试计划确认：首次新增、重复同步只有一行、修改时间、取消状态、负责人和备注保留、冲突提示、网络恢复补传。确认无误后，再启用真实项目批量同步。真实租户权限和字段行为需由团队应用联调验证。
