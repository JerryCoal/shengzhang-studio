# v1.3.1：价格语境识别与自定义替换

新增“语义替换（价格）”。AI 逐处判断原词是否正在表达价格；本地程序只使用你填写的替换词，不让模型自由改写金额或发明同音字。

## 设置与使用

1. 完全退出旧版（托盘菜单“退出并停止后台任务”），完整解压新版后运行 `ShengzhangStudio.exe`。旧用户与词库保留。
2. 打开“连接与设置 → 敏感词与替换词库 → 管理词条与替换方式”。添加原词、指定替换词，处理方式选择 **语义替换（价格）**，风险类可填 `PRICE`，保存词库。
3. 例如希望价格里的“元”写成“圆”，设置 `元 → 圆`。这只是格式示例，可以使用你自己的文字；不会自动改动已保存词条。
4. 到“内容制作 → 编辑与自检”。蓝色表示待判断的语义候选，不代表一定需要替换。
5. 点击 **AI 识别价格并替换**，确认模型及费用。模型只返回每个位置的判断：替换、保留或无法确定。
6. 查看每处原因和完整候选。比如 `19.9元起` → `19.9圆起`；`元气满满`、`元宇宙`应保留。“起”、优惠限制与其他原文由本地按范围拼接保留。
7. 确认后点击“采用到编辑框”，最后点“保存修改”。修改标题后需重新制作画面。保持手动发布。

TXT／CSV 新增写法：

```text
元|semantic|圆|PRICE
```

`semantic` 与固定替换的区别：本地初筛只标记，不执行替换；确认 AI 请求、模型判断该位置属于价格场景后，才生成指定文字的候选。替换词不能为空，不可增删或修改数字。不确定的位置保留，交给你检查。

## 范围与费用

- 同一个词在不同位置可以有不同判断；只处理已启用且命中的语义词条。未配置词条不自行创造映射。
- 本地初筛免费；语义判断沿用设置中的 OpenAI／DeepSeek“文案”模型，每次确认调用一次。单次最多 40 处，超出时先缩短文案，不自动拆成多个付费任务。
- 发给模型的是标题、正文与候选位置；不发送完整词库和替换词。模型不生成修改后的文案，由本地映射拼接，因此不会自行改价。
- 本流程只执行语义替换。固定替换与上下文改写仍有各自按钮；修改后再次本地复检。
- 当前编辑框内会记住模型明确选择保留的非价格词。继续改动文案或词库后需要重新判断。关闭并重新打开编辑器会重新字面初筛，蓝色仅表示候选。
- 模型可能误判，因此保留原文并提供逐处理由和预览；不承诺替换后一定通过平台审核。

新技能为 `skills/price-context-replacement/SKILL.md`。Python 独立工具支持 semantic 初筛，仍不调用模型；语义判断由应用现有后端完成。
