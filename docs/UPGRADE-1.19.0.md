## 升级

1. 在旧版托盘菜单选择「退出并停止后台任务」，避免两个版本同时操作同一工作区。
2. 将新版压缩包完整解压到新文件夹，运行 `ShengzhangStudio.exe`；不要只替换一个可执行文件。
3. 使用原来的 Windows 用户与工作站用户登录。不要删除旧的数据目录、保险箱或小红书登录资料目录。
4. 先检查原项目、AI 设置和账号，再测试新平台。建议保留旧版安装目录与已有本地备份。

## 五个平台如何开始

进入「设置 → 账号与发布」，选择平台、新建连接并核对账号名称。海外平台使用各自官方 OAuth 授权，不能使用小红书扫码登录替代。

| 平台 | 本版接入 | 首次配置要点 |
| --- | --- | --- |
| 小红书 | 发布、评论、同话题内容发现 | 延续内置/外部 MCP 及多账号独立登录资料 |
| 抖音 | 发布；通过另一服务读取评论与同话题内容 | 同一账号可填写主发布地址和独立采集地址，两边登录同一个抖音账号 |
| YouTube | 视频提交、评论、关键词内容发现 | Google OAuth、YouTube Data API；使用附带的修复入口及桥接 |
| Instagram | 图文/Reels、自有评论、标签热门/近期内容 | 专业账号；标签发现需要 Facebook Login 路线 |
| TikTok | 账号与发布权限检查、图文/视频提交 | 官方 OAuth；当前适配 MCP 不支持评论读取或全网搜索 |

完整安装说明在包内 **`多平台MCP/README.md`**，配套脚本和配置模板在该目录的 `scripts`、`examples`。源码说明见 [五平台 MCP 接入](MATRIX-MCP-SETUP.md)。这些是可按需安装的外部服务，本版没有把第三方程序和登录资料直接打进安装包。

保存地址后先「检查连接」与核对实际账号，再使用发布或采集。工作站只接受本机 MCP 地址。发布仍需逐次确认；TikTok 还需读取当前账号允许的可见范围和互动选项。Instagram/TikTok 要求平台可读取的公开 HTTPS 素材地址，TikTok 另有域名验证要求；本机文件路径或网盘预览页不能代替。

AI 密钥和 MCP 访问令牌继续在工作站本机加密保存。外部 MCP 的 OAuth 文件由外部程序保存，部分为本机明文；请使用独立账号目录，不要加入 GitHub、同步盘或素材包。平台可使授权失效，保存配置不代表永久登录。

## 找同话题的高表现内容

1. 打开热点研究，选择「同话题高表现内容」，再选平台、读取账号、话题和时间范围。
2. 搜索取得真实帖子/视频后，程序清洗去重，核对时间与话题，按同平台的一项实际指标比较。
3. 查看播放、点赞、评论、收藏、分享。没有返回的指标显示未知，不能视为零；无匹配样本或缺少可比较指标时不会直接调用 AI 分析。
4. 阅读 AI 给出的观察、可能原因与创作试验建议，挑选参考资料再用于创作。结果说明可能的关联，不保证涨流量。

YouTube 会合并相关检索与高播放候选；小红书综合模式合并综合与高点赞候选；Instagram 是标签发现。各平台不混排成一个“热度分”。详情见 [同话题研究逻辑](TOPIC-CONTENT-RESEARCH.md)。

## 界面变化与验证范围

界面调整为灰白底、深色正文和蓝色主操作，减少绿色铺底；字体大小与重点加重设置继续保留。五平台入口、单列连接表单和研究指标已适配窄屏。

本轮已验证隔离测试、上游服务握手和界面布局；尚未用真实海外账号完成 OAuth、最终发帖与完整评论采集。具体见 [验证记录](VALIDATION-1.19.0.md)。静态网页仍不能运行本机 MCP 服务。
