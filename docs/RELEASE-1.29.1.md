# v1.29.1 小红书近期研究修复

近七天、近三十天的小红书 Redfox 研究现在优先请求最新发布的样本，随后校验正文、精确发布日期和研究条件。原先仅取一页相关/热门样本的方式容易漏掉近期内容。

- 新增可选补充读取：每个关键词最多两页，整轮最多三次详情补全。确认窗口显示本轮请求和费用上限；关闭后每词一页，不补详情。
- 补全缺失的正文或精确日期，不把标题当成正文。重复、空页和失效任务及时停止，不自动重复扣费重试。
- 显示本轮候选、符合条件、待核实、实际分析及失败来源数量。详细来源仍可折叠展开。
- 区分读取失败、无样本、格式不符、正文/日期缺失、超出日期范围及其他筛选原因；保留旧参考及已选内容。没有合格证据时不调用 DeepSeek。
- 保持个人版、团队版和未来服务器接口边界。旧客户端不传新字段时不会增加取数请求。

Redfox 当前优质库仍是提供商的数据范围，近期查询不代表小红书全站实时覆盖；真实余额、服务可用性和具体关键词命中以实际查询为准。

测试采用隔离模拟数据，不产生真实 Redfox 或文字模型费用。最终验收范围见 `VALIDATION-1.29.1.md`。
