用户数据仍位于 `%LOCALAPPDATA%\ShengzhangStudio`。本次整理不修改数据格式；同一台电脑、同一 Windows 账户下，可继续登录原有本地用户。请牢记密码并定期导出备份。

## 推荐使用顺序

1. 先点击“开始免费练习”：确认策略、制作封面、导出素材包。
2. 新建正式项目，填写品牌、受众、产品事实与模型预算。
3. 在项目语料库导入介绍文档，查询并核对原文。
4. 可选：在“热点与灵感”手动更新近七天新闻，核对来源和名称风险，挑选候选并生成项目标签。
5. 生成或编辑策略，确认版本后进入内容制作。
6. 按需用 OpenAI / DeepSeek 编写文案；末尾执行可维护敏感词规则。标签与语料引用可辅助填写要求。
7. 图文使用本地模板或 Seedream 封面；AI 视频先用 GPT Image 2 / Seedream 生成首尾帧，再提交 Seedance。
8. 检查成品后导出。小红书手动发布并登记作品；抖音需官方权限和授权，再逐条启用投稿。
9. 导入或同步评论，核对复盘建议，采用有依据的经验用于下一轮策划。

## 操作帮助

左侧“使用指南”、顶部问号或 F1 可查阅说明。Seedream 模型输入框下的“是不是提示‘模型或者接入点不存在’”可打开问答，关闭后保留未保存输入。

排查时先选模型系列，再填控制台复制的北京区域 `ep-` ID，保存图片连接。有效 Model ID 也可使用；权限、模型开通状态和额度需在服务商账户中确认。

## 使用边界

- 数据按用户在本机加密保存；调用 AI 时发送当前任务所需资料与凭证。
- 联网网页后端仍是部署选项，本次 GitHub 正式发布不重新开放个人电脑后端。GitHub Pages 本身不能执行后端任务。
- 小红书采用手动发布与评论导入；抖音自动功能需平台权限。
- 新闻仅覆盖指定来源返回的有效条目；关键词检索、风险提示和词库替换均需人工核对。
- 自动任务需保持应用和电脑运行。手机工程尚未签名、真机验证或上架，Windows 包尚无代码签名。
