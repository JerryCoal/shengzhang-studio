# 小红书文案创作需求

复制后填写已有信息即可；未知项留空，不需要为填满模板编造事实。

## 必填信息

- 产品 / 服务 / 项目名称：
- 用一句话介绍它：
- 主要写给谁：
- 本次目标（介绍 / 招募 / 咨询 / 教程 / 真实体验分享）：
- 已确认的功能、服务内容或事实：

## 表达偏好（可选）

- 想切入的具体场景：
- 最希望读者记住的一点：
- 语气（自然聊天 / 温和专业 / 活泼轻松 / 简洁直接）：
- 正文字数：
- 想保留的词或句子：
- 想避免的表达：
- 已选择的标签 / 已核实热点：
- Emoji 或小红书表情偏好：
- 结尾希望读者做什么：

## 需要核对的条件（有则填写）

- 价格与计价方式、是否为起价：
- 地点 / 时间 / 名额 / 适用条件：
- 不包含的服务或限制：
- 已有且可使用的报名入口 / 联系方式：
- 真实体验或案例原文及其来源：
- 项目语料库 / 附件：
- 自定义词库：附 TXT / CSV，或列出需固定替换的词。
- 价格语义替换：原词 → 指定替换；仅价格语境使用。

## 输出要求

默认：3 个不同角度的标题 + 1 篇正文 + 3—6 个相关标签。

调用示例：

> 使用 $xiaohongshu-copywriting，根据以上已确认资料写一篇小红书文案。没有依据的价格、体验、效果和福利不要补造。发布正文与待确认项分开。
