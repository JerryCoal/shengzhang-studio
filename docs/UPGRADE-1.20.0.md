# v1.20.0 使用说明

## 从介绍文档填写项目概要

1. 先在「连接与设置」保存自己的 DeepSeek API 密钥。此功能固定使用 DeepSeek V4 Pro，不改变其他步骤选择的模型。
2. 打开「新建项目」或「编辑项目与品牌资料」，展开顶部「导入介绍文档，自动填写概要」。
3. 选择 TXT、MD、DOCX 或文字型 PDF；也可直接粘贴介绍。PPTX、XLSX 以及复杂扫描件需要 Windows 本机增强解析组件。读取警告会显示在预览旁。
4. 检查正文，删除不需要发送的内容。点击「先估算提取费用」，勾选同意将预览正文发送给 DeepSeek，再点击「提取项目概要」。
5. 核对候选值与原文依据，勾选要采用的字段，点击「填入所选…项并保存」，随后可以继续手动修改。

应用文件夹中的 `项目介绍导入示例.txt` 是虚构演示资料，可用来体验流程；实际点击提取仍会使用你的 DeepSeek 额度。

可提取：项目名称、品牌、产品或服务、宣传目标、受众与场景、卖点、产品资料、语气与要求。文档没有的信息留待补充，项目类型、发布渠道、截止日期和模型费用上限仍由你设定。

默认只勾选未修改的空白字段。已有内容需手动勾选；产品事实始终需要你核对后勾选。原文引用只能证明资料来源，并不代表其中的宣传承诺或效果已经核实。

生成期间可以继续编辑，也可「保存并关闭」去处理其他工作。重新打开同一个项目，可读取上次任务与候选结果。新项目在提取完成前不能提交创建，以免结果归属错误。完全退出程序会中断请求，重新打开不会自动重试收费。

## 本地保存与费用

- 解析先在本机完成，仅发送你确认的预览正文和文件名到 DeepSeek；不发送其他项目、平台登录资料或未选择的语料库。
- 单次最多 30,000 字符且不超过 60,000 UTF-8 字节。超过时可以精简预览；系统不会偷偷截掉尾部。
- 密钥沿用本机加密保险箱；候选结果、字段快照与费用记录保存在当前用户加密工作区。原始文件和完整预览正文不会由此功能存入后台。
- 费用按本次模型价格与返回用量估算，最终以 DeepSeek 账单为准；网络中断等无法确认费用时保留预留记录。
- 新项目创建时，提取费用会归入该项目。关闭窗口不会丢弃草稿。
- 此功能可在 Windows 完整版和它提供的本机网页使用；GitHub Pages 静态体验版与远程中转网页版暂不支持。

## 同时包含小红书话题修复

外部小红书 MCP 发布时，将正文与话题候选分别传入。发布确认窗口可调整候选，兼容旧文案的 `#词[话题]#` 格式；修改内容或候选后需重新确认。上游服务没有返回逐项话题绑定结果，发布后仍应检查平台上的实际关联。

## 更新应用

先从旧版托盘菜单选择「退出并停止后台任务」，再完整解压新目录并运行 `ShengzhangStudio.exe`。已有项目、密钥和平台账号仍使用 `%LOCALAPPDATA%\ShengzhangStudio` 的本地数据。本版为本地构建，尚未上传 GitHub。
