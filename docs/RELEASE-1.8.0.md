## 本次新增

- 内置通用宣传文案 Skill，更新小红书写作规范：先核对事实、受众、使用场景和行动引导；外部热门案例只用于分析表达，不移植他人的体验与效果数据。
- 用户导入 Markdown Skills：预览、确认安装、启用/停用、删除与模板下载。沿用本地按用户加密存储。
- Windows「AI 文案」生成前选择写作规则，适配现有 OpenAI、DeepSeek、Qwen 路由；内置规则始终保留，敏感词及价格语义流程保持独立。
- 保存每次生成时所用规则的版本和原文；成品预览、编辑和历史恢复支持追溯。
- 网页请求移除本地 Skills 目录及历史规则原文。本轮自装 Skills 联网传输暂未启用，网页版仅用内置规则；本地安装、查看仍可用。
- 近期高互动内容参考库调研，列出采集、清洗、本地检索、AI 分析、人工采纳和创作复用的两期落地方案。
