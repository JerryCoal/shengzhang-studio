# 升级到2.2.0

1. 核对旧版仍在运行或结果未知的请求，退出旧程序后备份完整数据目录及配套密钥。避免新旧版本同时写同一数据库。
2. 新包：outputs/windows/Shengzhang-Studio-2.2.0/ShengzhangStudio.exe。完整保留包内文件；仓库 Start-App.cmd 按 package.json 版本选择对应包。
3. 数据仍保存在 %LOCALAPPDATA%\ShengzhangStudio。更新不删除既有项目、账号、素材与用量；保留旧包，回退请使用升级前的数据副本。

在总控输入需求并选账号，AI规划单独估算批准，也可用免费规则草案。确认计划后，逐项打开批准窗口，修改指令、选择本次Skills或默认规则、核对费用后批准。文案保存后可在同页制作配图。每张图片有独立状态和费用确认，失败只重试该张。

历史内容、发布复盘、账号连接和设置入口继续保留。删除已结束任务会从任务列表移除，费用、成果和下游依赖记录继续保留。结果未知先核对；图片生成不包含视频或发布授权。

资料页可导出包含任务历史的业务备份。备份JSON包含私人业务内容，须妥善保管；不含登录密钥。恢复的待执行记录保持暂停，需核对输入并重新批准。真实服务验证范围见 VALIDATION-2.2.0.md。
