# v1.26.0 Redfox 服务接入测试版

工作站新增 Redfox 连接，可分别开启公开平台资料、图片视频生成和联网搜索。个人与团队模式沿用既有加密存储、角色权限、账号身份和 Skills。

- 五个平台接入作品搜索与详情：抖音、小红书、TikTok、YouTube、Instagram。评论支持除抖音外的四个平台，先预览确认再导入；指标按作品保存快照。
- 近七天网页研究增加 Kimi 搜索来源，仍读取原网页并核对日期；新增手动获取的平台热榜。
- Redfox 媒体路由固定为 Seedream 5.0 Pro 图片和 Seedance 2.0 视频，支持封面候选、首尾帧、参考图上传与成品保存。
- 图片、视频和异步搜索保存上游任务编号，重启续查。无编号的中断提交保持待核对，不自动重复付费提交。
- 人民币估算独立记录，原文字模型、美元预算和原服务配置保留。切回原服务有明确开关。
- 新增用量、任务查询、失败和费用确认提示；继续校验账号归属、内容版本及后台操作者。

本版没有接入 Redfox GPT Image/Gemini 选择、账号粉丝看板或平台发布/私信，也不能用 Redfox 代替所有文字模型密钥。数据存在收录范围、T+1 更新与限时开放条件；媒体参数和实际费用仍待真实账号验证。

公开文档核验和模拟接口测试已完成，未调用真实收费接口，未进行真实平台发布。完整说明见 `REDFOX-TEST-REPORT-1.26.0.md`，测试与构建结果见 `VALIDATION-1.26.0.md`。本地打包交付不代表已上传公开 Release。
