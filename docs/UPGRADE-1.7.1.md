# v1.7.1 测试版：MCP 连接与评论流程完善

日期：2026-10-14。保留 v1.7.0 和此前安装包，现有本地用户与数据沿用原位置。本版没有迁移或上传个人工作区。

## 本次完善

- 外部小红书 MCP v2.5.5 的真实连接与 18 项工具发现已验证；在隔离本地浏览器缓存中已成功取得真实登录二维码。
- 工具连接与平台登录分开显示，新增「检查平台登录状态」；已登录时不再误报二维码缺失。
- 按上游 v2.5.5 的公开工具格式验证评论数量和回复参数，加入拒绝未知参数的协议测试。
- 无评论时展示空预览；导入成功但刷新失败时明确告知已保存，避免重复导入。修改采集条件会清除旧预览。
- 连接失败后清除旧连接状态；分别提示服务未启动、访问令牌错误、浏览器组件错误和响应中断，不回显上游敏感信息。
- MCP 设置增加三步指引、未保存提示、分操作进度提示；窄窗口按钮和长地址可以换行。发布中心与使用指南统一说明 MCP 投送、助手和导出三种入口。
- 继续保留 DeepSeek、Qwen Plus / Flash、用户自定义词库和现有项目功能。模型与 MCP 密钥按工作台用户在本机加密保存。

## 建议先这样测试

1. 关闭旧版，从本包打开 `ShengzhangStudio.exe`，登录原有本地用户。
2. 「连接与设置 → 文字模型」选择 DeepSeek 或 Qwen，填写对应服务商密钥并检查连接；设置各阶段模型后点击「保存模型分工」。检查连接不等于已验证付费生成权限。
3. 「账号与发布」先使用内置 MCP，点击「检查连接」。内置服务随 Windows 应用启动，无需另装。
4. 在内容制作完成图文或视频，前往发布中心，选择「MCP 投送」，核对本次账号、文案、素材。内置助手自动准备页面，最终提交需要你确认；选择继续检查不会发布。
5. 平台确认发布后，在工作台登记真实作品链接。进入「评论与复盘 → MCP 获取评论」，选择自有作品、数量和是否包含回复。
6. 窗口自动加载和滚动，遇到登录或验证码时由你完成。采集返回后先看预览，再勾选导入。评论去重不会覆盖已经人工修改的分类。

## 可选：外部小红书 MCP

适配 [xpzouying/xiaohongshu-mcp v2.5.5](https://github.com/xpzouying/xiaohongshu-mcp/releases/tag/v2.5.5)。程序通过 MCP 协议连接，该第三方服务没有打进本工作台安装包。

1. 按上游说明下载并启动 Windows 版本。首次启动会下载配套浏览器；看到「启动 HTTP 服务器」后再连接。仅本机使用可加启动参数 `-port 127.0.0.1:18060`。
2. 工作台选择「外部 MCP」，填写 `http://127.0.0.1:18060/mcp`。服务配置过访问令牌才需要填写令牌；此处不是模型 Key 或 Cookie。
3. 保存连接 → 检查连接 → 扫码登录 → 我已扫码，检查登录。
4. 评论读取需要带 `xsec_token` 的完整官方作品链接，且必须与所选发布记录是同一作品。工作台不保存链接中的令牌。
5. 外部发布在工作台勾选并点击确认后，直接交由 MCP 执行。它不会再弹出内置助手的最终确认；请事先核对该 MCP 登录的实际账号。

平台登录文件由第三方服务自行管理，可能是本地 Cookie，不受工作台的密钥保险箱管理。不同工作台用户应使用独立服务目录和端口，不要共享登录文件。

本机实测曾出现第三方浏览器的 Windows 组件启动错误，使用隔离缓存后成功生成二维码。遇到同类错误可先切换内置助手，或更新并检查第三方服务的浏览器安装；不能把工具已连接理解为平台操作一定成功。
