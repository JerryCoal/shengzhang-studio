# 矩阵工作站的界面阅读调整

调研与实现日期：2026-10-15。此文记录本次界面设计依据和验证范围；不表示已完成全部平台接入或正式发布。

## 设计依据

- [抖音前端团队 Semi Design](https://github.com/DouyinFE/semi-design/blob/main/DESIGN.md)：参考企业工具的文字层级、语义色、平面卡片和克制阴影；蓝色用于关键操作，成功、警告和错误保留独立语义。只参考原则，没有引入组件库或复制代码。
- [Semi Design 颜色变量说明](https://semi.design/zh-CN/basic/tokens)：参考将颜色集中为可维护变量的方式。工作站使用自己的调色板。
- [微信官方 WeUI](https://github.com/Tencent/weui)：参考表单、列表、反馈组件的一致性，以及在小屏上保留清晰操作目标。没有照搬微信绿色品牌色。
- [飞书多维表格视图说明](https://www.feishu.cn/hc/zh-CN/articles/360049067931-使用多维表格视图)：参考把相同数据的筛选、分组、视图和操作放在稳定位置的组织方式；本轮保留工作站现有导航和设置分组，避免用户重新找功能。
- [小红书公开网页](https://www.xiaohongshu.com/explore)在此次公开访问中跳转登录页，未以私人账号页面作为设计依据，也没有声称复制其完整设计系统。

## 本次调整

将界面从大面积浅绿、灰绿文字调整为灰白底色、深灰正文和少量蓝色操作。绿色只在品牌点缀、已完成或成功状态等必要位置出现；用户导入或生成的图片素材不会随界面主题改色。

`src/ui-theme.css` 集中定义颜色变量；旧页面和专用面板中的绿色文本、边框、背景逐步改为这些变量。后续账号矩阵、采集和热点分析组件应沿用：

| 用途 | 变量 |
| --- | --- |
| 页面底色 / 卡片 | `--ui-canvas` / `--ui-surface` |
| 辅助面板 / 边框 | `--ui-surface-subtle` / `--ui-border` |
| 标题正文 / 次级说明 | `--ui-text` / `--ui-text-secondary` |
| 主操作 / 选中背景 | `--ui-accent` / `--ui-accent-soft` |
| 键盘焦点 / 成功状态 | `--ui-focus` / `--ui-success` |

旧的 `--green` 为兼容现有组件，映射为交互蓝色。新增代码使用 `--ui-accent`，不要再把“绿色”当作交互含义。账号身份、平台、任务状态和结果应同时用文字表达，不仅依赖颜色。

保留字体大小、重点加重、用户外观设置的保存逻辑；主操作按钮最小高度保持 40px。窄屏标题和操作区允许换行，设置分组在大字体下换行。MCP 使用一行可换行的平台选择按钮和单列账号表单，避免五个平台的长说明同时铺满页面。同话题样本的播放、点赞、评论、收藏、分享在桌面为五列，小屏为两列。

正文和次级文字对白色底的对比度分别约 14.25:1、5.63:1；最淡的辅助文字对浅灰底约 4.73:1。错误和警告文字使用较深语义色；选中项保留明确的蓝色边框与浅蓝背景。没有修改真实用户数据或偏好，没有修改导出图片的尺寸或生成规则。占位产品插画已与原 1.18.0 安装包逐项对照恢复颜色。

## 验证方式

使用独立 Electron 浏览器资料目录和内存样例工作区，阻止对外网络请求，检查工作台、项目、语料库、热点、发布、评论、运营数据、平台设置和外观设置。

- 1440px 桌面及 390px 窄屏；窄屏使用 137.5% 字体及重点加重。
- 逐页核对页面与表单、按钮、面板没有横向溢出。
- 外观设置通过真实控件选择特大字体及重点加重，读取隔离工作区验证保存。
- 五平台设置切换、同话题样本口径和五项指标均纳入，共 30 张截图；没有控制台错误和对外网络请求。
- `tests/appearance.test.mjs` 5 项通过，覆盖分用户偏好、加密保存、AI 等待期间可编辑和网页传输隔离。
- 构建检查通过；界面截图和验收 JSON 保存在 `.tools/neutral1190-results`。

这是布局、外观和外观设置的验证，不代表真实平台登录、收费 AI 生成或发布已经在线验证。新增平台和热点功能合并之后，需要再次执行整体构建与相关业务测试。

## 三个平台发布弹窗补充验收

TikTok、YouTube、Instagram 使用合成发布记录和本机只读假接口验证，真实平台提交请求在浏览器与服务两端拦截。15 组行为检查、14 张桌面及大字体窄屏截图通过，记录保存在 `.tools/publishui1190-results/result.json`。

- TikTok 读取权限后不预选可见范围，互动选项默认关闭；账号禁用的评论、合拍不可选择。付费合作不能选择仅自己可见，修改正文会清除最终确认。
- Instagram 需要核对公开素材地址与预览一致；地址修改会清除素材核对和最终确认。
- YouTube 默认私密，需要人工选择其他范围。运营账号绑定错误、权限读取失败时不允许提交。
- 三个平台的外部连接未检查成功、发布能力未知或不具备对应素材发布能力时，最终确认与提交均禁用，提供前往连接设置的入口。
- 所有表单在 1440px 和 390px／137.5% 字体下无横向溢出；没有控制台错误、外网请求或最终提交调用。此验收不代表已完成真实账号发布测试。
