| D23 经验采纳 | work-experience；只从可追溯的已成功成果选择/编辑候选，再明确采纳 | 不自动把聊天或模型建议写入长期经验 |
| D24–D28 导航与页面整合 | 总控/任务/账号/资料四入口、进展中心，旧功能保留兼容入口 | 静态中转版明确降级，无后台执行假象 |
| D29 真实界面 | 已打开合成工作区并完成总控目标输入 | 后续浏览器操作受自动权限审核超时阻断；完整截图、中文输入法、焦点/滚动及 Electron 通知交互未验 |
| D30 迁移与恢复 | 合成迁移、旧 ID 保留、私有业务备份、同归属空库恢复、原授权降为历史 | 未覆盖生产工作区；未做跨设备实测；旧程序不可写新数据库 |
| D31–D32 回归与交付 | 完整自动回归、个人版与团队版独立构建、源码清单和发布校验工具 | 构建包与上传结果以本版附带 validation.json 和远端资产为准 |

## 测试记录

2026-10-21 使用 Node 24.19.0、正常 Windows 用户身份和独立测试数据执行完整回归：146 个测试文件，1257 项全部通过，无失败、无跳过。Skills 一致性与 TypeScript 同轮通过。两项可选 Python 检查明确使用本机解释器执行；Windows DPAPI 测试使用新建临时库，没有读取真实用户库。

最终源码如继续修补，以发布附带 `Shengzhang-Studio-2.1.0-validation.json` 的最终计数为准。本地详细报告位于 `.tools/validation210/report.json`，不把私人测试目录放入公开源码包。

合成模型和 MCP 只验证适配、权限和故障语义，没有产生真实模型费用、采集或社交发布。缺少真实界面/真实账号/另一台设备验收时，不能据此标记整份开发计划全部验收通过。交付按明确列出这些限制的发布候选处理。
