# 生长 Studio 0.4.3 · Seedream 图片接口

本版在原有 GPT Image 2 关键帧流程中增加火山方舟 Seedream。Windows 应用仍然独立可用；电脑后端的公网部署已按要求暂停。

## 更新与使用

1. 从系统托盘选择旧版的“退出并停止后台任务”。完整解压 0.4.3，双击 `ShengzhangStudio.exe`。已有用户、项目、语料、敏感词和草稿仍在 `%LOCALAPPDATA%\ShengzhangStudio`，不会随应用安装包替换。
2. 登录后打开“连接与设置”，找到“Seedream 关键帧生成”。填写**火山方舟北京区域的 API Key**，选择已开通的 Seedream 系列。可以使用预填模型 ID，也可以填该系列的 `ep-` 接入点。
3. 点击“保存图片连接”。可以把“默认关键帧服务”切换为 Seedream。图片与视频连接分别保存；若使用同一火山方舟密钥，在 Seedream 和 Seedance 两处各填写一次。
4. 确认项目策略后，到“内容制作”上传真实产品图，打开视频任务的“AI 视频 · 首尾帧”。选择 GPT Image 2 或 Seedream，填写画面要求，生成首帧，再生成尾帧。尾帧会参考产品图和首帧；每张已保存图片会注明实际模型和尺寸。
5. 检查两张画面后，勾选确认并提交 Seedance。视频的动作、时长、声音和下载流程与原版相同。

## 本版行为

- 首帧、尾帧及重新生成均可选择 Seedream；仅配置 Seedream 也可完成图片生成，不要求 OpenAI 密钥。OpenAI 方式及原有关键帧继续保留。
- 提供 Seedream 5.0 Lite、5.0 Pro、4.5、4.0 系列及自定义模型 / 接入点 ID。默认 Lite；是否开通、额度和实际价格以自己的火山账户为准。
- Seedream 统一使用 1440 × 2560 的 9:16 图片，直接把 PNG/JPG 数据存入本地工作区。参考图支持本地 PNG、JPG、WebP；不需要把产品图上传到公开图床。
- 图片单价按“美元 / 张”填写，人民币报价需要自行换算。填 0 时保留预算预留；填写单价后按服务返回的图片数估算。项目预算检查取预留与单价中的较高者，实际账单由平台决定。
- 网络超时或结果不明时保留任务锁定，不自动重复生成。明确拒绝时显示权限、余额、频率或模型 ID 的检查方向。已有首帧不会被失败的尾帧覆盖。
- Seedream 密钥与 OpenAI、DeepSeek、Seedance 密钥独立，按本地用户加密保存，状态页仅显示末四位，导出项目备份不含密钥。网页版源码同样接入浏览器本地加密及按需发送凭证，但此次不恢复公网部署。
