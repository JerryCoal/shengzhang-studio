# 生长 STUDIO · Windows 0.4.7

本版新增 Seedream 接入点报错问答，保留 0.4.6 的热点、封面、语料库、提示词、引导与本地用户数据功能。

## 从哪里查看

打开“连接与设置 → Seedream 封面与关键帧”。在“Seedream 模型 / 接入点 ID”输入框下方，点击小字 **是不是提示“模型或者接入点不存在”**，即可打开排查说明。

说明中包含：开通模型并创建 ep- 接入点、北京区域与账号权限核对、模型可用状态检查、开发者 cURL 示例，以及仍失败时需要提供的脱敏信息。关闭说明或按 Esc 会返回原设置，保留尚未保存的输入。

也可以进入“使用指南 → 设置与排查”，搜索 `Seedream`、`接入点`、`404` 或 `InvalidEndpointOrModel` 查到同一篇问答。正文可以离线阅读；官方控制台和文档链接需要联网。

## 配置要点

1. 到火山方舟北京区域开通 Seedream，创建对应模型的自定义推理接入点。
2. 在本应用先选择与接入点一致的模型系列，再粘贴控制台复制的 `ep-…` ID；切换系列会重新填入预设 ID。
3. 填写有权访问该接入点的 API Key，点击“保存图片连接”。
4. 回到封面或关键帧页面核对模型和预算后，手动测试生成。

该接入点路径来自用户实测经验。官方接口也接受有效且已开通的 Model ID，不能把模型展示名称与 Model ID 混为一谈。本应用固定使用北京区域，暂未提供区域切换。通用 404 提示本身不能证明具体根因。

参考：[官方图片接口](https://www.volcengine.com/docs/82379/1541523)、[接入点创建说明](https://www.volcengine.com/docs/82379/1099522)、[图片生成教程](https://www.volcengine.com/docs/82379/1824121)。

阅读帮助不会保存连接或调用付费模型；实际生成需要有效权限、额度，并按服务商规则计费。排查时不要提供完整密钥或 Authorization 请求头。

## 更新与数据

从旧应用的托盘菜单选择“退出并停止后台任务”，完整解压新版压缩包，再运行 `ShengzhangStudio.exe`。无需覆盖旧程序文件夹。

正式用户数据仍保存在 `%LOCALAPPDATA%\ShengzhangStudio`；本次帮助界面更新不改变数据格式。旧版 0.4.6 压缩包保留。本次为本机 Windows 交付，公网部署与上传仍暂停。
