# v1.17.0：Seedream 可见水印设置与角标检查

生成宣传图时，可选择是否让 Seedream 添加可见的“AI生成”角标。生成结束后，Windows 本机文字识别会检查可疑边缘标签，标出位置供你核对；不会自动涂抹、裁剪或修改原图。

## 使用步骤

1. 完整解压新版，先从旧版托盘菜单退出，再运行新版 `ShengzhangStudio.exe`。本地用户、项目和密钥继续使用。
2. 在「连接与设置 → Seedream 封面与关键帧」选择默认可见水印设置，保存图片连接。旧版配置默认仍为开启，可自行关闭。
3. 打开「内容制作」，进入「AI 封面 · Seedream」或「AI 视频 · 首尾帧」。生成前可临时切换本次是否添加可见水印；临时选择不会改动默认设置。
4. 生成后查看本次请求与检查结果。发现可疑角标时按标记位置放大查看原图，再核对产品外观、文字和角标。
5. 确认画面后采用封面，或继续生成视频。生成和检查期间可收起弹窗，应用需保持运行。

## 检查结果怎样理解

- **发现可疑角标**：识别到边缘的独立短标签，例如“AI生成”或“AI generated”。可能有误报，请对照原图。
- **未发现可疑角标**：在本轮识别到的文字中没有匹配项，不代表图片没有水印或 AI 标识。浅色、复杂背景、小字、图形水印和模糊文字可能漏检。
- **需人工核对**：当前系统不支持识别、缺少中文识别组件、图片无法识别或检查超时。生成的图片和费用记录仍会保留，不会为此自动重新请求模型。
- **旧图未检查**：旧版本图片没有这次功能的检查记录，不补造检测结论。

识别使用 Windows 系统组件，不额外请求大模型或第三方识别接口。图片会暂存于系统临时目录用于本机识别，正常完成或失败后清理。非 Windows 后端显示人工核对提示；静态体验版仍不能调用生成接口。

## 范围与费用

开关控制 Seedream 官方图片 API 的 `watermark` 参数，适用于小红书封面和 Seedream 首尾帧。它不修改已有图片，不清除隐式标识，也不代表平台无法识别 AI 内容。OpenAI 图片与 Seedance 视频沿用各自现有行为。

生成仍按原模型计费。检查不新增模型费用，不触发收费重试；当前封面候选及当前首尾帧保留本次请求设置与检查结果，方便复核。重新生成会替换对应候选记录，历史成品保留原有图片与文案，不是所有检查结果的永久档案。

本版以 GitHub Pre-release 测试版提供，包含截至 v1.17.0 的累计更新；历史版本继续保留。核对依据：[火山方舟图片生成接口](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)。
