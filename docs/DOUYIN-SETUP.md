# 抖音评论接口说明 · v1.2.0

发布已统一为手动流程，**无需配置此处**。在内容制作点击「导出与发布」，打开官方创作中心上传；回发布中心登记成功作品链接。详见 [v1.2.0 使用说明](UPGRADE-1.2.0.md)。

## 只有评论查询需要接口资格

个人开发者目前只能创建小程序、小游戏、小玩法；企业身份可创建移动 / 网站应用，但认证不保证获得接口权限。旧版接口文档仍可访问，新企业应用能否申请需先咨询官方，不能凭文档存在就认定可开通。

官方资料：[入驻常见问题](https://developer.open-douyin.com/docs/resource/zh-CN/developer/join/issues)、[新版 OpenAPI 目录](https://developer.open-douyin.com/docs/resource/zh-CN/dop/develop/openapi/list)、[评论列表接口](https://open.douyin.com/platform/resource/docs/openapi/interaction-management/comment-management-user/comment-list)。

1. 已有获批移动 / 网站应用时，核对 video.data 和 item.comment。需要作品选择列表时再申请 video.list。本版不请求 video.create，不再上传或创建作品。
2. 在控制台登记自己的合法回调域名 / 地址，与设置里填写的完整地址保持一致。平台不接受本地地址时需使用自己管理的 HTTPS 回调。
3. 在设置保存 Client Key / Secret。桌面版本机加密保存；网页版在浏览器加密保存，请求时由后端临时使用。凭证不是抖音登录密码。
4. 点击连接账号，优先应用内官方授权；不能完成则用浏览器链接，完成后 15 分钟内粘贴完整回调地址。
5. 在平台手动发布并登记链接，关联同一账号已公开的 item_id。该编号不一定等于分享链接里的数字。
6. 评论页可立即同步或单独启用每 5 / 15 / 30 / 60 分钟同步。关闭、断网或休眠会暂停处理。

仅同步官方接口可见的一级评论，每页 20 条，每轮最多 200 条并继续分页；按 ID 去重，保留原文与人工校正。暂不采集回复，不自动回复或发布任何内容。

没有接口权限时直接使用「导入评论」，不影响制作、导出、手动发布和复盘。真实抖音评论联调尚未完成。删除本机凭证会停止后续同步；平台侧授权可在抖音账号安全设置中另行撤销。
