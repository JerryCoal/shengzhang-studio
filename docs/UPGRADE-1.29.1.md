# v1.29.1 升级与使用

关闭旧版工作站，解压新版到独立目录，运行 `ShengzhangStudio.exe`。沿用已有本机用户和数据，不删除旧版或原数据目录。升级前可使用原有备份功能保留备份。

进入热点与灵感研究，选择小红书、Redfox 公开数据及近七天/近三十天，填写具体关键词。新版优先按最新发布时间取样，再按所选研究规则筛选、分析。

“允许补页和详情补全”开启时，每关键词最多读取两页，整轮最多额外读取三次详情；关闭时每词仅一页。空页、全部重复或来源明确没有下一页时提前结束；仅缺正文或精确日期时补详情。确认窗口会显示上限，以实际调用和提供商账单为准。三个关键词且开启补充读取时最多九次请求，当前目录单价下为 ¥0.36；一个关键词最多五次、¥0.20。

若未得到合格内容，先看本轮取数摘要及具体原因。可以展开来源报告核对失败来源与筛选数量。系统不会自动扩大日期范围，也不会拿缺少日期或正文的线索充当已核实证据；旧参考会保留。

团队版由主机管理员按现有停机、备份与迁移流程更新。不要让两个版本同时写同一团队数据目录。服务器扩展说明随包提供。
