# Shengzhang Studio 2.1.0 发布候选

本次按《DEVELOPMENT-PLAN.md》将工作站增量升级为「总控计划确认 → 持久后台任务 → 真实活动与成果 → 通知与回看」。旧工作区、账号身份、Skills、模型适配和发布确认继续保留。

本版仍有真实界面、原生通知及跨设备验收未完成，作为预发行候选提供；不把合成测试通过描述为整份计划已全部验收。建议备份后在独立测试数据中先试用。

## 主要变化

- 四个主入口：总控、任务、账号、资料；原有平台创作与发布复盘放入兼容入口。
- AI 总控先生成待确认草案，规划费用独立批准；免费规则草案可选。局部修订仅使用目标任务和必要计划摘要，不载入其他任务私聊。
- 后台任务分开保存计划、任务、运行、尝试、活动、成果版本、通知和阅读状态。账号与输入快照固定，切换筛选不串用身份。
- 独立任务并行，依赖任务读取固定的上游成果版本；幂等批准、租约、资源锁、供应商限流等待和费用保留防止隐性重复执行。
- 活动展示真实请求、检查点、工具摘要和结果，不展示或伪造模型隐藏推理。未知结果不会自动重试。
- 成果编辑另存版本，迟到结果保留候选；通知只在成果事务落盘后创建。备份含持久任务历史，恢复不继承执行授权。

## 边界

新增后台角色仅覆盖小红书文案/封面方向、抖音公开研究和脚本文案；其他平台、媒体制作与最终发布继续走旧流程。没有新增无人值守发布授权。模型与平台是否可用取决于用户自己的连接、权限、额度与网络。

本地后台不是云服务；电脑休眠或进程退出时停止推进。系统通知受操作系统权限、专注模式等影响，站内未读仍保留。费用预算是应用侧预留与派发约束，不替代服务商最终账单。

Windows x64 解压包与团队部署包分别交付，均不含真实工作区、Cookie 或密钥。第三方运行组件固定版本与校验值，旧包不覆盖。个人版仍无代码签名安装器或自动升级器。

请先阅读 `UPGRADE-2.1.0.md` 和 `VALIDATION-2.1.0.md`。发布是否完成必须以 GitHub 的实际标签、Release 资产与校验文件为准；本说明本身不是上传完成证明。
