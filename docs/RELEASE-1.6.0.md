# 生长 STUDIO v1.6.0 · 平台工作流测试版

本次上传此前本地 v1.3.x–v1.6.0 的累计升级，保留 v1.2.0 正式版下载。v1.6.0 标记为 **Pre-release（测试版）**：本地逻辑、模拟接口和离线桌面流程已验证，真实平台账号的完整发布与采集仍待联调。

## 本次更新

- **官方页面发布助手**：Windows 应用内登录小红书或抖音，自动上传本次素材并填写文案；用户核对并确认后才提交。保存可识别的发布回执，结果不明时锁定重试，避免重复投稿。
- **评论采集**：自有作品的网页采集支持自动滚动、展开回复、结构化响应与页面文字合并去重；保留父评论编号、发表时间及点赞数，重复采集不覆盖人工分类。
- **运营数据空间**：可采集当前作品可用的互动指标，也能手动补录。按时间保存快照与来源，未知项留空，汇总不重复叠加累计数据。
- **登录复用**：同一次工作台登录中复用平台会话；退出工作台、刷新主窗口或退出应用后清理。平台密码和 Cookie 不进入项目备份。
- **累计创作与协作升级**：敏感词固定替换 / AI 改写与语义识别、可维护词库、小红书文案规则、飞书多维表格发布计划同步、评论本地初筛 / AI 分类 / 人工核对与复盘。

## 检查结果

2026-10-13 发布前检查：**211 项回归测试全部通过**，包含 Python 敏感词检查器对照。TypeScript 与桌面前端生产构建通过。桌面上传、中文 / 表情填写、确认取消、单次提交、回执保存与窄窗口布局通过独立 Electron 离线验证。

未进行真实账号最终投稿；平台页面、模型权限、网络与风控可能影响实际使用。模拟验证不等同于真实平台端到端验收。详见 [验证记录](https://github.com/JerryCoal/shengzhang-studio/blob/v1.6.0/docs/PLATFORM-ASSIST-VALIDATION-1.6.0.md)。

## 下载与升级

1. 下载 `Shengzhang-Studio-1.6.0-windows-x64.zip`，完整解压。
2. 在旧版托盘菜单选择「退出并停止后台任务」，再运行新版 `ShengzhangStudio.exe`。
3. 使用原来的本地用户登录；同一 Windows 账户的数据继续从 `%LOCALAPPDATA%\ShengzhangStudio` 读取。不要手动复制数据库进程序文件夹。
4. 先测试自有作品的评论与指标，再检查发布助手填写的草稿。最终发布需由你确认。

附件同时提供 SHA-256 校验文件。ZIP 内不含用户数据库、API 密钥、平台登录会话或测试账号。

## 使用范围

- 新增的网页自动操作需要 Windows 桌面端；静态 GitHub Pages 不具备跨站读取和桌面自动化能力。
- 当前发布助手处理单张图片或单条 MP4；不会无人值守定时投稿，遇到登录验证或未知页面时停止。
- 平台接受提交不代表审核通过；评论与互动指标以平台实际返回内容为准，不保证完整。
- 保留素材导出、手动上传、手动回填和原有可选抖音只读评论接口。
- 参考相关仓库的流程独立实现，未打包其源码、签名算法或凭证提取程序。

完整操作见 [v1.6.0 使用说明](https://github.com/JerryCoal/shengzhang-studio/blob/v1.6.0/docs/UPGRADE-1.6.0.md)。
