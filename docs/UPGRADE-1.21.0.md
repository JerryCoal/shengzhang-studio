# v1.21.0 使用说明：统一管理 AI Skills

这是本地 Windows 升级版，保留原有项目、账号、语料、词库及 API 配置。完整解压后双击 `ShengzhangStudio.exe`，使用原来的本地用户登录即可。更新不需要删除用户数据，也不需要重新填写密钥。

## 设置一次，后续生成自动使用

1. 打开 **连接与设置 → AI Skills**。
2. 找到工作步骤。每一步默认都启用平台内置规则，可展开阅读。
3. 点击“导入 Skills”，先选择适用步骤，再选择 UTF-8 Markdown 文件或粘贴内容。
4. 预览并确认安装。安装后，在对应步骤的下拉列表选中它；选择即时保存。
5. 返回生成界面，查看“本步骤 Skills”摘要，正常生成。无需在每个弹窗重新选择。

每次可叠加一份自装 Skill。文件最多 24 KB，当前工作站用户最多安装 30 份。相同文件可以分别安装到不同步骤，同一步骤不重复安装。修改导入内容或目标步骤后需重新预览。

## 20 个步骤

| 类别 | 工作步骤 |
| --- | --- |
| 项目与资料 | 项目概要提取、资料卡提炼 |
| 选题与研究 | 检索方向规划、联网新闻搜索、近期内容分析 |
| 策略与文案 | 宣传策略、下期策划、小红书/抖音/TikTok/YouTube/Instagram 文案 |
| 检查与复盘 | 敏感词改写、价格语义判断、评论分类、评论复盘 |
| 图片与视频 | 小红书封面、视频首帧、视频尾帧、视频生成 |

联网新闻搜索规则用于 Qwen 联网模型。公开新闻采集、普通搜索 API 和 MCP 取回内容不执行语言规则；返回内容在研究分析步骤应用所选 Skill。免费本地模板、密钥检查、登录、上传发布和 RAG 向量计算也不执行 Skills。

## 默认规则与自装规则如何配合

默认规则始终保留，自装规则补充业务侧重点、文风、分析方法或画面要求。输出字段、原文证据检查、真实产品事实、预算、实际生成参数和发布确认仍由程序控制。Skills 不会执行脚本、安装依赖或自行发布。

运行中的任务使用启动时的规则。修改设置只影响之后的新请求，禁用或删除当前所选 Skill 会自动回到默认规则。重新启用后需自行选择。旧版本导入的文案 Skills 保留原平台范围，可在兼容的文案步骤里选用。

设置与文件按工作站用户在本机保存；本机完整版随当前请求向所选模型发送当前步骤的规则，其余安装文件不进入模型输入。不同工作站用户互不串用。当前仍是用户级、按步骤配置，不提供逐平台账号的独立 Skills 配置；账号定位和项目事实继续沿用既有生成输入。

## 检查与费用

Skills 会增加输入文字量，预算预估包含实际加入的规则。过长的媒体提示词会明确提示精简，不静默截断。OpenAI 关键帧预留包括基础 $1 与完整提示词的输入预留；最终以服务商账单为准。

模型遵循偏好的程度仍需检查，不保证装入一份 Skill 就能提升流量。项目文档提取仍需核对候选字段再填入，敏感词仍保留本地检测、用户词库和复检。

网页版边界见本版验证记录；静态体验版只管理本地设置，不调用付费模型。
