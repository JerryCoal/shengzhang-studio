## 建议桌面验收顺序

1. 退出旧版托盘程序，完整解压 v1.4.0 后打开。
2. 发布中心选择测试成品，打开发布助手；在该临时窗口登录对应平台。
3. 进入发布页，点击“上传本次素材”，待上传完成后点击“填写标题与正文”；检查账号、素材、文字和可见范围。验收期间不点击平台发布。
4. 评论中心选择自己的已发布作品，开始 50 条、不含回复的采集；核对结构化条数、停止原因和结果预览，再确认导入。同一批次重导应去重。
5. 开启包含回复再采集，遇到登录或验证提示先暂停并由本人处理。

实现代码为独立编写。参考仓库的源码、签名算法、Cookie 文件与依赖均未进入安装包。
