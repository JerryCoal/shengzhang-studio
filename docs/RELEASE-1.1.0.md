# 生长 STUDIO v1.1.0 · 抖音授权、发布与评论同步

本版将抖音开放平台的配置、账号授权、视频投稿和评论回流串成可操作的流程，同时保留 v1.0.0 的本地用户、项目语料、热点、策略、文案、封面和视频功能。

## 下载与升级

- [Windows x64 完整包](https://github.com/JerryCoal/shengzhang-studio/releases/download/v1.1.0/Shengzhang-Studio-1.1.0-windows-x64.zip)
- [SHA-256 校验文件](https://github.com/JerryCoal/shengzhang-studio/releases/download/v1.1.0/Shengzhang-Studio-1.1.0-windows-x64.zip.sha256)
- [抖音开通与使用指南](https://github.com/JerryCoal/shengzhang-studio/blob/v1.1.0/docs/DOUYIN-SETUP.md)

先在旧版托盘菜单选择「退出并停止后台任务」，完整解压新包，再双击 `ShengzhangStudio.exe`。同一 Windows 账户的原数据继续保存在 `%LOCALAPPDATA%\ShengzhangStudio`；不需要复制数据库或覆盖原数据目录。不要同时运行两个版本操作同一工作区。

## 新增与完善

### 1. 面向第一次使用者的开通说明

- 设置页顶部新增「抖音开通与授权」快捷入口。
- 提供六步开通指南、权限对照表、常见问题及官方控制台链接。
- 说明开放平台应用与普通抖音账号的区别，以及应用审核、权限申请、回调配置和运行条件。

### 2. 应用内登录与可选权限

- Windows 优先在隔离的临时窗口中打开抖音官方授权页，完成后自动回到工作台。
- 无法完成内置授权时，提供浏览器登录链接与手动回调入口。
- 可分别选择发布、评论或两项功能；作品列表权限按需授权。
- 应用密钥与平台授权凭证继续在本机按用户加密保存；抖音密码在官方页面输入。

### 3. 视频投稿与发布后评论采集

- 每条任务检查视频、文案、账号和时间后，显式确认启用自动投稿。
- 可在确认时勾选「发布后自动获取评论」，并设置同步频率。
- 等待抖音审核且确认作品公开后，才标记发布成功并开始采集。
- 可以选择授权账号中已有的公开作品，也可手动关联作品 ID。
- 支持每 5、15、30 或 60 分钟同步，支持手动立即同步、暂停和续采。
- 评论保留原文、发表时间、点赞数及人工分类，按 ID 去重，并展示最近同步、下次同步及本轮新增/更新数量。

## 修复与体验调整

- 评论接口单页数量修正为最多 20 条，每轮最多 200 条，超过后保留分页进度继续采集。
- 检查异常或不前进的分页游标，避免重复循环请求。
- 平台授权过期会提示重新连接抖音，并暂停相关任务，不再误触发工作台本地退出登录。
- 防止同一发布记录改绑其他作品导致评论混入；保留既有发布确认与重复投稿保护。
- 改善窄屏按钮换行、权限状态提示及同步信息展示。

## 开始使用

「连接与设置 → 抖音开通与授权」→ 按指引开通应用及权限 → 保存应用信息 → 连接抖音账号 → 发布中心逐条确认 → 评论与复盘查看同步结果。

## 适用范围与验证情况

- **需要自己的开放平台应用、获批的对应接口权限和账号授权。** 普通抖音账号登录不能代替接口权限申请，是否可申请以官方控制台及审核结果为准。
- 本版支持视频投稿和授权账号自有公开视频的一级评论，暂不支持抖音图文投稿、楼中楼回复或任意第三方账号的评论采集。
- 自动任务要求工作区已登录、电脑联网且唤醒。关闭窗口可留在托盘后台，完全退出会停止任务。GitHub Pages 静态页不提供这些后台能力。
- 本地业务与模拟接口测试、授权窗口隔离测试、Windows 本机加密存储与重启验证、桌面启动和界面检查已通过；**尚未使用已获权限的真实抖音应用完成账号授权、真实投稿或真实评论采集联调**。
- 本次发布包含完整源码、Windows ZIP 和校验文件，不包含用户工作区、个人 API 密钥或平台凭证。

官方接口参考：[网页授权](https://open.douyin.com/platform/resource/docs/develop/permission/web/oauth2)、[创建视频](https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/create/create-video)、[评论列表](https://open.douyin.com/platform/resource/docs/openapi/interaction-management/comment-management-user/comment-list)。
