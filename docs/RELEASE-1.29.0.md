# 生长工作站 1.29.0 · 连贯创作流程

日常工作区收为工作台、选题与资料、内容、发布、复盘。项目与账号在管理区维护，页面上方统一选择浏览范围。

## 本版变化

- 创建内容时直接描述需求，选择账号和图文/视频；不必创建专门养号项目，也不必先确认策略。旧项目、旧策略和养号输入继续保留。
- 内容页先显示内容列表。打开一篇后按需求、文案、图片/视频、发布核对操作。标题、正文和封面工具只在相关位置出现，历史记录按需展开。
- 热点研究、热榜和新闻支持收藏资料、保存经验、带参考创建内容。保存内容保留来源、账号范围、期限与版本；后续研究不会覆盖收藏。
- 普通文案、小红书助手和媒体制作读取适用的资料与经验；生成前可以预览，结果保留引用快照。评分仍使用真实样本，不以经验代替样本。
- 前往发布、复盘及后台任务返回保留具体内容或作品。发布状态按账号和内容版本计算；已有计划可继续处理。
- 指标、评论和经验归入复盘。可核对观察后保存为账号经验，带入下一篇。

## 运行方式

Windows 本地版与团队主机版使用同一业务模块及 HTTP 接口。新增草稿和知识保存也支持浏览器加密本地数据适配。独立网页中转仍保留原隐私边界，直接草稿的账号身份生成需 Windows 或团队主机版，网页不会丢弃身份后静默生成。

本版没有新增服务商，没有自动发布授权，也没有后台自动扩样或隐式付费调用。版本验证范围见 VALIDATION-1.29.0.md。
