# v1.9.0 · 全流程 AI Skills 本地测试版

更新日期：2026-10-14。本版在 v1.8.0 的自装文案规则功能上，增加策略、下期策划、抖音文案、评论分类与复盘、封面、首尾帧和视频专用规则。共 12 份内置 Skills，覆盖 12 个实际生成场景；每次只加载当前环节需要的规则。

## 怎么使用

1. 完整解压 Windows 包，启动 `ShengzhangStudio.exe`。已有本地用户、项目、密钥与词库沿用原位置；旧版压缩包可继续保留。
2. 在「连接与设置 → 文案与词库 → 创作 Skills」展开「各环节自动写作与分析规则」，查看各步骤使用的规则、版本及原文。这些规则随应用自动生效，不用重复安装。
3. 按原有流程创建策略、确认后生成文案或画面。「本步骤说明」显示当前自动规则；普通文案还会按目标平台叠加小红书或抖音规范。
4. 在普通「AI 文案」窗口仍可选择自己安装的 Skills。自装规则只补充本次文案风格，不能修改事实、结构和审核要求；敏感词与价格语义步骤独立处理。联网网页版继续只使用内置规则。
5. 生成封面时选构图、风格与文字模式。无字模式不额外添加宣传文字；真实参考图已有包装与标识保留。指定标题模式按给定标题生成，成图仍需检查文字和产品是否正确。
6. 视频先确认首尾帧，再选择时长、声音并检查提示词预览。本版会将实际选择同步到提示词，首尾帧参考图顺序由程序说明。
7. 评论分类会标出含混情绪与需核对项；复盘需要引用真实评论。请核对结论，不把少量评论当作销量或增长证明。

## 提效改动

- 规则按步骤加载，不增加额外规划模型或自动重试，固定模板留在规则文件，当前资料单独提供。
- 下期策划不重复提交旧策略的派生任务、整份事实快照及历史检查记录；保留上期内容、状态及本轮反馈。
- 文案仅在确认任务提示词含完全相同的策略前缀时去重；人工修改及本次要求保留。
- 修复 Qwen 策略重复追加语料，以及 DeepSeek/Qwen 分类示例中布尔类型错误。
- 调用记录保存内置规则名称与版本；媒体生成配方仍保留实际提示词，普通文案保留完整规则追溯。

这些措施减少已确认的重复输入、统一步骤约束；真实成本和质量取决于输入、所选模型及输出，不能保证一次生成成功或固定比例提效。

## 当前边界

本版没有新增 AI 联网搜索、向量检索或自动下载第三方 Skills。热点采集、语料关键词检索、本地敏感词扫描与平台 MCP 工具继续各自工作。更全面的近期高互动内容获取、清洗、检索与总结，按原调研方案单独开发和验证。

规则在本地查看和管理不计模型费用；实际生成仍将必要资料发送给你选定的服务商并按其账户计费。没有为本次测试调用真实付费模型，也没有发布平台内容；测试通过说明接线与保护流程正常，不代表已完成真实生成质量评估。

研究依据见 [全流程规则设计](AI-SKILLS-WORKFLOW.md)，测试记录见 [本版验证](VALIDATION-1.9.0.md)。
