# v1.2.0 升级与手动发布指南

## 升级

1. 在旧版系统托盘菜单中选择「退出并停止后台任务」。仅关窗口会继续留在托盘。
2. 下载并完整解压 v1.2.0，双击 `ShengzhangStudio.exe`。使用原来的本地用户登录。
3. 原用户、项目和密钥仍位于 `%LOCALAPPDATA%\ShengzhangStudio`。不要复制数据库进安装文件夹，不要同时使用新旧版本。
4. 打开发布中心检查旧记录。旧自动投送已停用，未提交的任务转为手动待办。
5. 如果显示「旧版任务 · 请先核对平台」，先看抖音是否已有作品。已发布则登记原链接，不要再次上传。升级无法撤回旧版已经交给平台的投稿。

## 从创作到发布

1. 在内容制作完成封面或视频。修改标题后需重新制作画面。
2. 点击「导出与发布」，预览成品、标题与正文。
3. 图片可选择保留原格式、PNG 或 JPG。JPG 会以白色填充透明背景，保持原图尺寸。
4. 下载完整 ZIP，或只下载图片 / 视频或 TXT。素材包须先解压，平台不能直接使用 ZIP 作为作品。
5. 发布中心选择成品，添加手动待办，核对账号名称与时间。时间只作记录，到点不会投送。
6. 点击「打开抖音创作中心」或「打开小红书创作中心」，在官方页面登录目标账号并上传素材。也可把文件传到手机，用官方 App 发布。
7. 分别复制标题与正文，检查并选择话题、声音、可见范围、素材授权和平台要求的 AI 内容标识，再亲自点击发布。
8. 平台确认成功后，回发布中心「登记结果」，粘贴对应平台的 HTTPS 作品链接并确认。
9. 导入作品评论，完成分类、复盘与下一轮策划。发布不需要开放平台权限。

## 导出文件怎么用

```text
标题-平台-R版本-发布素材包.zip
├─ 01-素材/标题-平台-R版本-封面.png（或 JPG / WebP / 视频 MP4 / WebM）
├─ 02-文案/标题.txt
├─ 02-文案/正文.txt
├─ 02-文案/完整文案.txt
└─ 03-发布指引.txt
```

文件名自动过滤 Windows 不支持的字符；TXT 是 UTF-8 BOM，中文和换行保留。完整文案不会被截断，超出平台长度限制时请在平台编辑。包内只包含所选成品与文案，不含密钥、语料或原始生成提示词。

视频按真实格式导出。若平台不接受 WebM，请在视频编辑器中转为 MP4（建议 H.264 / AAC）；不要直接改扩展名。本版不内置转码器。Seedance 保存的 MP4 不需要在导出时转码。

## 可选评论接口

设置中的抖音连接只用于作品查询和评论同步，普通用户可忽略，直接导入评论文本。只有已有移动 / 网站应用及 `video.data`、`item.comment` 等获批权限的用户才填写凭证。个人开发者资格和新企业应用能否申请，需以官方当前规定为准，认证不等于开通权限。

保留的定时评论同步需要单独开启并保持应用联网运行；它不会上传或发布作品，也不会自动回复评论。
