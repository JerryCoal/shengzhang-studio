# 生长 STUDIO 1.26.0 升级说明

本版为工作站增加可选 Redfox 服务，用一份服务密钥连接公开作品搜索、详情、评论、热榜、联网检索和图片视频生成。现有账号、项目、身份记忆、Skills、发布流程及其他服务配置保留。

## 升级步骤

1. 先处理、查询正在生成或采集的任务，并在工作站导出备份。团队版还需按包内 `团队部署与使用说明.md` 备份主机数据与恢复环境。
2. 退出个人应用；团队版使用原包的 `Stop-Team.cmd` 停止主机服务。完整解压新包到新程序目录，保留原数据目录，不把程序目录覆盖到数据目录。
3. 使用原来的个人登录方式，或以团队版相同 Windows 运行用户、相同数据目录和 HTTPS 地址启动。团队主机不会重新创建管理员，也不应删除旧 `master.key`。
4. 在“连接与设置 → Redfox”保存自己的 API Key，选择需要开启的范围。团队由管理员保存。保存本身不产生付费请求。
5. 按界面确认费用后开始读取或生成。密钥“已配置”仅表示保存成功；真实接口权限、生成结果和计费需在自己的账号核验。

## 新入口

- 热点与灵感：同话题研究选择 Redfox 读取服务；近七天研究可使用 Redfox Kimi 联网来源；新增平台热榜。
- 内容制作：Redfox 媒体开关启用时，封面和首尾帧使用 Seedream 5.0 Pro，视频使用 Seedance 2.0。
- 评论分析、运营数据：新增 Redfox 读取入口，预览核对后再保存。
- 连接与设置：三个开关分别控制平台资料、图片视频、联网搜索；人民币估算用量单独显示。

本版不新增 Redfox GPT Image 选择、账号粉丝看板、平台发布或私信功能；文字创作和分析继续使用原有文字模型。各平台详细支持范围和已知限制见 `REDFOX-TEST-REPORT-1.26.0.md`。

## 任务与退路

看到已有任务编号时先查询原任务，重启不会自动重新提交。若提交中断且没有编号，先到 Redfox 核对记录，再决定是否解除锁定；解除后再次生成或研究会单独收费。

需要退回原服务时，先处理完在途任务，关闭相应 Redfox 开关。原有 OpenAI、Seedream、Seedance、搜索和 MCP 配置继续保留，失败时不会自动换另一个收费服务。若更换程序版本，请保留升级前备份；不要通过删除数据目录或主机密钥解决版本问题。

个人与团队数据目录不变，不自动合并。此升级不开放公网、不配置防火墙或 DNS，也不增加系统开机自启。
