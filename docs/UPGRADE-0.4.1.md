# 生长 Studio 0.4.1 · API 诊断修复

保留 0.4.0 的快捷登录、项目语料库、敏感词替换和自动保存。本次修复 OpenAI API 错误被合并成“额度或频率受限”的问题。

## 更新

1. 在旧应用的托盘或菜单选择“退出并停止后台任务”。仅关闭窗口不会退出。
2. 完整解压 0.4.1 压缩包，运行其中的 ShengzhangStudio.exe。
3. 使用原本的本地用户名登录。原项目和密钥仍位于 `%LOCALAPPDATA%\ShengzhangStudio`，不需要重新建立账号或复制数据库。

## 排查 API

打开“连接与设置 → API 与模型”。“检查连接”只读取官方模型列表，不收费，也不能验证账户余额或生成权限。请回到原来的生成步骤重试一次，再查看设置中的“最近一次 API 异常”。

| 诊断结果 | 处理方式 |
| --- | --- |
| 预付余额用完 / 可用额度不足 | 在 OpenAI Billing 中检查密钥所属组织的余额和计费状态 |
| 项目或组织支出上限 | 检查对应项目或组织的 Limits，不是应用里的项目预算 |
| 组织用量上限 | 申请提高服务商批准的上限，或等待重置 |
| 请求 / token 限流 | 按页面显示的时间等待，减少同时生成的任务或单次输入量 |
| 密钥或权限问题 | 检查密钥是否有效、项目成员资格、接口和模型权限 |
| 网络错误 | 检查连接；系统代理设置改变后，从托盘退出应用再重新打开 |
| 无法识别的 HTTP 429 | 暂时不能确定原因，检查 Billing / Limits 并导出诊断结果 |

创建新密钥不会补充 API 额度；应用的项目预算也不会给 OpenAI 充值。成功读取模型列表不会清除先前的生成额度错误。

新版不自动重复提交付费生成。明确被拒绝的请求释放应用内的预留费用；网络中断、超时或服务端错误仍需核对服务商账单。限流等待期间，同一用户、同一模型的重复生成不会发出请求。模型费用以服务商账单为准。

Windows 的最近一次诊断保留在当前登录会话的内存中，退出应用后清除；可在设置页导出不含密钥和项目资料的诊断 JSON。密钥仍按原方式加密保存。本地用户的数据存储位置没有改变。
