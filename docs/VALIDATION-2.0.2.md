## 两套打包后端

个人版和团队版均使用包内 Node v24.19.0 与最终编译后端，只在隔离临时目录和本机回环地址运行，并拒绝外部网络。各 13 项检查通过：

1. 后端启动、版本检查及编译静态资源正常提供。
2. 私人 Agent 草稿、临时正文和任务日志必须认证。
3. 新工作区默认 Seedream，Redfox 可选路由关闭。
4. Seedream/Seedance 可选水印默认关闭；本地 Qwen 默认关闭，保存合成配置不自动探测；读取研究/MCP 设置不启动服务。
5. 合成 GLM/Redfox 密钥只加密保存，不自动启用或探测。
6. 草稿修订检查、交接幂等、相同任务编号及共享作品的临时编辑按成员隔离。
7. 灵感对话保留未发送输入的空白与 pending 的冻结目标；两个成员使用相同对话/轮次编号仍彼此隔离，没有提交模型。
8. 正常退出和登出只撤销对应会话。
9. Windows DPAPI 保护存在，隔离文件不含测试密码、合成密钥、草稿和检查点明文。
10. 重启准确恢复对话、未提交内容、账号绑定及暂停检查点，不重复生成或建立草稿。
11. 恢复任务可以转为人工核对，不改变其他成员任务或重放请求。
12. 清理一名成员临时编辑不影响另一成员的恢复资料。

以上分组归纳各报告的 13 条断言。两包外网尝试、真实收费调用和真实用户数据访问均为 0；未启动第三方 MCP 或投送社交平台。四个启动/重启进程均正常以退出码 0 结束，独立复核无残留、无强杀。
