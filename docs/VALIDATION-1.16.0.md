# v1.16.0 验证记录

本轮使用隔离内存工作区和模拟 MCP / DeepSeek，不读取真实用户的资料、密钥或登录状态，不执行发布、评论操作或付费生成。

## 验证范围

- MCP 官方筛选映射、三词与十二篇详情上限、不加载额外评论、不保存作者或访问凭据。
- 七天、三十天和不限时间只作用于小红书；新闻仍七天，未知/未来日期不进入研究。
- 样本排序区分缺失与零，保留约数，不把字面匹配视为语义置信度。
- 小红书模式只使用所选 DeepSeek，一次分析，无扩词或其他收费搜索；没有合格来源不调用分析模型。
- 分析建议必须引用本条证据，选用后按该分析自己的时间范围进入创作。
- 重用参考、失败保留、计费、用户隔离、后台任务与原有研究流程回归。
