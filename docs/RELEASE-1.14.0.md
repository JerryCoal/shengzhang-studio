# 生长 STUDIO v1.14.0

- 新增应用内“后台任务”入口，支持策略、下期策划、AI 文案、敏感词候选、评论分类与复盘、热点研究、Qwen 索引及语料查询。
- 处理时可用“收起窗口”、X 或 Escape 收起弹窗，请求继续执行；从任务列表返回查看，完成后不会自动跳回原项目。
- 正在处理的项目保守锁定修改与重复提交，其他项目可继续编辑；Windows 版可同时处理不同项目的任务。
- 联网网页版继续限制为一次一个联网请求，等待时可切换页面、编辑其他项目的本地内容。
- 收起期间保留原页面与候选，敏感词等候选仍需核对、采用并保存。后台刷新不会清空其他项目正在编辑的策略草稿。
- 文字后台任务进行时暂时禁用连接设置与退出用户。请保持应用运行；刷新或彻底退出可能打断请求、丢失内存候选，不承诺重启恢复。
- 封面和视频继续使用原有后台机制，在素材卡查看，未纳入新任务列表的统一追踪。

更新前请等待旧版任务完成并保存结果，从菜单彻底退出旧版，再完整解压新版并运行 `ShengzhangStudio.exe`；本地用户数据沿用。Windows 关闭主窗口仍会缩到托盘。

本地 Windows 测试版，尚未上传 GitHub；未使用真实密钥调用付费模型。使用与更新步骤见 [升级说明](UPGRADE-1.14.0.md)。
