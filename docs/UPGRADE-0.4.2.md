# 生长 Studio 0.4.2 · DeepSeek 与多服务商

保留 Windows 本地应用和原有用户、项目、语料、敏感词库、自动保存。文字任务现在支持 OpenAI 和 DeepSeek 官方接口，每个环节可以分别选模型。

## 更新与设置

1. 从旧应用的菜单或托盘选择“退出并停止后台任务”。仅关闭窗口仍会保留旧程序。
2. 完整解压新版，运行 ShengzhangStudio.exe。确认左下角显示 v0.4.2，再登录原本的本地用户。
3. 打开“连接与设置 → API 与模型”，将“模型服务商”选为“DeepSeek 官方 API”。
4. 填写在 DeepSeek 官方控制台创建的 API Key，点击“加密保存到本机”。不能在这里使用 OpenAI 的密钥。
5. 点击“检查连接与余额”。应用只读取官方模型列表和账户余额，不进行付费生成。
6. 点击“文字任务使用 DeepSeek 分工”，再点击“保存模型分工”。也可以逐项选择，混用两家服务商。
7. 回到策略、文案或评论页面，在生成窗口确认模型和接收资料的服务商后开始生成。

## 推荐分工

| 环节 | DeepSeek 推荐模型 | 处理方式 |
| --- | --- | --- |
| 宣传策略、下期策划 | DeepSeek V4 Pro | 启用思考，综合资料和反馈 |
| 文案与分镜 | DeepSeek Flash | 关闭思考，按已确认策略生成 |
| 评论标签与情绪 | DeepSeek Flash | 关闭思考，按固定类别处理 |
| 评论复盘 | DeepSeek Flash | 启用思考，保留评论原文依据 |

使用 DeepSeek 时，策略和文案仍会先查询当前项目语料，生成后筛选敏感词；结果还需人工检查。内容会记录实际使用的模型，不会自动切换到另一家服务商。

GPT Image 2 关键帧继续使用 OpenAI 密钥，Seedance 视频使用独立的 Seedance 密钥。只配置 DeepSeek 可使用全部文字 AI 环节；本地模板、图片排版和本地短片无需这些文字模型接口。自动发布与评论同步仍需相应平台授权。

## 费用和密钥

- 只填写密钥不会调用模型。DeepSeek 的“检查连接与余额”显示查询时的快照，不保证以后每次调用一定成功。
- DeepSeek 费用以美元估算，按 2026-09-14 官方高峰、输入缓存未命中价格记录：Flash 输入 $0.30 / 输出 $1.20，V4 Pro 输入 $1.32 / 输出 $3.96，单位均为百万 token。缓存命中或非高峰时段的真实费用可能更低，最终以官方账单为准。
- API 余额不足、请求限流、密钥失效和网络问题会分别提示。失败不会自动重复付费请求，也不会自动换用另一家的密钥。
- Windows 密钥分别存入当前本地用户的加密保险箱，由登录密码与 Windows 账户共同保护。界面只显示末尾四位，项目备份不包含密钥。
- 联网网页版源代码同步支持两家服务商，数据和密钥仍由浏览器本地加密保存。每次仅临时发送所选服务商的密钥及必要任务资料，后端不持久保存。公网完整网页版仍需完成后端托管。
