这些是按任务特点选定的默认值，尚未用用户真实品牌样本评估输出质量。设置页可分别调整五个文字环节，修改会用于下一次实际请求。失败时不会自动换模型或用模板伪装成功。

默认单价：GPT-5.4 输入 $2.50 / 输出 $15；mini $0.75 / $4.50；nano $0.20 / $1.25，单位为百万 token。按官方标准价格记录估算；实际费用、权限以账户为准。价格来源：[GPT-5.4](https://developers.openai.com/api/docs/models/gpt-5.4)、[mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini)、[nano](https://developers.openai.com/api/docs/models/gpt-5.4-nano)。

图片生成、视频生成、AI 配音尚未接入。后续日常图片候选为 [GPT-Image-2.5 Flare](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare)，配音候选为 [GPT-4o mini TTS](https://developers.openai.com/api/docs/models/gpt-4o-mini-tts)。这些候选不出现在可执行的模型选择器中，不产生调用。

## 如何使用

1. 在运行服务的 Windows 电脑打开 `http://127.0.0.1:4318/#settings`。
2. 在「API 与模型」输入自己的 OpenAI API Key，点击「加密保存到本机」。保存无需联网、无需重启。
3. 「检查连接」只向官方请求模型列表，没有付费生成。列表可见不保证余额充足或生成权限。
4. 策略窗口选择 AI；内容制作卡片点击「AI 文案」；评论页点击「AI 分类」或「AI 复盘」。每次会说明数据发送与计费方式。
5. 模型分工可单独保存或恢复推荐。模型返回错误、引用无效或结果未完成时，现有内容保留。

AI 文案修改已确认策略下的制作内容，保留旧成品历史，更新标题、正文、Prompt 与三个分镜，并标记待重新制作。它不会自动修改已经确认的策略或发布快照。

分类每次最多处理 60 条未分类评论，跳过无关、人工校正与已经 AI 分类的评论；可重复点击处理余下评论。AI 复盘使用本项目全部有效评论，当前上限 200 条，不静默截取。超过时可用本地规则复盘。证据 ID 必须存在，样本数与证据数由代码计算，建议仍需人工判断。

## 密钥存储与边界

- 文件：`data/private/openai.dpapi.json`（使用自定义 DB_PATH 时在数据库目录下）。整个密钥通过 Windows DPAPI 的 CurrentUser 保护后写入；仅另存末尾四位用于识别。
- 密钥通过匿名管道交给 Windows，不进入子进程参数、命令文本、临时明文文件或日志。写入使用原子替换，失败保留旧文件。
- 完整密钥不返回客户端，不进入 localStorage、sessionStorage、SQLite 项目数据、JSON 备份、PWA 缓存或安卓/iOS 安装包。输入框提交即清空。
- 调用时解密到本机服务内存，仅通过 HTTPS 发往固定的 `api.openai.com`；禁用重定向，不接受用户任意中转地址。Responses API 使用 `store:false`，这不等于服务商完全不保留处理日志。
- 保存、删除、检测、模型设置与个人密钥调用只接受直连回环地址及本机来源，拒绝代理头、远程来源与移动端 Origin；工作区密码存在时仍需登录。
- 「删除本机密钥」删除密文文件；不撤销服务商账户上的密钥，也不保证磁盘历史副本的安全擦除。旧环境变量密钥单独管理，设置页明确提示其来源。
- 保护依赖当前 Windows 用户账户。以同一账户运行的不可信程序、管理员权限或已入侵的系统仍可能读取调用时内存；不存在绝对安全保证。建议使用独立项目密钥，并在提供商账户设置额度。
- 本地目录、磁盘/系统备份中的密文仍应保密。迁移到其他 Windows 账户或电脑时重新输入密钥；不要把 DPAPI 文件当作跨设备密钥备份。

Windows 机制依据：[Microsoft DPAPI / CurrentUser 说明](https://learn.microsoft.com/en-us/dotnet/standard/security/how-to-use-data-protection)。沙盒或未加载用户配置的服务账户可能无法使用 DPAPI；应用会拒绝保存，不退回明文。

## 多端范围

**本版完成 Windows 本机密钥保险箱。** 手机网页、远程部署和原生壳不会上传个人密钥到运行服务的电脑，也不能使用该个人密钥触发模型费用。仍可使用本地模板、素材与数据功能。

安卓 Keystore、iOS/macOS Keychain 尚未实现。后续若要每台手机独立调用个人 API，需增加原生安全存储和原生网络调用适配，并在真机验证；不能把共享开发者密钥写进安装包，也不能把手机用户密钥误存到远程工作区。Linux/Docker 的个人密钥保险箱目前关闭。
