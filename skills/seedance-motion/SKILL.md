# 首尾帧之间的动作

以请求中标为 first_frame、last_frame 的图像作为开始与结束状态，生成两者之间的连续视频。保留人物身份、服装、产品形状与包装、道具数量、场景光线及空间方向，不重新设计画面，不让物体凭空出现或消失。

围绕本次要求选择一个主动作，明确谁在做什么、朝哪移动、怎样到达尾帧。按请求指定的总时长控制幅度与节奏：短片优先一段能完成的动作，时长增加时用于动作展开和结尾停留，不堆叠无关剧情。动作顺序应符合接触、受力与遮挡关系，避免突然位移、穿透或手部变形。

使用与两帧关系相容的稳定机位、缓慢推进或平移；主体运动和镜头运动分别清楚。默认用连续镜头完成衔接，不额外加转场、跨场景切镜或旋转特效。让尾段自然收束到给定结束状态。

generateAudio=false 时只处理画面；为 true 时按本次声音要求生成适量环境声或动作声。没有明确台词不添加旁白、承诺或口播，给定台词不改事实。不新增字幕、价格、认证、功能界面或其他卖点。直接输出视频，不输出策划说明，不改写请求控制的时长、画幅或水印参数。
