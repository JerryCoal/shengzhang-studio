# Shengzhang Studio v2.0.0 · 自媒体运营工作站

JCoal 开发。基于原有工作站增量升级，不重建账号、项目或模型接入架构。

## 新工作流

灵感 Agent → 小红书 / 抖音 / Instagram / YouTube Agent → 发布 Agent → 结果分析 Agent → 人工筛选经验 → 下一轮创作。

- 独立 Agent 页面、平台色彩与清晰步骤导航；旧内容、资料、账号和复盘入口继续兼容。
- 灵感需求识别热点意图，带入已有平台研究流程；读取范围、账号及费用仍需确认。呈现来源与分析，不把“热门”当成效果保证。
- 需求、目标账号、选定经验、热点分析、模型与发布要求通过明确数据包交接。用户选中的经验优先指导创作，不取代已核实事实。
- 各 Agent 可选择文字模型及多条适用 Skills；保留默认规则编辑、Markdown 导入和规则来源记录。平台写作规则不会偷偷变成媒体控制指令。
- 加入 GLM 官方接口，与 Qwen、DeepSeek、原有 OpenAI 并存。新工作区图片默认官方 Seedream，视频沿用官方 Seedance；已有配置不改写。Redfox 保留可选，保存密钥不自动开启路由。
- 统一任务中心显示文字、研究、图片和视频任务。不同内容可并行；同一内容的冲突操作仍互斥，共享预算并发预留。完成提示支持弹窗和可关闭的轻提示音。
- Agent 输入和编辑器未提交正文自动加密保存，按成员与账号隔离；安全检查点支持暂停/继续。关闭时可以后台继续，也可先保存进度再退出。已提交模型的请求不能保证撤销，重开后需核对，不自动再次付费提交。
- 发布中心保留实际投稿前确认、独立账号/排期记录，增加跨平台或跨账号改编入口。已连接飞书时询问是否记录新计划；已授权的自动同步规则继续生效。
- 可登记此前在平台发布的完整作品链接，绑定真实账号后采集指标、评论并由用户确认分析。经验可保留、停用、复用或导出 Markdown 分享。

## 下载与升级

个人版：`Shengzhang-Studio-2.0.0-windows-x64.zip`。

团队版：`Shengzhang-Studio-Team-2.0.0-windows-x64.zip`。

完整解压到新文件夹再运行，勿覆盖正在运行的旧目录。先在旧版导出备份，保留旧包。个人和团队数据目录各自保留，不互相迁移。各压缩包配有 SHA-256 校验文件。

## 验证边界

本版使用隔离数据和模拟服务验证流程、并发、费用保护、账号隔离及打包后端；未替用户发起真实付费生成或真实社交平台发布。实际服务可用性取决于密钥、余额、MCP 工具能力和平台授权。

独立静态/中转网页版可管理草稿，但含私人账号身份、多选 Skills 的新 Agent 生成请使用 Windows 完整版或团队版；不会静默丢弃选项后继续生成。其联网请求仍保留单请求安全锁。

飞书直连范围仍是发布计划多维表格；分析经验可导出后上传飞书/腾讯文档，本版没有声称新增通用腾讯文档自动写入。媒体与模型结果需要人工检查，不声称支持服务商未提供的中途取消或跨平台无条件自动投送。
