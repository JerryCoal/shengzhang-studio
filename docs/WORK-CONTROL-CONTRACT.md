## D02 冻结契约

- Plan 保存版本、节点、目标、批准；计划修改产生新版本，旧批准不变。节点角色首期限定小红书文案、抖音研究、抖音脚本。
- Task 固定项目、账号/公共研究身份与角色；Run 固定计划版本、输入快照和额度；Attempt 固定派发及回执，客户端不能伪造执行状态。
- ActivityEvent 服务端追加，按 run 的 sequence 排序；网络重复交付以 id 去重。只保存公开执行事实和脱敏摘要，不保存隐藏思维过程。
- ArtifactVersion 保存正文/结构和既有素材 ID 映射；用户编辑产生版本；迟到结果为候选版本。成果保存、成功状态与通知写入同一 SQLite 事务。
- Notification 和 ViewCursor 按成员隔离；通知生成、客户端交付和用户已读分别记录。点击目标固定任务、运行与成果版本。
- 新表使用原工作区 SQLite 和加密密钥；每条活动单独加密，不重写工作区大 JSON。新 schema 单向兼容：回退旧程序前恢复升级前备份，不让旧程序写新版数据。
- 状态：waiting_dependencies / queued / running / waiting_user / paused / succeeded / failed / cancelled / needs_reconciliation；停止请求另存 requestedAction，不能把请求当成已停止。
- 计划批准才能入队；幂等键按成员和操作隔离，输入变化重用键报冲突。任务重试新建 run，不覆盖旧运行。
- 调度器持久租约 + fencing token，后台执行与页面生命周期分离；依赖绑定具体运行及成果版本。凭证只在调用边界从安全配置获取，输入快照不包含密钥。
- 旧 journal 是客户端历史检查点，不是服务端执行证据；迁入历史不会入队，最多只迁已有记录，无法恢复已删除历史。
- 现有 GET/PUT `/api/agent-workspace` 路由保持不变，草稿 key 为 `projectId:agentId`，不是 `/api/projects/:id/agent-workspace`。

## 并发边界

旧全项目锁继续排斥该项目的所有新任务；素材锁使用原 asset ID，策略与研究保留原资源锁。平台浏览器/MCP 共享连接锁不加假账号后缀绕过。独立文案与研究可并发。供应商并发限制和未知费用预留不因重试/退出释放。

## UI 与降级

总控 / 任务 / 账号 / 资料四个主入口，旧创作、发布、复盘保持兼容入口。AI 总控先独立估算和批准规划费用，生成待批准草案；不收费规则草案仍可选，明确标注非 AI。活动只展示服务端执行事实而非隐藏推理。静态网页/中继版不启动后台队列，显示能力限制并保留原流程。

## 保留策略与迁移

记录默认不自动删除，界面分页；提供明确归档接口而非无限加载。归档仍在同一加密数据库中，旧游标收到需重新同步提示。先对合成资料演练，真实用户数据只在正常启动时非破坏性新增表；旧成果不改写、旧用量不结算、不释放预算。
