## 两套真实打包后端

个人版和团队版均使用包内 Node v24.19.0 与最终后端，在全新临时目录、仅本机回环连接、拒绝所有外部网络的条件下各通过 11 项检查：

1. 后端启动、版本健康检查和编译后静态页面服务。
2. 未登录时不能访问私人 Agent 草稿、临时正文与任务日志。
3. 新工作区默认 Seedream，Redfox 路由默认关闭。
4. 合成 GLM/Redfox 密钥仅加密保存，不发起连接测试或自动启用服务。
5. Agent 草稿修订冲突、幂等交接、相同任务编号及共享作品临时编辑的成员隔离。
6. 首次正常关闭及退出登录仅撤销对应会话。
7. Windows DPAPI 保护存在；隔离磁盘文件不含测试密码、合成密钥、需求或检查点明文。
8. 重启后准确恢复需求、未提交标题/正文/要求、账号绑定和暂停检查点，不重复生成或增加草稿。
9. 恢复任务转为人工核对状态，不重放付费请求或修改另一成员任务。
10. 清理一名成员临时正文不影响另一名成员暂存。

以上分组归纳了各报告的 11 条断言。两包外网请求均为 0、真实付费 API 调用均为 0。四次启动/重启进程均正常退出，无残留测试后台。首次沙箱运行受 Windows DPAPI 权限限制，随后在正常 Windows 用户权限下重新运行并通过；不是绕过加密验证。
