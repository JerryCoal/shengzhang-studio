## 环境排查记录

第一次连接失败是启动时配套浏览器尚未下载完成。等待 HTTP 服务就绪后协议连接成功。

默认缓存中的第三方浏览器报 Windows side-by-side 组件配置错误。在项目内复制浏览器、补齐版本组件目录并使用独立本地缓存后，浏览器能够启动并生成真实二维码。该隔离修复用于本机联调，不代表所有 Windows 环境都需要同样修复，也没有改动用户 Chrome、系统组件或关闭浏览器安全选项。
